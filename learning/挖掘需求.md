# 一、如何找到一个能赚钱且很容易的需求点？

## 1、哪些产品付费率很高?

哥飞的工具中有一个 Stripe引荐流量榜,可以看到网站有多少流量到达付费页。但光看这个你只是知道有谁在赚钱,但你并不知道谁赚钱厉害！https://seo.web.cafe/referring/ 我会多看一步：网站访问量/strip页面流量=到达付费页的比例；用这个指标代替付费率，从而可以很好评估这个产品的用户需求是否强烈 ![image](https://s.web.cafe/image/656ae9a845824696981bc2176018951b.jpg) 以 Higgsfield 为例：269.26 万 ÷ 3131.87万 ≈ 8.60％也就是说，每获得100 次网站访问，大约会产生8.6次进入Stripe收银台的访问.假设：支付页到达率：8.6%；进入付款页后的支付成功率：50％客单价：50 美元；月访问量：10万 那么：10万 × 8.6% × 50％ × 50美元= 21.5 万美元新增付款金额。但是：1、这不是普通订阅站的行业平均值，进入Stripe 引荐榜的网站本身就很优秀；2、不能只想好的不想差的，以1％的保守值估计。

## 2、广告平台消耗数据

如果你一个产品赚钱很厉害，你是不是想要放大量赚更多的钱？我们就用这个思维来反推那些一直在投放，或者突然加大投放的产品，它的ROI 一定是大于1 的，抄作业。 我用过的平台：（1）小红书聚光：可以筛选关注领域的热门素材，可以让你打破信息差,知道在你认知之外的哪些产品正在投放赚钱。类似的还有抖音的巨量 ![image](https://s.web.cafe/image/a95b804c20754eebacb89c70203cb50f.jpg) （2）谷歌应用商店和appstore的软件下载量与收入 app.sensortower.com ，这个网站可以查看一些下载量和收入数据。我自己实验以及与一个游戏开发者聊过，自查对比过这个数据和内部数据，具体数值是不准的，但趋势范围是对的.比如上面写月收入 50K，企业内部真实数据基本就在40K到 60K 这个区间，不会出现50K和 5K这种量级的区别。类似的软件：七麦数据、点点数据等等

## 3、淘宝和闲鱼销售数据

我曾经做过一款面向研究生的学习软件。在做用户调研时，我们发现竞品在淘宝和闲鱼上有很多人卖安装包或使用教程，月销量能达到几千份。我们找其中一位店主聊了聊，他提到一个关键点：很多人需要翻译功能。当时我们在想，研究生最基本的六级翻译应该都会吧?谁会要翻译，而且已经有这么多翻译工具。但后来上了这个功能（当然是结合用户的场景和做了细节方面优化），因为大家看的是专业科研论文，信息量大且专业用词多，所以看不懂.例如Zotero 是一个免费开源的文献管理插件，但你发现淘宝上光卖这个插件安装包和教程的都能卖几万份。（而这在 GitHub上有很多免费的开源项目，但是百度上搜不到 GitHub 的链接）如果你再结合搜索引擎的一些搜索数据，你会发现用户的需求很强烈。 ![image](https://s.web.cafe/image/fcf9f831153747b5a36b7144a13ccb3e.jpg)

## 4、关注一些工具工厂或者大厂会员功能

PDF转 Word、图片OCR、录音转文字这些需求，你觉得用户会付费吗？能够支撑一个产品的月订阅到 1 千美元的收入吗？ wps 你去看看WPS 的付费会员功能，会发现每一个功能都能找到免费开源方案，或者调用 API 极其简单的实现方式。但想想那些整天兴趣爱好是吃喝玩乐、并不研究工具和效率的人，对他们来说，把10 页PDF 转成Word就很困难。如果人们不会为这些功能付费，WPS的收入是从哪来的？ ![image](https://s.web.cafe/image/13b0a6765cc44105967650913e29b063.jpg) 但也不是所有的都可以做，**优先选择那些高级会员才能用的功能，而且还限制次数、限制用量的功能**

## 5、分享量很高的视频

哥飞的群友，大家做的可能都是需求比较明确、有大量搜索词方向，或者说一个突然起来的新词。我做社交媒体的时候，是否会选择做一个方向，就是评判这个方向爆款的内容是不是分享量比点赞量还高。比如说点赞量 1万，分享量2 万，那说明这个东西很具有传播力。它是一个吸引人、让人愿意分享的东西。做这个产品，它会降低我营销的成本，会有人自发地去传。

# 二、挖掘好需求时必须要有的 5 个认知：

上面说的是怎么找到一个可能很容易就能赚到钱的需求点,下面是一些你自己如何更快的去验证这件事的一些经验和教训。看起来或许比较空洞，但每一个都是我们真用真金白银和时间获得的，虽然没有技法，但是指导思想层面的感悟，让我们尽量做出正确的决策。

## 1、伟大的技术，原始的需求。

AI技术迭代速度很快，但是人们关于工具的需求迭代很慢，需要解决的问题迭代也很慢。所以有很多 Web 时代、移动互联网时代就存在的产品，今天用AI再做一遍照样能赚钱。 ![image](https://s.web.cafe/image/01edd07d46844e26af46ec308da87911.jpg)

## 2、大模型能实现的功能，不代表所有用户都会用大模型。

比如说，批量生成公众号文章，批量生成发言稿.豆包、文心一言、Deepseek 任何一个产品都能做。但是你去搜索相关的产品APP，发现照样很多。所以千万不要陷入“大模型有我就赚不到钱”的这种误区。

## 3、先有用户,再开发

错误行为：先有产品，再有推广。 正确的做法应该是在写第一行代码之前，先 Vibe Coding一个页面出来,然后假装你已经有了这个产品，然后你去做 3件事： （1）拿着这个demo 去宣传，看能不能有曝光，看能不能在1个月之内获得几百、几千个用户，验证你的需求。 （2） 在设计页面的时候，不要写“立即预约”，一定要写“立即购买”，哪怕你没有接购买。 （3）不要开发一个完整的功能，用户给扫你个人微信付款，你手搓给用户交付。 甚至，我们不少产品功能不是产品经理想出来的，每个功能做几个不同的 demo页面，然后去分发宣传,看哪个设想的功能点能够吸引用户的注意力，然后我们就按照这个视频里出现的demo 功能去开发。

## 4、便宜是一个坏生意

做工具订阅，如果你不是视频生成、图片生成这种按量计费,最好能够把它包装成按月或者按年订阅的服务，固定价格，不要卖积分,那样你吸引的都是斤斤计较的价格敏感型用户。当你卖不出去的时候，第一反应不要想着去降价，而是想着自己是不是没有给用户一个合适的理由，让他愿意为你付出更高的价格。

## 一个很烂的产品都有人付费和夸奖

如果你在社交媒体或者 Vibe Coding 的话题里看到一个产品，你一瞬间觉得：它不就是前端页面吗？不做烂了吗？结果还有人夸奖，你去试用发现它甚至都不成熟、不稳定，那说明这个需求真的很痛很痛。这么垃圾的产品都有人在用！看到这种产品不要嘲笑它，而是应该敬畏它、学习它。
