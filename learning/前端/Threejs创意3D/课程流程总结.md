## 二、课前准备阶段

### 3. 基础知识完全指南（`基础知识完全指南.md`）
- Three.js 核心概念速查
- GLSL 语法参考
- 常见问题和解决方案

## 三、课程制作阶段（每课 AI 完成）

以**第 N 课**为例，AI 执行以下步骤：

### Step 1：创建课程代码
```
项目目录：~/Documents/code/2026/@learn/threejs_creative_3d/
├── src/
│   ├── main.ts                    ← 入口文件（切换 lessons/homework）
│   ├── core/SceneManager.ts       ← 共用场景管理器
│   ├── lessons/
│   │   └── N-xxx/main.ts         ← 课程代码（当前课）
│   └── homework/
│       └── N-xxx/main.ts         ← 作业代码（当前课）
├── docs/
│   └── N-xxx.md                   ← 技术文档
└── public/
    ├── models/                    ← 3D 模型
    └── textures/                  ← 纹理图片
```

**操作流程**：
1. 创建 `src/lessons/N-xxx/main.ts` — 课程主代码
2. 创建 `src/homework/N-xxx/main.ts` — 作业代码（或占位）
3. 更新 `src/main.ts` — 切换入口到当前课
4. TypeScript 编译检查 `npx tsc --noEmit`
5. 启动开发服务器 `vite` → `http://localhost:3300`

### Step 2：编写技术文档
- 文件：`docs/N-xxx.md`
- 内容：核心概念、API 速查、代码示例、实现细节
- 要求：与 wiki 课程笔记内容一致

### Step 3：创建 wiki 课程笔记
- 文件：`~/wiki/learning/前端3D/Threejs创意3D/课程笔记/第N课-xxx.md`
- 内容：详细知识点说明、代码示例（JSDoc 注释风格）
- 原则：保留知识点说明，去掉大段代码实现

### Step 4：更新学习进度跟踪
- 文件：`~/wiki/learning/前端3D/Threejs创意3D/学习进度跟踪.md`
- 更新内容：日期、状态（进行中）、主题目标、所需物料

### Step 5：Git 提交
```bash
cd ~/Documents/code/2026/@learn/threejs_creative_3d
git add .
git commit -m "feat: 第N课 - xxx"
```

## 四、学习阶段（每课学生完成）

### Step 1：阅读精选资源
- 课程笔记中的链接
- Three.js 官方文档
- The Book of Shaders（GLSL 课）

### Step 2：动手练习
- 运行项目，观察效果
- 调整参数，对比变化
- 完成练习清单（每课 5-8 项）

### Step 3：苏格拉底问答
- AI 出题（3-7 道，有明确技术深度的原理/推理/应用题）
- 学生回答
- AI 评分 + 追问 + 补充
- 记录到学习进度跟踪

**出题原则**：
- ❌ 不出基础记忆题、代码细节题、主观题
- ❌ 不出片面题（单一方向对比）
- ✅ 偏好有明确技术深度和确定性答案的原理/推理/应用题
- ✅ 只考察课程知识点，不涉及课后作业

### Step 4：费曼学习法
- AI 用大白话解释核心概念（比喻 + 类比）
- 学生用自己的话复述
- AI 诊断：✅ 讲对了 / ❌ 小错误 / ⚠️ 讲漏了

### Step 5：课后作业（可选）
- 复刻 Awwwards 获奖网站效果
- 评分标准：功能实现 + 视觉完成度 + 交互体验
- 代码位置：`src/homework/N-xxx/main.ts`
