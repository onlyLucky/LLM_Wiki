# Three.js 创意 3D 课程

面向有前端基础的学习者的 Three.js + GLSL 创意课程：20 次课、每次 2 小时，共 5 周。前 9 课覆盖 Three.js 全套基础（架构、几何体、材质、灯光、相机、纹理、场景图、模型加载、动画），第 10-16 课深入 GLSL（基础语法、数学函数、噪声、高级 Shader、后处理、粒子、Ray Marching），第 17-20 课转向实战（滚动驱动、创意交互、网站架构、性能调优与部署）。课程的终点不是「会用 API」，而是能复刻 Awwwards 获奖网站的核心 3D 效果。

课程假设你已掌握 Vite + TypeScript（本课程学习者的起点是 Vite + React）。图形学的数学理论不在这里重复推导，需要时按文末「与其他课程的关系」跳转。

## 快速开始

课程代码仓库在 `~/Documents/code/2026/@learn/threejs_creative_3d`：

```bash
pnpm install
pnpm dev
```

课程代码按课组织：`src/lessons/` 是每课的参考实现，`src/homework/` 是作业骨架。启动后默认显示课程门户页，点击任意一行进入对应课程；也可以在地址栏直接加 hash 选课——`http://localhost:5173/#lesson-12` 进入第 12 课，`#homework-12` 进入对应作业。

笔记是纯 Markdown，在 Obsidian、VS Code 或 GitHub 里阅读均可。

## 与其他课程的关系

三份学习资料各管一段，互相引用、不重复内容：

- 《GAMES101 现代计算机图形学课程笔记》（`../../计算机图形学/GAMES101/`）：管数学与渲染理论。空间变换、光栅化、着色方程的推导都在那边，本课程笔记用到时直接指路。
- 《WebGPU 三天实战课程》（`../webgpu/`）：管 GPU 底层与新一代管线。想搞清楚 Three.js 替你屏蔽了什么（渲染管线、绑定组、compute shader），去那边；其讲义的「理论对照」反过来引用本课程第 10-16 课的 GLSL 内容。
- 本课程：管 Three.js 与创意效果的落地，从「能画出一个立方体」走到「能复刻一个获奖网站的核心效果」。

## 学习法说明

这门课与 webgpu 速成课的最大区别在节奏与反馈机制。每次课按固定循环运转：

1. 阅读笔记与动手练习：跑通当课代码，完成清单式练习项；
2. 苏格拉底问答：课前就本课核心概念连续追问，暴露理解缺口，答案与评分记入笔记；
3. 费曼学习法：挑一个核心概念用大白话讲给 AI 听，AI 诊断讲对了什么、漏了什么；
4. 评分与复盘：课程评分 10 分制，扣分点逐条写明「哪里对、哪里不完整」，进度记入《学习进度跟踪》。

完整的流程说明见《课程流程总结》。
