2. 重写 `src/main.ts`，改为 hash 选课：

```typescript
/**
 * 入口文件 - 按 URL hash 选择课程
 *
 * 用法：地址栏加 #lesson-17 或 #homework-12
 * 不带 hash 时默认加载 #lesson-17（当前修复进度所在课）
 */

const lessonModules = import.meta.glob<{ default?: unknown }>('./lessons/*/main.ts')
const homeworkModules = import.meta.glob<{ default?: unknown }>('./homework/*/main.ts')

function parseHash(): { type: 'lessons' | 'homework'; id: string } | null {
  const m = location.hash.match(/^#(lesson|homework)-(\d+)$/)
  if (!m) return null
  return { type: m[1] === 'lesson' ? 'lessons' : 'homework', id: m[2].padStart(2, '0') }
}

async function boot() {
  const target = parseHash() ?? { type: 'lessons' as const, id: '17' }
  const modules = target.type === 'lessons' ? lessonModules : homeworkModules
  // 目录名是 01-project-architecture 这种带名字的，按前缀匹配
  const entry = Object.keys(modules).find((path) => path.includes(`/${target.id}-`))
  if (!entry) {
    console.warn(`未找到课程：${location.hash}，回退到 lesson-17`)
    await lessonModules['./lessons/17-scroll-animation/main.ts']()
    return
  }
  await modules[entry]()
}

boot()
```

### A2 · 第 20 课实例重建内存泄漏修复

**背景**：`src/lessons/20-performance/main.ts` 的实例数量滑块逻辑有 bug。`init()` 里 `const instancedMesh = createInstancedMeshes(count, manager.scene)` 是 const；滑块 onChange 里写了 `const newInstanced = createInstancedMeshes(...)`，是局部变量。后果：第二次拖滑块时 `scene.remove(instancedMesh)` 和 `instancedMesh.dispose()` 作用的永远是最初那个 mesh（早就移除过了），新生成的 mesh 全部累积在场景里无法移除，渲染负载随拖动次数递增。另外 `createInstancedMeshes` 函数内部已经 `scene.add(instancedMesh)` 了，onChange 里又 `manager.scene.add(newInstanced)` 一次，属于重复添加。渲染模式下拉框的 onChange 也引用 const 的 `instancedMesh`，重建后模式切换会失效。

**修改**（把 init 里那行改成 let，onChange 里复用同一个变量名，去掉重复 add）：

```typescript
// init() 内，原来是：const instancedMesh = createInstancedMeshes(count, manager.scene)
let instancedMesh = createInstancedMeshes(count, manager.scene)

// 滑块 onChange 改为：
onChange: (v: number) => {
  instanceCount = Math.round(v)
  /** 实例数量变化后重建：移除并 dispose 旧对象再创建新的（createInstancedMeshes 内部会 add） */
  manager.scene.remove(instancedMesh)
  instancedMesh.dispose()
  instancedMesh = createInstancedMeshes(instanceCount, manager.scene)
},
```

**验收**：

- `npx tsc --noEmit` 无新错误
- `grep -n "const newInstanced" src/lessons/20-performance/main.ts` 无结果
- 渲染模式下拉的 onChange 里引用的 `instancedMesh` 与重建变量是同一个（都是 let 那个）

**提交**：`fix: 修复第20课实例重建导致的内存泄漏与重复添加`
