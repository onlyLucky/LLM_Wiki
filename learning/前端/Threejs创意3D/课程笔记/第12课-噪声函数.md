## 核心概念

### 1. 什么是噪声

噪声是一种**连续的伪随机函数**：相邻点的值接近，但整体看起来随机。

**与随机数的区别**：
| | 随机数（fract + sin） | 噪声函数 |
|--|--|--|
| 连续性 | ❌ 不连续，相邻点差异大 | ✅ 连续，相邻点平滑过渡 |
| 视觉效果 | 杂乱的雪花 | 云雾、地形、火焰等有机效果 |
| 可预测性 | 哈希，完全不可预测 | 梯度插值，有规律 |

**类比**：
- 随机数 = 掷骰子，每次独立，结果毫无关联
- 噪声 = 山脉的高度——相邻的位置高度接近，但整体走势不可预测

### 2. Value Noise（值噪声）

**核心思路**：格点存随机「值」（标量）而非梯度向量，再用平滑插值混合——噪声 = 插值过的随机。

**前置工具**：格点随机值 `random`——把二维坐标哈希成一个 `[0, 1]` 标量（fract + sin 经典哈希，后面 Value Noise 全靠它取值）：

```glsl
float random(vec2 st) {
  return fract(sin(dot(st, vec2(12.9898, 78.233))) * 43758.5453);
}
```

**代码实现**（10 行极简版，理解噪声本质的最佳教具）：
```glsl
/** 2D Value Noise */
float valueNoise(vec2 p) {
  vec2 i = floor(p);
  vec2 f = fract(p);
  /** 四个格点各自取一个随机值（而不是梯度向量） */
  float a = random(i);
  float b = random(i + vec2(1.0, 0.0));
  float c = random(i + vec2(0.0, 1.0));
  float d = random(i + vec2(1.0, 1.0));
  /** Hermite 平滑插值，四角值混合 */
  vec2 u = f * f * (3.0 - 2.0 * f);
  return mix(mix(a, b, u.x), mix(c, d, u.x), u.y);
}
```

**与 Perlin 的唯一区别**：格点存的是标量值（Value）还是梯度向量（Perlin），插值环节完全相同。

**视觉特征**：值在格心连续但一阶导不连续 → 格子感明显、对比度偏低、整体偏「糊」。胜在实现极简，适合教学演示和低频遮罩。

### 3. Perlin Noise

**发明者**：Ken Perlin（1983年，奥斯卡技术奖）

**核心思路**：
1. 把空间划分成网格，每个格点有一个**随机梯度向量**
2. 对于任意点，计算它到周围格点的**距离向量**
3. 用距离向量和梯度向量的**点积**得到影响值
4. 用**平滑插值**把周围格点的影响值混合起来

```
网格点：  A ---- B
          |      |
          |  P   |
          |      |
          C ---- D

P 点的噪声值 = 混合(A、B、C、D 四个格点对 P 的影响)
```

**前置工具**：随机梯度 `hash`——把格点坐标哈希成一个 `[-1, 1]` 区间的二维向量，作为该格点的梯度方向（与课程第 13 课 noiseUtils 同源）：

```glsl
vec2 hash(vec2 p) {
  p = vec2(dot(p, vec2(127.1, 311.7)), dot(p, vec2(269.5, 183.3)));
  return -1.0 + 2.0 * fract(sin(p) * 43758.5453123);
}
```

**代码实现**：
```glsl
/** 2D Perlin Noise */
float perlinNoise(vec2 p) {
  /** 1. 网格坐标 */
  vec2 i = floor(p);
  vec2 f = fract(p);

  /** 2. 四个角的梯度哈希 */
  vec2 a = hash(i);
  vec2 b = hash(i + vec2(1.0, 0.0));
  vec2 c = hash(i + vec2(0.0, 1.0));
  vec2 d = hash(i + vec2(1.0, 1.0));

  /** 3. 距离向量与梯度的点积 */
  float va = dot(a, f);
  float vb = dot(b, f - vec2(1.0, 0.0));
  float vc = dot(c, f - vec2(0.0, 1.0));
  float vd = dot(d, f - vec2(1.0, 1.0));

  /** 4. Hermite 平滑插值 */
  vec2 u = f * f * (3.0 - 2.0 * f);
  return mix(mix(va, vb, u.x), mix(vc, vd, u.x), u.y);
}
```

**关键点**：
- `floor(p)` 取整数部分 → 确定在哪个网格
- `fract(p)` 取小数部分 → 确定在网格内的位置
- `hash()` 生成伪随机梯度 → 每个格点方向不同
- `dot(梯度, 距离)` → 影响值（方向一致=大，垂直=0）
- Hermite 插值 → `f * f * (3.0 - 2.0 * f)` 比线性插值更平滑

### 4. Simplex Noise

**发明者**：Ken Perlin（2001年，Perlin Noise 的改进版）

**与 Perlin Noise 的区别**：
| | Perlin Noise | Simplex Noise |
|--|--|--|
| 网格形状 | 正方形 | 三角形（单纯形） |
| 插值数量 | 4 个角（2D）| 3 个顶点（2D）|
| 计算量 | O(n²) 梯度计算 | O(n) 梯度计算 |
| 视觉效果 | 有轴对齐的伪影 | 更均匀，无方向偏好 |
| 复杂度 | 简单 | 较复杂 |

**为什么 Simplex 更好**：
- 正方形网格有"轴对齐"问题：沿对角线和沿轴线的效果不同
- 三角形网格各向同性：任何方向都一样
- 计算量更少：2D 只需 3 个顶点而非 4 个

**实际使用**：Three.js 提供了 `THREE.SimplexNoise` 类：
```typescript
import { SimplexNoise } from 'three/addons/math/SimplexNoise.js';
const simplex = new SimplexNoise();
const value = simplex.noise(x, y); // 返回 [-1, 1]
```

**GLSL 手写实现要点**（Ashima Arts 标准版，课程「噪声对比」面板使用）：
- 斜切变换 `floor(v + dot(v, C.yy))`：把正方形网格扭成三角形网格
- `i1 = (x0.x > x0.y) ? vec2(1,0) : vec2(0,1)`：判断落点在三角形的哪一半
- 双重 `permute`（`mod((34x+1)x, 289)`）：把格点坐标打散成伪随机索引
- 半径衰减核 `m = max(0.5 - dist^2, 0)^4`：离顶点越远贡献越小，天然平滑
- 修正项 `1.79284291400159 - 0.85373472095314 * (a0^2 + h^2)`：数值归一化消除网格伪影，系数勿改

### 5. FBM（分形布朗运动）

**核心思想**：叠加多个不同频率和振幅的噪声，模拟自然界的分形结构。

**公式**：
```
FBM(x) = Σ (amplitude * noise(x * frequency))
         i=0..octaves
```

公式中的 `noise` 即「底噪」，用哪种已定义的噪声函数都行——下文实现统一用 `perlinNoise`。

**参数**：
| 参数 | 含义 | 典型值 |
|------|------|--------|
| `octaves` | 叠加层数 | 4~8 |
| `frequency` | 每层频率倍数 | ×2（lacunarity） |
| `amplitude` | 每层振幅倍数 | ×0.5（persistence/gain） |

**代码实现**：
```glsl
/** FBM 分形布朗运动 */
float fbm(vec2 p, int octaves) {
  float value = 0.0;
  float amplitude = 0.5;
  float frequency = 1.0;

  for (int i = 0; i < octaves; i++) {
    value += amplitude * perlinNoise(p * frequency);
    frequency *= 2.0;  /** 频率翻倍（lacunarity） */
    amplitude *= 0.5;  /** 振幅减半（persistence） */
  }
  return value;
}
```

**底噪的选择**：fbm 的叠加框架不挑底噪——本笔记与课程第 13 课代码统一用 `perlinNoise`（细节更均匀）；换成 `valueNoise` 质感偏糊，换成 Simplex 无伪影但更贵。

**视觉效果**：
- 1 层噪声：平滑的云
- 2 层噪声：云 + 细节
- 4 层噪声：云 + 更多细节
- 8 层噪声：非常精细的云雾/地形

**类比**：
- 想象你在画一座山：
  - 第 1 层：画出大轮廓（低频、高振幅）
  - 第 2 层：加上山脊（中频、中振幅）
  - 第 3 层：加上岩石细节（高频、低振幅）
  - 第 4 层：加上沙砾（更高频、更低振幅）
- 每一层都是"粗粒度"的补充，合起来就像真实的山脉

### 6. 噪声的常见应用

#### 6.1 云雾效果
```glsl
float cloud(vec2 uv, float time) {
  vec2 q = uv * 3.0 + time * 0.1;
  return fbm(q, 6);
}
```

#### 6.2 地形高度图
```glsl
float terrain(vec2 uv) {
  float height = fbm(uv * 5.0, 8);
  /** 用 smoothstep 强化山脊 */
  return smoothstep(0.0, 1.0, height);
}
```

#### 6.3 顶点变形
```glsl
/** 顶点着色器 */
varying vec3 vNormal;
void main() {
  vec3 pos = position;
  float noise = fbm(pos.xy * 2.0, 4);
  pos.z += noise * 0.5;  /** 用噪声偏移 z 坐标 */
  vNormal = normal;
  gl_Position = projectionMatrix * modelViewMatrix * vec4(pos, 1.0);
}
```

#### 6.4 火焰/烟雾
```glsl
float fire(vec2 uv, float time) {
  vec2 q = uv;
  q.y -= time * 0.5;  /** 向上飘动 */
  float n = fbm(q * 4.0, 5);
  return smoothstep(0.3, 0.8, n * (1.0 - uv.y));  /** 底部亮、顶部暗 */
}
```

## 代码实现要点

### 1. 噪声函数的输入输出

**输入**：
- 2D 噪声：`vec2`（UV 坐标、时间等）
- 3D 噪声：`vec3`（UV + 时间，或 3D 坐标）

**输出**：
- 范围通常为 `[-1, 1]`
- 使用时需要 `* 0.5 + 0.5` 映射到 `[0, 1]`

### 2. 频率和振幅的关系

**直观理解**：
- **频率（frequency）**：噪声的"密度"——频率越高，变化越快，细节越多
- **振幅（amplitude）**：噪声的"强度"——振幅越大，起伏越剧烈

**经典组合**（lacunarity = 2.0, persistence = 0.5）：
| 层 | 频率 | 振幅 | 效果 |
|----|------|------|------|
| 1 | ×1 | ×1 | 大轮廓 |
| 2 | ×2 | ×0.5 | 中等细节 |
| 3 | ×4 | ×0.25 | 细节 |
| 4 | ×8 | ×0.125 | 微细节 |

### 3. 噪声动画

**移动采样点**：
```glsl
float animatedNoise(vec2 uv, float time) {
  return perlinNoise(uv + vec2(time * 0.1, time * 0.05));
}
```

**改变频率**：
```glsl
float pulsingNoise(vec2 uv, float time) {
  float freq = 2.0 + sin(time) * 1.0;
  return perlinNoise(uv * freq);
}
```

两种写法可以叠加：采样点偏移让噪声场「流动」，频率变化让它「呼吸」。底噪换成 `valueNoise` 或 `fbm` 同理，动画逻辑不变。

## 复盘自测（答案）

**1. Simplex Noise 和 Perlin Noise 的核心区别是什么？**
- 网格形状：Perlin 用正方形网格，Simplex 用三角形（单纯形）网格
- 插值数量：Perlin 2D 需要 4 个角，Simplex 只需 3 个顶点
- 视觉效果：Perlin 有轴对齐伪影（沿对角线和轴线效果不同），Simplex 各向同性
- 计算量：Simplex 更少

**2. FBM 为什么要叠加多个频率的噪声？**
- 模拟自然界的分形结构：山脉、云雾、海岸线都有"自相似"的多尺度细节
- 单一频率的噪声太"干净"，叠加高频细节后更真实
- 每一层补充不同粒度的细节：低频=大轮廓，中频=结构，高频=纹理

**3. 噪声函数的输入参数通常是什么？**
- 2D 噪声：`vec2`（UV 坐标、UV + 时间）
- 3D 噪声：`vec3`（3D 坐标、UV + 时间用于动画）
- 通常会乘以频率控制密度，加时间偏移动画

**4. Value Noise 和 Perlin Noise 的唯一区别是什么？Value 的视觉缺陷来自哪里？**
- 区别：格点存的是随机标量值（Value）还是随机梯度向量（Perlin），插值环节完全相同
- 缺陷来源：值在格心处一阶导不连续（连续但有折角）→ 格子感明显、对比度偏低、偏「糊」
- 优势：10 行极简实现，适合理解「噪声 = 插值过的随机」的本质，以及做低频遮罩
