## 🎯 核心概念

### 1. 粒子系统基础

粒子系统用 `THREE.Points` 渲染，每个粒子是 BufferGeometry 中的一个顶点。

**核心区别**：普通 Mesh 每个物体是一个完整的几何体（三角形面），粒子系统每个"物体"只是一个点（顶点），GPU 自动把它渲染成屏幕上的小方块。

```typescript
const positions = new Float32Array(count * 3)  // 每个粒子 xyz
geometry.setAttribute('position', new THREE.BufferAttribute(positions, 3))
const particles = new THREE.Points(geometry, material)
```

### 2. gl_PointSize — 控制粒子大小

在顶点着色器中设置，决定粒子在屏幕上的像素大小。

```glsl
vec4 mvPosition = modelViewMatrix * vec4(position, 1.0);
gl_PointSize = size * (300.0 / -mvPosition.z);
```

**为什么要除以 `-mvPosition.z`？**
- `mvPosition.z` 是粒子在相机空间的深度（负值）
- 除以它实现**透视衰减**：远处的粒子看起来更小
- 如果不除，所有粒子一样大，没有远近感

### 3. gl_PointCoord — 粒子内部 UV

在片元着色器中获取，范围 [0, 1]，左下角为 (0,0)。

```glsl
float d = distance(gl_PointCoord, vec2(0.5));
if (d > 0.5) discard;  // 圆形粒子
```

**类比**：gl_PointCoord 就像每个粒子自带一个小 UV 贴图，(0.5, 0.5) 是中心。

### 4. 生命周期（Birth Time + Age）

每个粒子有 `aBirthTime` 属性，记录它"出生"的时间。Shader 用 `uTime - aBirthTime` 计算年龄。

```glsl
float age = mod(uTime - aBirthTime, uMaxLife);  // 循环
float lifeRatio = age / uMaxLife;                // [0, 1]
float size = aSize * sin(lifeRatio * 3.14159);   // 先大后小
vAlpha = 1.0 - lifeRatio;                        // 淡出
```

**视觉效果**：粒子诞生→变大→缩小→消失→重新诞生。

### 5. AdditiveBlending（叠加混合）

重叠粒子的颜色**相加**，越重叠越亮。

```typescript
material.blending = THREE.AdditiveBlending
material.depthWrite = false  // 必须禁用深度写入
```

**为什么适合火焰/烟雾？**
- 火焰叠加会越来越亮（模拟光的叠加）
- NormalBlending 会遮挡后面的粒子（看起来像固体）

**`depthWrite: false` 为什么必须？**
- 粒子是半透明的，不能写入深度缓冲
- 否则前面的粒子会挡住后面的粒子，看起来像方块

### 6. GPU 粒子 vs CPU 粒子

| | CPU 粒子 | GPU 粒子 |
|--|--|--|
| 更新方式 | JS 每帧更新 position 属性 | Shader 中计算（Transform Feedback） |
| 数量上限 | ~1 万（JS 性能瓶颈） | ~100 万（GPU 并行计算） |
| 灵活性 | 高（JS 可以做任意逻辑） | 低（只能用 GLSL 数学） |
| 数据传输 | CPU→GPU 每帧传一次 | GPU 自己算，不传数据 |
| Three.js 方案 | `BufferAttribute` + JS | WebGPU Transform Feedback |

**类比**：CPU 粒子像"一个人管理 1 万个弹珠"，GPU 粒子像"1 万个弹珠各自按规则运动"。

## 💻 代码实现要点

### 1. 星空粒子（基础 PointsMaterial）

最简单的粒子系统：随机位置 + 白色点 + 缓慢旋转。

- 5000 个粒子，随机分布在 20×20×20 空间
- `PointsMaterial` 的 `size: 0.05` 和 `sizeAttenuation: true`

### 2. 自定义 Shader 粒子

用自定义属性 `aSize`、`aBirthTime`、`aColor` 驱动生命周期动画。

- 大小随 `sin(lifeRatio * π)` 变化（先大后小）
- 颜色从蓝变白变红
- 透明度随 `1 - lifeRatio` 淡出

### 3. 流动粒子（噪声场驱动）

在顶点着色器中用噪声计算流动方向：

```glsl
float n = noise(pos.xz * 0.5 + t * 0.1);
pos.x += sin(n * 6.28) * 0.5;
pos.z += cos(n * 6.28) * 0.5;
pos.y = mod(pos.y + t * 0.3, 8.0) - 4.0;  // 循环上升
```
