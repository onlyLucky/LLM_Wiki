## 🎯 核心概念

### 1. SDF（有符号距离场）

SDF = 到最近表面的距离。**有符号**意味着区分内外：
- 正值 = 在物体**外部**
- 负值 = 在物体**内部**
- 零 = 正好在**表面**上

**类比**：闭着眼睛站在房间里，伸手摸墙——你摸到的距离就是 SDF 值。如果你在墙外面，距离为正；在墙里面，距离为负。

```glsl
float sdSphere(vec3 p, float r) {
  return length(p) - r;  // 到球心的距离减去半径
}
```

### 2. Ray Marching 原理

从相机沿光线方向**步进**，每次步进 SDF 距离（这是安全距离——不会穿过表面）。

```glsl
float rayMarch(vec3 ro, vec3 rd) {
  float t = 0.0;
  for (int i = 0; i < 100; i++) {
    vec3 p = ro + rd * t;      // 当前位置
    float d = map(p);           // 到最近表面的距离
    if (d < 0.001) break;      // 够近了 → 击中！
    t += d;                     // 安全步进
    if (t > 50.0) break;       // 太远了 → 没击中
  }
  return t;
}
```

**为什么步进 SDF 距离是安全的？**
- SDF 保证了以当前位置为球心、SDF 为半径的球内**没有任何表面**
- 所以你可以安全地前进 SDF 的距离，不会"穿过"任何东西
- 这就是 Ray Marching 的核心优化——不需要很小的固定步长

### 3. SDF 基本形状

| 形状 | SDF 函数 | 原理 |
|------|----------|------|
| 球体 | `length(p) - r` | 到球心距离减半径 |
| 盒子 | `length(max(abs(p)-b, 0))` | 到盒子边界的距离 |
| 圆环 | `length(vec2(length(p.xz)-R, p.y)) - r` | 到圆环中心线的距离 |

### 4. SDF 布尔运算

```glsl
float opUnion(float d1, float d2) { return min(d1, d2); }
float opSubtraction(float d1, float d2) { return max(-d1, d2); }
float opIntersection(float d1, float d2) { return max(d1, d2); }
```

**类比**：
- 并集（min）= 两个形状取**最近**的表面 → 合并
- 差集（max(-d1, d2)) = 从 d2 中**挖掉** d1（注意方向：第二个参数是被挖的物体，第一个参数是挖具）
- 交集（max）= 只保留**重叠**部分

**为什么三个公式只需要 min 和 max？**

关键在 SDF 的符号约定：**负值 = 在内部**。布尔运算本质上是对「内部区域」做集合运算，而 min/max 恰好对应集合的「或」与「且」。

沿一条同时穿过两个形状的直线看 SDF 值：

```text
d1（球）：  负━━━━━0───────────────────正
d2（盒）：        负━━━━━0─────────────正
──────────────────────────────────────────
min(d1,d2)：负━━━━━━━━━0─────────────正   ← 有一个是负（在某个内部）就是负 → 并集
max(d1,d2)：      负━━━━━0─────────────正   ← 两个都是负（同时在两个内部）才是负 → 交集
max(-d1,d2)：      正━━━━━0─────────────正  ← -d1 把球内外翻转：球内部变正（被排除）→ 差集
```

- **并集 = min**：点在并集内部 = 至少在一个形状内部。min 只要有一个参数为负结果就为负，零等值面自动变成两个形状边界的拼接。
- **交集 = max**：点在交集内部 = 同时在两个内部。max 要求两个参数都为负结果才为负。
- **差集 = max(-d1, d2)**：「在 d2 内部」且「不在 d1 内部」。-d1 把 d1 的符号翻转——原本 d1 内部的负值区域变成正值（视为外部），就被「挖掉」了。这也是为什么差集不需要专门的函数：一个负号就完成了「内外翻转」。

**平滑并集**（Smooth Union）：
```glsl
float opSmoothUnion(float d1, float d2, float k) {
  float h = clamp(0.5 + 0.5 * (d2 - d1) / k, 0.0, 1.0);
  return mix(d2, d1, h) - k * h * (1.0 - h);
}
```
k 控制过渡平滑度：k 越大，两个形状的交界越"融化"。

**本课的演示（四种形态面板切换）**：

`uShapeMode` 切换四种组合：并集（硬拼接）/ 平滑并集（交界融化，默认）/ 交集（只留重叠）/ 差集（球挖盒）。

一个容易踩的坑：**布尔运算要有重叠部分才有可见结果**。并集模式下球和盒子可以相隔一段距离（各自独立），但切到交集时，两个不相交的形状交集是空集——max 结果处处为正，整个物体直接消失。所以本课在交集/差集模式下把挖具球定义在盒子的局部空间里（跟随旋转），半径取盒半边长的 0.6 倍并嵌在盒面上，保证默认参数下就能看到「透镜状交集」和「盒面凹坑」。

### 5. 法线计算（有限差分法）

在击点附近采样 4 次 SDF，用梯度近似法线方向：

```glsl
vec3 calcNormal(vec3 p) {
  vec2 e = vec2(0.001, 0.0);
  return normalize(vec3(
    map(p + e.xyy) - map(p - e.xyy),  // x 方向梯度
    map(p + e.yxy) - map(p - e.yxy),  // y 方向梯度
    map(p + e.yyx) - map(p - e.yyx)   // z 方向梯度
  ));
}
```

### 6. 软阴影

从击点向光源方向步进，检查是否被遮挡。k 控制柔和度。

课程实现（Inigo Quilez 方法）：

```glsl
float softShadow(vec3 ro, vec3 rd, float k) {
  float res = 1.0;
  float t = 0.02;
  for (int i = 0; i < 32; i++) {
    float d = map(ro + rd * t);
    if (d < 0.001) return 0.0;  // 某一步几乎撞上表面 → 光路被完全挡住
    res = min(res, k * d / t);  // 记录全程「离遮挡物最近」的贴近程度
    t += d;                     // SDF 保证按距离 d 步进不会穿透表面
    if (t > 20.0) break;        // 走出检查范围，后面不可能再有遮挡
  }
  return clamp(res, 0.0, 1.0);
}
```

**为什么「沿光线步进的 SDF 最小值」能决定阴影软硬**：半影区的特征是光路没有被完全遮挡，但离遮挡物很近。SDF 返回的正是「离最近表面的距离」，所以每一步记录 `k * d / t`（贴近程度与已走路程之比），`min` 取全程最小值：光路畅通时每步 d 都很大，res 始终接近 1；半影区里没有哪一步真的撞上（不会触发返回 0），但某一步贴着遮挡物掠过、d 很小，res 就被拉向 0；完全挡住则在某步 d < 0.001 直接返回 0。遮挡物边缘因此自然形成 0 到 1 的渐变，这就是软阴影。

**k 控制半影宽度**：同样的贴近距离，k 越大算出的 `k * d / t` 越小，阴影收得越窄越硬（k 趋于无穷就退化为硬阴影）；k 越小半影越宽越软。课程取 `k = 8.0`。调用时先沿法线把起点抬离击点（`p + n * 0.01`），配合 `t = 0.02` 的起步距离，避免把击点所在的表面自己当成遮挡物。合成时阴影同时压暗漫反射和高光：`color = matColor * (0.1 * ao + diff * shadow * 0.8) + spec * shadow * 0.3;`

### 7. 环境光遮蔽（AO）

在击点法线方向多次采样 SDF，距离越近 → 被遮挡越多 → 越暗。

理想情况下 AO 要对击点上方半球的所有方向积分——衡量周围几何挡掉了多少环境光。全算太贵，课程用 Inigo Quilez 的 5 次采样近似：

```glsl
float calcAO(vec3 p, vec3 n) {
  float occ = 0.0;
  float weight = 1.0;
  for (int i = 0; i < 5; i++) {
    float d = float(i) * 0.15;             // 沿法线的 5 个采样高度：0, 0.15, 0.30, 0.45, 0.60
    occ += (d - map(p + n * d)) * weight;  // 实际距离比采样高度小多少，就是被包裹的程度
    weight *= 0.5;                         // 越近的采样层权重越大
  }
  return 1.0 - clamp(occ * 2.0, 0.0, 1.0);
}
```

**原理**：在击点上方沿法线取 5 个高度，各问一次 SDF「这一点离最近表面多远」。周围开阔时，这些点的 SDF 值约等于采样高度本身，`d - map(...)` 接近 0，不产生遮蔽；击点处在角落、缝隙等被包裹的位置时，周围表面把实际距离压得比高度小很多，差值逐层累积、越采越暗。`weight *= 0.5` 让贴近击点的层权重最大——紧挨着的遮挡对视觉影响最大。最后的 `1.0 - clamp(occ * 2.0, ...)` 把累积遮蔽量翻转成 0 到 1 的 AO 系数。

**与阴影的分工**：合成式里 AO 只作用于环境光项（`0.1 * ao`），负责角落和缝隙的「接触变暗」；直接光的明暗交给 softShadow，两者互补。

## 💻 代码实现要点

### 1. 全屏 ShaderMaterial

Ray Marching 不使用 Three.js 几何体，而是用一个覆盖全屏的平面 + 片元着色器。

```typescript
const geometry = new THREE.PlaneGeometry(2, 2)  // NDC 全屏
const material = new THREE.ShaderMaterial({
  vertexShader: rayMarchVertexShader,   // 只做透传
  fragmentShader: rayMarchFragmentShader, // Ray Marching 在这里
})
```

### 2. 场景 SDF（map 函数）

定义整个 3D 场景：多个基本形状通过布尔运算组合。

`uShapeMode` uniform 支持四种布尔形态的面板切换（并集 / 平滑并集 / 交集 / 差集）。交集与差集模式下，挖具球定义在盒子的局部坐标空间（`rotP`）中并跟随盒子旋转——布尔运算需要两形状重叠，否则交集是空集、物体直接消失。

### 3. Gamma 校正

光照在 main() 里按线性空间算完后，最后一步、送进 `gl_FragColor` 之前做 Gamma 校正：

```glsl
color = pow(color, vec3(0.4545));  // 1/2.2
```

**为什么要做**：显示器对输入电压的响应不是线性的，近似幂函数「输出亮度 ≈ 输入^2.2」（CRT 时代的物理特性遗留成了行业标准）。给屏幕送 0.5 的灰，实际显示亮度只有 0.5^2.2 ≈ 0.22，整体被压暗。光照计算在线性空间里是物理正确的，但结果直接送显就会被这条 2.2 次幂曲线压暗，所以输出前先做一次 1/2.2 次幂（0.4545）提亮回来——两头抵消，屏幕上呈现的就是线性计算的本来亮度。

**什么时候会双重校正**：如果输入纹理本身已按 sRGB 编码（颜色值被「压暗」过一次才存进文件），把它当线性数据参与光照、最后再 pow 一次提亮，画面就会整体过亮。正确做法是采样时先解码回线性（或用 sRGB 纹理格式让硬件自动解码），算完在输出端只校正一次。本课没有贴图输入、颜色全部程序化算出，天然是线性值，所以只需要输出端这一次 pow。
