## 核心知识点

### 1. 几何体（Geometry）是什么

几何体定义了物体的**形状**。它由顶点（vertices）和面（faces）组成。

```
几何体 = 顶点坐标 + 面的连接方式
```

Three.js 内置了多种基础几何体，不需要手动定义顶点数据。

### 2. 五种基础几何体

| 几何体 | 用途 | 构造函数 |
|--------|------|----------|
| BoxGeometry | 立方体/长方体 | `new THREE.BoxGeometry(w, h, d)` |
| SphereGeometry | 球体 | `new THREE.SphereGeometry(r, wSeg, hSeg)` |
| CylinderGeometry | 圆柱体/圆锥体 | `new THREE.CylinderGeometry(rTop, rBot, h, seg)` |
| TorusGeometry | 圆环/甜甜圈 | `new THREE.TorusGeometry(r, tube, rSeg, tSeg)` |
| PlaneGeometry | 平面/地面 | `new THREE.PlaneGeometry(w, h, wSeg, hSeg)` |

### 3. 分段数（Segments）— 性能与质量的平衡

分段数决定了几何体的**精细程度**：

| 分段数 | 效果 | 顶点数 | 适用场景 |
|--------|------|--------|----------|
| 低（8） | 粗糙，能看到多边形 | 少 | 低性能设备、像素风格 |
| 中（32） | 圆滑 | 适中 | 大多数场景 |
| 高（64+） | 非常圆滑 | 多 | 特写镜头、高质量渲染 |

**关键原则**：
- 用**最少的分段数**达到**可接受的视觉效果**
- 分段数用 **2 的幂**（8, 16, 32, 64）是一个常见的经验做法，不是硬规则：好处是 LOD 逐级降级时顶点数正好对折（64→32→16→8），过渡整齐；Three.js 内置几何体的默认值也多取 2 的幂（如 SphereGeometry 默认 32×16）。它对画质本身没有额外加成，非 2 的幂（如 30、50）一样能用
- 远处的物体可以用低分段数，近处用高分段数（LOD 策略）

### 4. Wireframe（线框）可视化

```typescript
const material = new THREE.MeshBasicMaterial({ wireframe: true })
```

线框模式可以直观看到几何体的**顶点和面**，用于：
- 调试几何体形状
- 观察分段数的效果
- 做线框风格的视觉效果

### 5. 组合多个几何体

用 `THREE.Group` 或 `scene.add()` 把多个几何体组合在一起：

```typescript
const group = new THREE.Group()
group.add(mesh1)
group.add(mesh2)
group.add(mesh3)
scene.add(group)

// 移动整个组
group.position.x = 5
group.rotation.y = Math.PI / 4
```

### 6. TextGeometry（3D 文字）

3D 文字比内置几何体多两步：字体是**外部数据文件**，要先用 `FontLoader` 异步加载，再交给 `TextGeometry` 生成几何体。

```typescript
import { FontLoader } from 'three/addons/loaders/FontLoader.js'
import { TextGeometry } from 'three/addons/geometries/TextGeometry.js'

const fontLoader = new FontLoader()
fontLoader.load('/fonts/helvetiker_regular.typeface.json', (font) => {
  const textGeometry = new TextGeometry('Three.js', {
    font,             // 异步加载好的字体对象
    size: 1,          // 字号（世界坐标单位）
    depth: 0.4,       // 挤出厚度（r163 前参数名叫 height）
    curveSegments: 8, // 曲线分段数
  })
  scene.add(new THREE.Mesh(textGeometry, material))
})
```

理解要点：
- **它把本课的知识点串起来了**：文字轮廓的圆滑度由 `curveSegments` 控制（分段数思想）；字体文件要异步加载、加载完成前场景照常渲染（资源加载思想，是第 8 课模型加载的预演）
- **挤出（Extrude）**：`depth` 把平面文字「拉」出厚度变成真 3D 物体；开 `bevelEnabled` 倒角后边缘有斜切面，光照下立体感更强
- **原点在左下角**：文字默认以起点为原点向右排，居中要先 `computeBoundingBox()` 算出宽度再平移

## 参数详解

### BoxGeometry

```typescript
new THREE.BoxGeometry(width, height, depth, widthSegments, heightSegments, depthSegments)
```

| 参数 | 默认值 | 说明 |
|------|--------|------|
| width | 1 | X 轴宽度 |
| height | 1 | Y 轴高度 |
| depth | 1 | Z 轴深度 |
| widthSegments | 1 | X 轴分段数 |
| heightSegments | 1 | Y 轴分段数 |
| depthSegments | 1 | Z 轴分段数 |

### SphereGeometry

```typescript
new THREE.SphereGeometry(radius, widthSegments, heightSegments)
```

| 参数 | 默认值 | 说明 |
|------|--------|------|
| radius | 1 | 球体半径 |
| widthSegments | 32 | 水平分段数（经度方向） |
| heightSegments | 16 | 垂直分段数（纬度方向） |

### CylinderGeometry

```typescript
new THREE.CylinderGeometry(radiusTop, radiusBottom, height, radialSegments)
```

| 参数 | 默认值 | 说明 |
|------|--------|------|
| radiusTop | 1 | 顶部半径 |
| radiusBottom | 1 | 底部半径 |
| height | 1 | 高度 |
| radialSegments | 32 | 径向分段数 |

**特殊用法**：
- `radiusTop = 0` → 圆锥体
- `radiusTop = radiusBottom` → 圆柱体
- `radiusTop ≠ radiusBottom` → 圆台

### TorusGeometry

```typescript
new THREE.TorusGeometry(radius, tube, radialSegments, tubularSegments)
```

| 参数 | 默认值 | 说明 |
|------|--------|------|
| radius | 1 | 圆环半径（中心到管中心） |
| tube | 0.4 | 管的粗细 |
| radialSegments | 12 | 径向分段数 |
| tubularSegments | 48 | 管的分段数 |

### PlaneGeometry

```typescript
new THREE.PlaneGeometry(width, height, widthSegments, heightSegments)
```

| 参数 | 默认值 | 说明 |
|------|--------|------|
| width | 1 | 宽度 |
| height | 1 | 高度 |
| widthSegments | 1 | 宽度分段数 |
| heightSegments | 1 | 高度分段数 |

**注意**：Plane 默认在 XY 平面，要做地面需要旋转：
```typescript
plane.rotation.x = -Math.PI / 2  // 旋转到水平
```

### TextGeometry

```typescript
new TextGeometry(text, {
  font,              // FontLoader 加载的字体（必填，没有它只会得到默认挤出体）
  size,              // 字号，默认 100
  depth,             // 挤出厚度（r163 前叫 height），默认 50
  curveSegments,     // 曲线分段数，默认 12
  bevelEnabled,      // 是否倒角，默认 false
  bevelThickness,    // 倒角厚度（挤出方向），默认 10
  bevelSize,         // 倒角宽度（轮廓向外扩），默认 8
  bevelSegments,     // 倒角分段数，默认 3
})
```

**注意**：默认值是按「size 100」的字体坐标系设计的。当 `size: 1`（世界坐标）时，`depth`、`bevelThickness`、`bevelSize` 也要按同比例缩小（如 0.4、0.04、0.02），否则倒角会比笔画还宽。

## 常见错误

1. **分段数太高**：球体用 128×128 分段，性能浪费。通常 32×16 足够。
2. **分段数太低**：球体用 4×4 分段，看起来像多面体，不圆滑。
3. **忘记旋转 Plane**：Plane 默认垂直，做地面需要 `rotation.x = -Math.PI/2`。
4. **不理解 segments 参数顺序**：SphereGeometry 的 widthSegments 是水平方向，heightSegments 是垂直方向。
5. **几何体和材质混淆**：Geometry 只定义形状，Material 定义外观，两者分开。
6. **TextGeometry 用旧参数名 height**：r163 起改名 `depth`，写 `height` 会被静默忽略——文字变成没有厚度的薄片。同样的问题：`size: 1` 时倒角参数不缩水，倒角会宽过笔画。

## 代码示例

### 创建一个球体

```typescript
const geometry = new THREE.SphereGeometry(1, 32, 16)
const material = new THREE.MeshStandardMaterial({ color: 0x4488ff })
const sphere = new THREE.Mesh(geometry, material)
scene.add(sphere)
```

### 创建一个低分段线框球体

```typescript
const geometry = new THREE.SphereGeometry(1, 8, 4)
const material = new THREE.MeshBasicMaterial({ wireframe: true, color: 0xffd43b })
const wireSphere = new THREE.Mesh(geometry, material)
scene.add(wireSphere)
```

### 组合多个几何体

```typescript
const group = new THREE.Group()

const box = new THREE.Mesh(new THREE.BoxGeometry(1, 1, 1), material)
const sphere = new THREE.Mesh(new THREE.SphereGeometry(0.5, 32, 16), material)

group.add(box)
group.add(sphere)
sphere.position.x = 2  // 相对于 group 的位置

scene.add(group)
group.position.set(0, 1, 0)  // 移动整个组
```

### 创建 3D 文字

```typescript
import { FontLoader } from 'three/addons/loaders/FontLoader.js'
import { TextGeometry } from 'three/addons/geometries/TextGeometry.js'

// 字体加载是异步的：加载期间场景照常渲染，完成后才 add 文字
new FontLoader().load('/fonts/helvetiker_regular.typeface.json', (font) => {
  const geometry = new TextGeometry('Three.js', {
    font,
    size: 1,
    depth: 0.4,
    curveSegments: 8,
    bevelEnabled: true,
    bevelThickness: 0.04,
    bevelSize: 0.02,
  })
  geometry.computeBoundingBox()
  const b = geometry.boundingBox!
  geometry.translate(-(b.max.x - b.min.x) / 2, 0, 0) // 水平居中

  const material = new THREE.MeshStandardMaterial({ color: 0xffd43b, metalness: 0.6, roughness: 0.35 })
  const text = new THREE.Mesh(geometry, material)
  text.position.set(0, 2.5, 0)
  scene.add(text)
})
```
