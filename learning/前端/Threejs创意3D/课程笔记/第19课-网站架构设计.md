## 🎯 核心概念

### 1. 多场景管理架构

每个场景是独立的 `Scene3D` 对象，包含独立的 Scene、Camera、update 和 dispose。

```typescript
interface Scene3D {
  scene: THREE.Scene
  camera: THREE.PerspectiveCamera
  update: (time: number) => void
  dispose: () => void
}
```

**类比**：电视频道——每个频道有自己的节目（场景），遥控器（管理器）负责切换。切换时旧频道停止播放，新频道开始播放。

### 2. 场景切换过渡（淡入淡出）

用一个黑色 DOM overlay 覆盖 canvas，通过 opacity 实现淡入淡出。

```typescript
overlay.style.opacity = '1'  // 淡出（黑色覆盖）
await sleep(500)
currentScene = newScene       // 切换
overlay.style.opacity = '0'  // 淡入（露出新场景）
```

### 3. dispose 防止内存泄漏

Three.js 不会自动释放 GPU 资源，必须手动 dispose。

**需要释放的资源**：
| 资源 | 释放方法 | 忘记释放的后果 |
|------|----------|---------------|
| 几何体 | `geometry.dispose()` | GPU 顶点缓冲区泄漏 |
| 材质 | `material.dispose()` | Shader 程序泄漏 |
| 纹理 | `texture.dispose()` | GPU 纹理内存泄漏 |
| 渲染目标 | `renderTarget.dispose()` | 帧缓冲区泄漏 |

### 4. 预加载 vs 按需加载

| | 预加载 | 按需加载 |
|--|--|--|
| 首次加载 | 慢（加载所有） | 快（只加载当前） |
| 切换体验 | 快（已缓存） | 慢（需等待） |
| 带宽 | 高（可能浪费） | 低（按需） |
| 适用 | 小项目、资源少 | 大项目、资源多 |

**50MB × 5 页面的例子**：
- 预加载：首次加载 250MB（浪费 150MB）
- 按需加载：只加载访问的 100MB
