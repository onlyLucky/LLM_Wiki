## 🎯 核心概念

### 1. GLTF 格式详解

**GLTF vs GLB**：

| 格式 | 说明 | 适用场景 |
|------|------|----------|
| GLTF | JSON 文本，资源分散（.gltf + .bin + 纹理） | 开发调试 |
| GLB | 二进制，单文件包含所有资源 | 生产环境 |

**GLTF 文件结构**：
```
scene.gltf          # JSON 主文件（场景描述）
scene.bin           # 二进制数据（顶点、索引）
texture.png         # 纹理文件
```

### 2. GLTFLoader 使用

**基础加载**：
```typescript
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js'

const loader = new GLTFLoader()
loader.load('/models/suzanne.glb', (gltf) => {
  scene.add(gltf.scene)
})
```

**LoadingManager 统一进度管理**：
```typescript
const manager = new THREE.LoadingManager()
manager.onProgress = (url, loaded, total) => {
  console.log(`${(loaded / total * 100).toFixed(0)}%`)
}
manager.onLoad = () => { /* 全部加载完成 */ }

// 传给 loader 后，进度自动报告给 manager
const loader = new GLTFLoader(manager)
```

**关键**：LoadingManager 必须传给 Loader 构造函数，否则 `onLoad` 不会触发。

### 3. Draco 压缩

**原理**：Google 的 3D 几何压缩库，通过量化、预测和熵编码压缩顶点数据，可减小 90%+ 文件大小。

```typescript
import { DRACOLoader } from 'three/addons/loaders/DRACOLoader.js'

const dracoLoader = new DRACOLoader()
dracoLoader.setDecoderPath('https://www.gstatic.com/draco/versioned/decoders/1.5.6/')
loader.setDRACOLoader(dracoLoader)
```

**压缩效果**：

| 模型 | 原始大小 | Draco 压缩后 | 压缩率 |
|------|----------|--------------|--------|
| Damaged Helmet | 4.2 MB | 0.8 MB | 81% |
| Flight Helmet | 5.1 MB | 1.2 MB | 76% |

### 4. 模型自动缩放和居中

**问题**：不同来源的模型尺寸差异很大（0.01 ~ 100 单位），需要统一处理。

**算法**：
```typescript
// 1. 计算包围盒
const box = new THREE.Box3().setFromObject(model)
const size = box.getSize(new THREE.Vector3())

// 2. 计算缩放比例（目标大小约 3 个单位）
const maxDim = Math.max(size.x, size.y, size.z)
const scale = targetSize / maxDim
model.scale.setScalar(scale)

// 3. 重新计算包围盒并居中
const newBox = new THREE.Box3().setFromObject(model)
const newCenter = newBox.getCenter(new THREE.Vector3())
model.position.sub(newCenter)
```

**关键**：缩放后必须重新计算包围盒再居中，因为 `scale` 改变了世界坐标。

### 5. LOD（Level of Detail）

**原理**：根据物体与相机的距离，自动切换不同精度的模型。

```typescript
const lod = new THREE.LOD()
lod.addLevel(highPoly, 0)    // 0-20 米：高精度
lod.addLevel(mediumPoly, 20) // 20-50 米：中精度
lod.addLevel(lowPoly, 50)    // 50+ 米：低精度
scene.add(lod)
```

**适用场景**：大场景中的远景物体，减少渲染开销。

### 6. AnimationMixer 动画播放

**AnimationMixer**：动画混合器，管理模型的所有动画。

```typescript
const mixer = new THREE.AnimationMixer(model)
const action = mixer.clipAction(gltf.animations[0])
action.play()

// 动画循环中更新
mixer.update(delta)
```

**AnimationAction 控制**：
```typescript
action.setLoop(THREE.LoopRepeat, Infinity)  // 循环播放
action.setLoop(THREE.LoopOnce, 1)           // 播放一次
action.timeScale = 2.0                       // 2 倍速
action.fadeIn(0.3)                           // 淡入
action.fadeOut(0.3)                          // 淡出
```

## 💻 代码实现要点

### 1. LoadingManager 与进度条

```typescript
// 创建 LoadingManager 并绑定 UI
const loadingManager = createLoadingManager()
const gltfLoader = createGLTFLoader(loadingManager)

// LoadingManager 必须传给 Loader
function createGLTFLoader(manager?: THREE.LoadingManager) {
  return manager ? new GLTFLoader(manager) : new GLTFLoader()
}
```

**进度条 UI**：
- 默认 `display: none`（不影响其他课程）
- 第 8 课启动时 `display: flex`
- `onLoad` 触发后 opacity → 0 → `display: none`

### 2. GLTFLoader + DRACOLoader

```typescript
const dracoLoader = new DRACOLoader()
dracoLoader.setDecoderPath('https://www.gstatic.com/draco/versioned/decoders/1.5.6/')
loader.setDRACOLoader(dracoLoader)
```

**注意**：Draco 解码器从 CDN 加载，不需要本地文件。

### 3. 模型加载与自动处理

```typescript
loader.load('/models/suzanne.glb', (gltf) => {
  const model = gltf.scene

  // 自动缩放
  const box = new THREE.Box3().setFromObject(model)
  const maxDim = Math.max(box.getSize().x, box.getSize().y, box.getSize().z)
  model.scale.setScalar(targetSize / maxDim)

  // 自动居中
  const newBox = new THREE.Box3().setFromObject(model)
  model.position.sub(newBox.getCenter(new THREE.Vector3()))

  // 阴影设置
  model.traverse((child) => {
    if (child instanceof THREE.Mesh) {
      child.castShadow = true
      child.receiveShadow = true
    }
  })

  scene.add(model)
})
```

### 4. AnimationController 封装

```typescript
class AnimationController {
  private mixer: THREE.AnimationMixer
  private actions: Map<string, THREE.AnimationAction> = new Map()

  play(name: string, options = {}) {
    const action = this.actions.get(name)
    action.reset()
    action.setLoop(THREE.LoopRepeat, Infinity)
    action.fadeIn(0.3)
    action.play()
  }

  update(delta: number) {
    this.mixer.update(delta)
  }
}
```
