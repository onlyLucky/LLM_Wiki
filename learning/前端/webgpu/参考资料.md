# 参考资料

这份清单按四个阶段分层：入门（建立全景、跑通第一个例子）、系统（完整过一遍知识体系）、深入（性能与底层、面向能上线的产品）、工具（写代码时开着随时查）。用法对应课程的节奏：Day 1 之前只看入门层，Day 1–2 期间用系统层补语言细节，Day 3 靠工具层查 API，结营后进入深入层。表格的「适合阶段」一列写的是建议的引入时间，不是硬性顺序——卡住的时候往上一层翻，比硬啃更快。

注意一件事：TSL 迭代很快，教程与论坛帖子里的写法可能与课程锁定的 three 0.186.0 有出入（讲义 3.1 的「TSL API 变更注记」专门讨论过）。查任何 TSL 资料时，先对齐版本号再抄代码。

## 入门

第一次接触 WebGPU，目标是建立全景认知并跑通第一个例子，不追求覆盖每个 API。

| 名称 | URL | 一句话定位 | 适合阶段 |
|------|-----|-----------|---------|
| WebGPU 官方社区站 | https://webgpu.org/ | 标准与生态的门面：FAQ、浏览器支持动态、官方演示集散地 | Day 1 之前 |
| MDN WebGPU API | https://developer.mozilla.org/en-US/docs/Web/API/WebGPU_API | API 字典，每个接口的类型定义与兼容性表格，查参数首选 | 全程 |
| WebGPU 官方示例集 | https://webgpu.github.io/webgpu-samples/ | 工作组维护的可运行示例，从 hello triangle 到 compute 全有源码 | Day 1–2 |
| ICS MEDIA「WebGPU 対応 Three.js のはじめ方」 | https://ics.media/entry/250501/ | 日文社区质量最高的 three.js + WebGPU 上手教程，配图完整（另有英文版） | Day 3 入口 |

## 深入

面向「能上线的产品」：性能、后端差异、以及从原生走向 TSL 的完整桥。

| 名称 | URL | 一句话定位 | 适合阶段 |
|------|-----|-----------|---------|
| Raw WebGPU | https://alain.xyz/blog/raw-webgpu | Alain Galvan 对裸 WebGPU 管线的深入拆解，图像质量与同步语义讲得比入门资料深一层 | Day 2 后 |
| toji.dev WebGPU Best Practices | https://toji.dev/webgpu-best-practices/ | Chrome WebGPU 团队成员 Brandon Jones 的实践系列：buffer 上传时机、bind group 用法、错误处理各一篇，讲义 1.1 / 2.6 有引用 | Day 3 / 结营后 |
| WWDC25 Session 236 · Unlock GPU computing with WebGPU | https://developer.apple.com/videos/play/wwdc2025/236/ | Safari 团队讲解 WebGPU 如何映射到 Metal，演示案例就是清单里的 Aurelia 水母 | 结营后 |
