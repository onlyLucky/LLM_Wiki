## 实现要点

- 环带几何（任务 1）：下标编排「内圈 k → `2k`、外圈 k → `2k + 1`」，同角度的内外两点相邻存放；每条边由 `(内k, 内n, 外n)` 与 `(内k, 外n, 外k)` 两个三角形拼成四边形，`n = (k + 1) % 6` 收口成闭合六边形
- `rotation2D`（任务 2）：列主序 9 个数 `[c, s, 0, -s, c, 0, 0, 0, 1]`——列 0、列 1 是旋转，列 2 保持 (0, 0, 1)
- 矩阵上传（任务 3）：`mat3x3f` 在 uniform 地址空间按 **16 字节列步进** 存放，9 个数要写进 `0–2 / 4–6 / 8–10` 号 float 槽位，3、7、11 是空洞；均匀缩放直接乘进前两列（`i < 6` 的那 6 个数），第三列不动
- 呼吸缩放（任务 4）：`1 + 0.05 * sin(t * 1.2)`，与旋转共用同一时间轴；vs 里 `u.model * vec3f(vin.position, 1.0)` 应用矩阵后再乘 `vec2f(u.aspect, 1.0)`

**实测证据**：本仓库的浏览器实验（SwiftShader + 读回像素）确认 uniform 里 `mat3x3f` 三列分别读 float 下标 `[0,1,2]`、`[4,5,6]`、`[8,9,10]`。README 提示三里 `uniforms.set(九个数, 0)` 的连续写法会把列 1 的首元素掉进列 0 的填充洞——照抄会得到变形的碎环，跳槽位写才是对的。

## 与骨架的差异

- `buildHexRing()`：填入 12 顶点 × 5 float 与 36 索引的生成逻辑（任务 1）
- `rotation2D()` / `breatheScale()`：填入列主序矩阵与呼吸系数（任务 2 / 4）
- 帧循环：补矩阵写入与 `writeBuffer`（任务 3）——注意答案是**跳槽位写**而非 README 提示里的连续 `set`
- 加分项：新增 `mouseX` 监听与 `uniforms[13]`（字节 52），`hex.wgsl` 的 struct 加 `mouse: f32` 字段、fs 加 ±8% 亮度扰动；骨架 struct 只有 `model + aspect`，这 4 字节是答案追加的
- 其余脚手架（管线、绑定组、drawIndexed 调用）与骨架逐字一致

## 视觉规格

- 色板：内圈电蓝 `#4C6FFF` → 外圈紫 `#8B5CF6` 的径向渐变，三角化后插值平滑
- 动效：每秒 0.6 rad 持续旋转 + ±5% 呼吸缩放（约 5.2 秒一个周期）
- 加分项：鼠标横移 ±8% 亮度扰动
- 底色：`clearValue` `#0B0E14`，环带居中，内外半径 0.25 / 0.62
