## 实现要点

- `lineTopology()` 返回 `'line-list'`（任务 1）：每 2 个连续顶点连一条线段，所以一段弧是「段数 × 2 个端点」
- 数据组织（任务 2）：每顶点 8 个 float `[x, y, r, g, b, arcT, band, seed]`，stride 32 字节。外层循环 5 条轨道带（半径 0.10→0.58）、内层循环每带 12~20 颗星；每颗星半径带内微扰 ±0.015、起角随机、弧长双峰分布——80% 短弧 0.08~0.22 圈（扫过即逝的暗星）+ 20% 长弧 0.45~0.70 圈（曝光最久的主星），节奏有断有连，避免「规整圆环」的机械感；段数按弧长配平（约每 0.02 单位一段），1080p 下折线圆滑无折角。`mulberry32` 固定种子——每次刷新构图完全一致，像同一张长曝光照片
- 色温纵深（任务 2）：按带从暖金 `#FFD194` 滑向冷蓝 `#7AA8FF`（内带老星、外带年轻星），每星再微扰 ±0.04；18% 的亮星往白里混 55%
- 绕极点旋转（任务 3）：极点 `POLE = (0.30, 0.18)`（半屏高单位）放在画面右上 1/3——偏心构图是星轨摄影的经典；`spin = time × (0.05 + 0.028 × (4 − band))` 内带快外带慢，漩涡式的旋转层次；旋转在半屏高单位空间做（等距空间），标准 2D 旋转公式乘 `position − POLE`，出口统一 `toNdc()`（x **除以** aspect）——半径在 x、y 两向换算成像素等距，轨道才是屏幕上的正圆；buffer 里的数据一个字节都不动
- 视差 + 渐隐 + 闪烁（任务 4）：视差幅度 `0.3 + 0.7 × band / 4` 外带更大；`arcT` 的双 smoothstep（0.22 / 0.78）让弧线头尾渐隐（长曝光的起止感）；每星按自己的种子以 0.5~2.2 rad/s 缓慢闪烁；外带亮度再压 22%，纵深多一档
- 彩蛋（作业侧已写好）：极点处八向金色星芒（4 长 4 短、慢旋呼吸）；流星是 buffer 里的一条对角线段（`seed = −1` 标记），着色器拿 `fract(time / 9)` 把它变成每 9 秒划过一次的流星——顶点的最终位置不必与 buffer 里的位置有任何关系
- 氛围层（答案专属加分）：`fs` 里以 `ndc` varying 拿到逐像素坐标——极点方向的微弱天光（`exp(−d × 2.4) × 0.30`，单位空间测距、光晕是正圆）+ 四角压暗的暗角，让「线段画」长出「照片感」
- 混色：`fs` 里 `mix(BG, color, alpha)` 混回底色，`BG` 与 `clearValue` 逐字一致（`#070A12`），渐隐的弧线像融进夜空而不是淡入灰雾

## 与骨架的差异

- `lineTopology()`：返回 `'line-list'`（任务 1）
- `buildStarTrails()`：填入固定种子 PRNG + 5 带 × 星弧 + 极星 + 流星的生成逻辑（任务 2）
- `trails.wgsl` 的 `vs` 星轨弧分支：填入绕极点旋转 / 视差 / 渐隐 / 闪烁（任务 3、4）
- 流星与极星分支骨架里已写全（彩蛋）：数据到位（`seed = −1`、`band = 5`）即点亮
- `fs` 氛围层（天光 + 暗角）与 `ndc` varying：答案在骨架之上追加的加分体验，作业骨架不含
- 其余脚手架（8 float attribute 布局、uniform、鼠标监听、帧循环）与骨架逐字一致

## 视觉规格

- 构图：极点在半屏高单位 `(0.30, 0.18)`，弧心偏右、左下留白——星轨摄影的经典画面；所有几何（弧 / 星芒 / 流星端点）统一在半屏高单位空间推导，唯一出口 `toNdc()`
- 色板：内带暖金 → 外带冷蓝的色温纵深，亮星偏白，极星金白 `#FFEBBF`，流星冷白青
- 动效：转速 0.05–0.16 rad/s 内快外慢；每星 0.5–2.2 rad/s 低频闪烁；极星 8 芒 1.3 rad 呼吸慢旋；流星每 9 秒一颗、1.26 秒飞完
- 视差：鼠标满幅移动时外带位移约 0.055 NDC
- 底色：`clearValue` `#070A12` 深空蓝黑
- 顶点量：约 4800 顶点 / 80 段弧共约 2400 段 × 2 + 16 极星 + 2 流星，单 buffer 一次写入
