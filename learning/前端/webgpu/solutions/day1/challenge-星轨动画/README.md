# 作业 C 参考答案 · 星轨动画

## 运行

```bash
npm run dev
# http://localhost:5173/solutions/day1/challenge-星轨动画/index.html
```

## 实现要点

- `lineTopology()` 返回 `'line-list'`（任务 1）：每 2 个连续顶点连一条线段，所以一个 90 段的圆要放 90 对端点，不是 90 + 1 个顶点
- 数据组织（任务 2）：外层循环环号、内层循环段号，每段推入角度 `a` 与 `a + 4°` 两个端点；`Float32Array(6 × 90 × 2 × 5)` 单 buffer 装下 1080 个顶点；颜色按环号 `r / 5` 在紫与青之间取插值——插值系数只依赖环号，所以同环整圈同色
- 着色器推导（任务 3）：每环固定 180 个顶点，`ring = i / 180u` 整除切环号；`speed = 0.10 + 0.06 * f32(ring)` 内慢外快；`select(-1.0, 1.0, (ring % 2u) == 0u)` 逐环反转方向；旋转就是标准 2D 旋转公式乘原始位置——buffer 里的数据一个字节都不动
- 视差（任务 4）：`u.mouse * (0.01 + 0.012 * f32(ring))`，外环幅度更大，鼠标一动近环小移、远环大移，深度感就出来了

## 与骨架的差异

- `lineTopology()`：返回 `'line-list'`（任务 1）
- `buildStarRings()`：填入 6 环 × 90 段的双端点生成逻辑（任务 2）
- `trails.wgsl` 的 `vs`：填入环号 / 转速 / 反向 / 旋转 / 视差推导（任务 3、4）
- 其余脚手架（uniform 布局、鼠标监听、帧循环）与骨架逐字一致——`fs` 保持骨架原样（顶点色插值即是线色）

## 视觉规格

- 色板：内环紫 `#8B5CF6` → 外环青 `#2DD4BF` 的单向径向过渡，六环同屏
- 半径：0.16 起步、每环 +0.13，最外环 0.81；90 段的圆在 1080p 下无可见折角
- 动效：转速 0.10–0.40 rad/s 递增，偶数环顺时针、奇数环逆时针
- 视差：鼠标满幅移动时外环位移约 0.07 NDC（1% + 0.012 × 环号）
- 底色：`clearValue` `#0B0E14`，星轨居中
