# Day 1 · A 进阶 参考实现 —— 万花筒

对应作业：`homework/day1/advanced-万花筒/`（四个 TODO 全部就位的对照版）。

## 实现要点

1. **uniform 填充槽**（1.6 的坑二次巩固）：`time`(f32) 之后是 `mouse`(vec2f)，vec2f 要求 8 字节对齐——JS 侧写 `[0]`、`[2]`、`[3]`、`[4]`，`[1]` 是洞，跳过。
2. **折叠三步**（`fold`）：`theta % period` 取周期 → `abs` 把负半边镜像折正 → `min(a, period - a)` 折回楔形。八重对称的本质：每个像素只归属 1/8 圆的楔形，其余 7 份都是它的镜像。
3. **边界无缝的条件**：楔形里花纹 `sin(folded * 24.0)` 的 24 是 segments(8) 的整数倍——`fold(0)` 与 `fold(period/2)` 处花纹值相等，镜像拼合处才不会出现放射硬边。换折数时同步换瓣数。
4. **aspect 校正**：uv 乘 aspect 后除以对角线长度 `length(vec2f(aspect, 1.0))`，角落半径恰好为 1——画布拉成任何宽高比，中心圆都是圆。
5. **分层出设计感**：半径方向叠三层节奏（细年轮向外流 / 宽环带慢呼吸 / 中心辉光衰减），角向一层花瓣（pow 锐化成放射），再加外缘余晖。色温由鼠标横移在电蓝与品红金之间插值，纵移调花瓣锐度——克制两三个颜色，不用彩虹。
