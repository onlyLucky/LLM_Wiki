# Demo 07 · Raymarching

对应讲义：`2.8 光线追踪与 Ray Marching`

## 运行

```bash
npm run dev
# http://localhost:5173/demos/day2/07-raymarching/index.html
```

## 关键点

- 全屏大三角形（讲义 2.8）：顶点 `(-1,-1) (3,-1) (-1,3)`，裁剪后恰好覆盖屏幕，比两个三角形拼 quad 少一次对角插值；NDC 从 vs 直接传到 fs 做射线
- 相机射线在片元里构建：`fwd/right/up` 基 + `tan(半视野角)`，鼠标 NDC 环绕方位角与俯仰（幅度 ±0.55 / ±0.18 rad）
- SDF 场景：无限地面 `p.y` + 圆角盒与三个球的 `smin` 融合雕塑；`map` 返回 `(距离, 材质)` 二元组
- 步进核心：`t += map(p)`（到最近表面的距离就是安全步长），命中判据 `d < 0.001·t`，90 步上限 + 22 距离上限
- 光照件：四面体差分法线、软阴影（`min(res, h/(k·t))`）、AO（沿法线 4 次抬升采样）、`exp(-0.028·t²)` 距离雾、`pow(col, 1/2.2)` 伽马

## 视觉规格

- 构图：极简雕塑展台——冷白灰雕塑立于深蓝灰地面，电蓝主光 + 琥珀补光 + 地面电蓝辉光环，深空底渐变与星点
- 色板：电蓝主光 `#4C6FFF` 系、琥珀补光 `#F59E0B` 系、雕塑 `#9EA8C2`、地面 `#0E1320`、雾色 `#050710`
- 交互：鼠标环绕相机（方位 ±0.55 rad、俯仰 ±0.18 rad），另有 0.05 rad 的缓慢漂移
- 命中判据用相对误差 `0.001·t`：远处表面步进更大也不闪烁

## 常见报错

| 报错 | 原因 |
|------|------|
| 只画出一个三角形/半屏 | 大三角形顶点写成 `(-1,-1) (1,-1) (1,1)` 这类普通全屏 quad 尺寸，没「伸出」NDC 范围 |
| 画面整体过曝、阴影发灰 | 射线方向没 `normalize`，`march` 命中距离与光照计算全乱了 |
| 远处地面有噪点闪烁 | 步数上限太小（< 60）或命中阈值太小，步进没走到就放弃；地面掠射角本就费步数 |
| 雕塑边缘锯齿明显 | 法线差分步长 `e` 过大；0.001~0.002 之间微调 |
