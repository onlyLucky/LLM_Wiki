# Demo 07 · Raymarching —— 熔核图腾

对应讲义：`2.8 光线追踪与 Ray Marching`

## 运行

```bash
npm run dev
# http://localhost:5173/demos/day2/07-raymarching/index.html
```

## 关键点

- 全屏大三角形（讲义 2.8）：顶点 `(-1,-1) (3,-1) (-1,3)`，裁剪后恰好覆盖屏幕；NDC 从 vs 直接传到 fs 做射线
- 相机射线在片元里构建：`fwd/right/up` 基 + `tan(半视野角)`，低机位仰视 + 鼠标环绕（±0.45 / ±0.12 rad）+ 0.04 rad 缓慢漂移
- SDF 场景：无限地面 `p.y` + 五颗球的 `smin` 融合图腾（k=0.10→0.07 自下而上收紧，缩腰分节）+ 悬浮圆环（`sdTorus`，绕 x 轴微倾摇摆）；球心水平漂移刻意压小（0.06~0.10，珠心贴近中轴）、半径呼吸全是低频动画，SDF 保持光滑解析，步进不穿透
- **伪次表面散射**（本 demo 的招牌技法）：熔核不进 `map`（藏在图腾内部，march 永远碰不到），着色时用 `sdCore(p)` 计算表面到熔核柱心的距离——熔核是**恒定半径 0.18** 的竖直柱心（呼吸 ±0.03），透光强度 = 壁厚项 `exp(-14·max(sdCore,0))` × **五个珠心高斯权重** `exp(-22·(p.y-yi)²)`（把透光限制在每颗珠的赤道带，缩腰处趋零）× `sin(t·1.05)` 呼吸脉动，黑曜石内部像揣着一颗活的心脏
- **黑曜石着色**：低反照率 `(0.04,0.05,0.08)` + 冷白主光 + Blinn-Phong 窄高光（pow 60）+ 窄菲涅尔青轮廓（pow 4.5）——石头感全靠「低漫反射 + 高光点 + 细轮廓光」三件套
- **平面伪镜面反射**：地面命中后把射线按法线翻折再 march 一次（小预算：44 步 / 9 距离上限 / 省掉阴影与 AO），反射强度用菲涅尔 `pow(1-cosθ, 3)` 掠射增强——黑地面把图腾与熔光「倒」进来
- 步进核心：`t += map(p)`（到最近表面的距离就是安全步长），命中判据 `d < 0.001·t`；`march` 参数化 `maxT/maxSteps`——主射线 90 步 / 22 距离，反射射线 44 步 / 9 距离
- 光照件：四面体差分法线、软阴影（`min(res, h/(k·t))`）、AO（沿法线 4 次抬升采样）、`exp(-0.024·t²)` 距离雾、`pow(col, 1/2.2)` 伽马
- **青金双色分级**（split-toning）：按亮度 `lum` 把暗部乘偏青 `(0.82, 0.94, 1.18)`、高光乘偏金 `(1.14, 1.00, 0.80)`，再加暗角——一张图的「电影感」多半来自这一步

## 视觉规格

- 构图：低机位仰拍，黑曜石图腾纵贯画面中央、悬浮细环缠绕，熔光在黑地面拉出倒影与近地光晕
- 色板：熔橙 `#FF6B24`（透光主角）、冷青 `#29A0D9`（轮廓光）、黑曜石 `#171A21`、深空底 `#020508`
- 动效：球链漂移与半径呼吸（0.4~0.9 rad/s）、熔核脉动（1.05 rad/s）、细环摇摆（0.4 rad/s）、相机漂移、细网格圆点星闪烁——静中有活
- 纵向温度梯度：顶部珠径小壁薄自然「熔透」暖橙、底部珠保持黑曜石冷黑剪影——层次本身即设计语言
- 命中判据用相对误差 `0.001·t`：远处表面步进更大也不闪烁

## 常见报错

| 报错 | 原因 |
|------|------|
| 只画出一个三角形/半屏 | 大三角形顶点写成 `(-1,-1) (1,-1) (1,1)` 这类普通全屏 quad 尺寸，没「伸出」NDC 范围 |
| 画面整体过曝、阴影发灰 | 射线方向没 `normalize`，`march` 命中距离与光照计算全乱了 |
| 透光效果不显示 | `sdCore` 返回的是「到熔核表面的有符号距离」，透光公式要取 `max(d, 0)` 再做 `exp(-k·d)`；方向反了表面永远全亮或全黑 |
| 反射图像上下颠倒 | 反射射线要用 `rd - 2·dot(rd,n)·n` 翻折后再从命中点偏移 `n·ε` 出发，直接用原射线会穿回地面 |
| 远处地面有噪点闪烁 | 步数上限太小（< 60）或命中阈值太小，步进没走到就放弃；地面掠射角本就费步数 |
| 雕塑边缘锯齿明显 | 法线差分步长 `e` 过大；0.001~0.002 之间微调 |
