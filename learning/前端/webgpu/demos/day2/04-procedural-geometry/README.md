# Demo 04 · Procedural Geometry

对应讲义：`2.5 几何生成与顶点动画`

## 运行

```bash
npm run dev
# http://localhost:5173/demos/day2/04-procedural-geometry/index.html
```

## 关键点

- 格点平面由双层循环生成（讲义 2.5 参数化几何）：顶点只存 `(x, z)` 两个 float，高度是时间函数放进顶点着色器，网格数据保持静态不用重传
- 索引缓冲把 16641 个顶点组织成 32768 个三角形：每格两个三角形、六个索引，`uint16` 刚好装下（顶点数 < 65536）
- 波浪是三组正弦叠加；波场函数 `waveField` 同时返回高度与两个偏导，法线用解析梯度 `normalize(-dh/dx, 1, -dh/dz)` 重建（讲义 2.5 的法线策略一）
- 鼠标波源：JS 侧把 NDC 沿相机射线与地平面求交（不需求逆矩阵），世界坐标经 uniform 传入，环形波 `sin(d·k − ωt)·exp(-d·σ)` 从光标扩散
- 片元里做 Blinn 高光 + 菲涅尔 + 距离雾，雾色与画布底色一致，隐藏网格边界

## 视觉规格

- 构图：42° 透视俯视的海面，电蓝主浪 + 交叉浪 + 斜向细浪，鼠标是波源
- 色板：波谷深海底 `#04121F` → 电蓝 `#4C6FFF` → 波峰青 `#2DD4BF`，按波高映射
- 光照：左上方向光（暖白）+ Blinn 高光 + 菲涅尔边缘；距离雾 `smoothstep(3.2, 8.2)` 渐隐到 `#0B0E14`
- 交互：波源平滑跟随鼠标（lerp 0.14），涟漪幅度 0.22、衰减系数 1.4

## 常见报错

| 报错 | 原因 |
|------|------|
| `float32x2` 顶点出现拉扯的三角形 | `arrayStride` 忘了写 8，或顶点数组长度与 `ROW²·2` 不符 |
| `Index buffer index is out of bounds` | 索引值 ≥ 顶点数；129² = 16641 没超 65535，改大 SEG 前先换 `uint32` |
| 海面一片死灰、高光位置诡异 | 法线没随位移更新（还在用平面朝上的 `(0,1,0)`），见讲义 2.5 常见坑 |
| 波纹在屏幕角落疯狂抖动 | 鼠标射线掠过地平面（`dir.y` 接近 0），交点飞到无穷远；保留上一次有效波源 |
