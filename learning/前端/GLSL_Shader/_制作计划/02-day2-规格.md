## 讲义 2.1 像素级绘画：step、smoothstep 与 SDF 形状

```markdown
# 2.1 像素级绘画：从 step 到符号距离场

> Day 2 · 模块 1 · 约 55 分钟
> 理论对照：《GAMES101》光栅化章节——「屏幕上没有形状，只有像素」的硬件视角；本篇讲的是软件视角：每个像素自己判断「我在不在形状里」
```

**章节大纲**：
- 导语：昨天你的画面是渐变——连续的、没有边界的东西。今天开始画「有边界的形状」：按钮、徽章、图案、文字轮廓，全从这一讲的三个函数长出来
- `## step：一刀切出的边界`：`step(edge, x)` 语义（x ≥ edge 为 1）；代码段：用 `step` 画半屏、画矩形边框（四次 step 相乘——「乘法是 AND」）；**为什么不写 if**（分支发散 + 无法抗锯齿，1.1 讲的老朋友）
- `## smoothstep：给边界一条 1px 的过渡带`：三参数语义；代码段：把 step 版矩形升级成柔和边界；`smoothstep` 与 fwidth 的配合（过渡带宽 = `fwidth(d)`，屏幕空间导数——**为什么它天生抗锯齿**）
- `## SDF：一个返回「距离」的函数`：定义 `float sd = length(p) - r;`——负值在形状内、零在边界、正值在外（svg：sdf-distance-field 等值线图）；「SDF 就是一个 TypeScript 函数：输入坐标，返回离形状多远——只不过每个像素并发调用它」；**为什么用距离而不是布尔**：距离可插值、可缩放、可 smooth、可发光——「布尔只能回答是与否，距离回答了有多近」
- `## 形状库：圆 / 方 / 圆角方 / 线段`：四个标准实现代码段（iq 2D SDF 的课程精简版：`sdCircle` / `sdBox` + `rounding` 参数 / `sdSegment`）；每个配一行「调参直觉」
- `## 布尔运算：并交差与平滑混合`：`min` 并、`max` 交、`max(a, -b)` 差；**平滑布尔** `smin`（`mix` 距离场——「形状焊接」的工业手法，lusion 的液态形体全是它）
- `## How：demo 01「SDF动物园」逐段精讲`：一个 fragment 里陈列 6 只形状（圆、方、圆角方、线段、并、平滑并），底部标签各自公式；呼吸动画统一驱动
- `## 常见坑`（表格）：`fwidth` 在部分移动端要开扩展（WebGL2 无此问题，提一句历史）/ SDF 距离直接当颜色输出（过曝，要 `smoothstep`）/ `smin` 的 k 太大形状「融化」/ 线段 SDF 忘了除 2
- `## Checkpoint`：能默写圆与方 SDF；能解释距离场相对布尔的三个优势；能用 fwidth 写出任意 SDF 的抗锯齿填充行
- `## 相关材料`：iq 2D distance functions 文章链接、The Book of Shaders「Shapes」章节链接

## 讲义 2.2 坐标变换：旋转、平铺与极坐标

```markdown
# 2.2 坐标变换：旋转矩阵、fract 平铺与极坐标图案

> Day 2 · 模块 2 · 约 50 分钟
> 理论对照：《WebGPU 三天实战课程》2.1「空间变换」——矩阵推导在那里；本篇只讲 2D 工程中最常用的三个套路
```

**章节大纲**：
- 导语：形状会画了，但都钉死在屏幕中央。这一讲让它们转起来、铺满屏幕、绕成花纹——**变换的是坐标，不是形状**
- `## 黄金法则：变换坐标，而不是变换形状`：`p = rot(p)` 后再代 SDF；与 CSS `transform` 的心智对照（CSS 变换元素、GLSL 逆变换坐标）；一行口诀「你想让形状往右，就把坐标往左」
- `## mat2 旋转：手写，就一次`：`mat2 rot(float a)` 完整实现；列主序坑（为什么 webgpu 课讲过这里就一句带过）；旋转速度与 u_time 相乘
- `## 平移与缩放`：`p - center`（平移）与 `p / scale`（放大形状＝缩小坐标）；对称轴 `abs(p.x)`——「镜像是最便宜的对称」
- `## fract 平铺：一块瓷砖铺满墙`：`vec2 id = floor(p * n)`（格子编号）+ `vec2 f = fract(p * n) - 0.5`（格内坐标）；每格独立图案（用 `id` 参与 hash——明天 2.3 的钩子）；「先分格再画，图案的世界观从单幅变无限」
- `## 极坐标：从方格到放射`：`atan(p.y, p.x)` 与 `length(p)`；代码段：放射条纹（`step(0.5, fract(angle * N / TAU))`）；重复扇区 `mod(angle, TAU/N)` + 镜像 `abs`——曼陀罗公式（昨天 challenge 的理论补课）
- `## How：demo 02 里第 1 格的旋转 + 平铺双案例精讲`：本日 demo 02「voronoi细胞」虽然主菜是 voronoi，但其骨架「平铺格子」来自本讲——精讲它的 `id/f` 双坐标分解
- `## 常见坑`（表格）：旋转矩阵参数顺序写反（转错方向）/ 平铺后忘 `fract - 0.5` 居中（图案贴角）/ 极坐标在圆心角度未定义（`atan(0,0)`，画个避让半径）/ 变换顺序不对（先旋转后平移 ≠ 先平移后旋转——矩阵不可交换）
- `## Checkpoint`：能手写 mat2 旋转；能解释「变换坐标」与「变换形状」的方向差异；能用三行写出「N 重复扇区镜像」
- `## 相关材料`

## 讲义 2.3 伪随机与图案：hash、格子与 voronoi

```markdown
# 2.3 伪随机与图案：hash、格子与 voronoi 细胞

> Day 2 · 模块 3 · 约 50 分钟
> 理论对照：无直接章节——本篇是 shader 程序化图案的完整入门，参照 The Book of Shaders「Random / Noise」两章的深度展开
```

**章节大纲**：
- 导语：把每块瓷砖的颜色随机化，城市立面的窗灯、Orage 网格的闪烁数据包——随机感是「数字世界里的生命感」的第一来源
- `## hash：每一帧都一致的 Math.random()`：为什么不能真随机（无状态 + 每帧独立 → 画面闪成雪花）；`hash21` 标准实现代码段（`fract(sin(dot(p, vec2(127.1, 311.7))) * 43758.5453)`）；「输入相同 → 输出相同；输入差一点 → 输出差很多」（雪崩效应）；大数与精度坑一句带过
- `## 随机格子：闪烁的窗灯`：`hash21(id)` 给每格一个 0–1 值；阈值切分成「亮格 / 暗格」；时间维度：`step(0.5, hash)` 换成 `step(0.5, hash + 0.1 * sin(u_time + hash * TAU))`——每格按自己的相位呼吸（1.6 相位表的实战）
- `## voronoi：离谁最近就是谁的领地`：算法三行（遍历 3×3 邻域 → 距离取最小 → 记录胜者编号 `id`）；完整代码段（标准的 iq 精简版）；距离场第二产出（`F1` 最近距离、`F2` 次近距离——**F2-F1 是细胞壁**）
- `## 细胞壁与玻璃裂纹`：`smoothstep` 处理 F2-F1 画出晶格缝——「石板 / 龟裂 / 大理石纹」的共同母题
- `## How：demo 02「voronoi细胞」逐段精讲`：细胞填充色（胜者 hash → 调色板索引）+ 细胞壁 + 鼠标视差（格心微移）
- `## 常见坑`（表格）：hash 大数在 mediump 下变黑（精度）/ 只遍历 1 格找最近（边缘细胞跳变，必须 3×3）/ voronoi 循环里 break（部分驱动不展开，性能反而差）/ 细胞壁宽度不随格子尺寸缩放（用 `fwidth`）
- `## Checkpoint`：能解释 hash 为什么必须确定性；能默写 voronoi 的 3×3 遍历骨架；能说出 F1/F2 各自的视觉用途
- `## 相关材料`：iq「voronoi borders」文章链接

## 讲义 2.4 噪声：从 value noise 到 domain warping

```markdown
# 2.4 噪声：value noise、fbm 与域扭曲——流动感的来源

> Day 2 · 模块 4 · 约 60 分钟
> 理论对照：无直接章节——本篇是创意网站「背景流动感」的技术核心，参照 The Book of Shaders「Noise」+ iq「fbm」的工程化展开
```

**章节大纲**：
- 导语：hash 的格子太碎，噪声要的是「相邻处相似、远处不同」——平滑随机。lusion 的丝绸、Noomo 的雾、几乎每个 awwards 站的背景，全部建立在接下来三层的塔上：noise → fbm → domain warping
- `## value noise：格子间的平滑插值`：算法四行（取格点 hash → 四角值 → `mix` 双线性 → 输出 0–1）；完整代码段（课程标准实现，含 `smoothstep` 缓动的双线性）；与「随机格」的并排对比（svg：noise-fbm-composition 第一联）
- `## 让噪声动起来：坐标偏移`：`noise(p + vec2(u_time * 0.15, 0))`——流动方向与速度全在这一行；为什么用 `+time` 而不是乘（乘会缩放图案）
- `## fbm：噪声的噪音`：`fractal brownian motion` 一句话人话（同一噪声多个倍频相加：低频给形体、高频给细节）；标准五倍频代码段（振幅减半、频率加倍）；octaves 参数的性能直觉（每加一层贵一倍，背景 4–5 层封顶）
- `## domain warping：先扭曲坐标，再采样噪声`：`fbm(p + fbm(p) * k)` 嵌套代码段；前后对比（svg：domain-warping 双联图）；「双 fbm 的价格买一个丝绸质感」——lusion 背景的配方核心；warp 强度 k 的三档表（0.3 微澜 / 0.8 丝绸 / 1.5 熔岩）
- `## 性能账单`：一张表算清——单像素 fbm(5 octaves) 的函数调用次数（~20 次 hash + 插值）；1080p 全屏 ≈ 200 万像素 × 20；为什么 demo 里 warp 常只 warp 一层
- `## How：demo 03「fbm云海」+ demo 04「域扭曲流场」双联精讲`：03 是塔的第一二层（云海：fbm 灰度 + 调色板映射 + 边缘 glow）；04 是塔顶（流场：warp 后的 fbm 做速度场，条纹沿场流动）
- `## 常见坑`（表格）：octaves 叠到 8（视觉无增益、帧率减半）/ warp 里又 warp（指数爆炸）/ 忘 `fract` 让 noise 输入无界（精度抖动）/ 用 `abs(p)` 后再 noise（折痕，有时是故意的——顺带教一招「纸折痕」技巧）
- `## Checkpoint`：能默写 value noise 四步；能解释 fbm 每层的频率振幅变化；能写出 domain warping 一行并说明 k 的三档效果
- `## 相关材料`：iq「noise - value noise」「fbm」文章、kishimisu 噪声视频链接

## 讲义 2.5 色彩工程：mix、余弦调色板与配色直觉

```markdown
# 2.5 色彩工程：从手写三个颜色到余弦调色板

> Day 2 · 模块 5 · 约 45 分钟
> 理论对照：无直接章节——配色属于 shader 工程的「设计侧」，母本是 iq 的 cosine palette 文章
```

**章节大纲**：
- 导语：你已经能画形状与噪声，但颜色还是手写 `vec3(1.0, 0.3, 0.5)` 两个来回——画面的「高级感」八成卡在配色上。这一讲给你设计师的调色公式
- `## mix：颜色世界的呼吸阀`：`mix(c1, c2, t)` 复习 + 双向滥用（t 可以是任何 0–1 信号：噪声、SDF、时间）——「把 mix 当 if-else 的连续版」
- `## 余弦调色板：一个公式装下一整套配色`：`a + b * cos(TAU * (c * t + d))` 完整实现（a 基线 / b 振幅 / c 频率 / d 相位——svg：palette-cosine 四参数各自作用的色带图）；为什么余弦而不是线性插值（RGB 通道错相 → 过渡自然带色偏，「渐变不脏」的秘密）
- `## iq 的三张经典色卡`：代码段直接给出（iq 文章原版「蓝橙 / 熔岩 / 彩虹」三组的 a/b/c/d 参数表）——**抄这几组参数起步，再改 d 相位做微调**
- `## 把信号映射成色彩：配色即函数设计`：`palette(fbm(uv))`——噪声值 0–1 当 t；SDF 距离当 t（「离边缘越近越亮」）；「你调的从来不是颜色，是 t 的分布」——对比表：t 用原值 / smoothstep 后 / pow 后的色彩差异
- `## 亮度与对比的最后一公里`：`col = pow(col, vec3(0.4545))`——gamma 校正为什么是收尾必备（人眼对暗部敏感，线性 RGB 显示偏暗）；一句「记不住原理就记住位置：最后一步、指数 0.4545」
- `## How：demo 05「调色板实验室」逐段精讲`：a/b/c/d 四个 uniform 实时可调（键盘或滚轮切参数、画面九宫格预览）——「这是你自己的配色工作台」
- `## 常见坑`（表格）：不做 gamma 输出（画面发灰发闷）/ 调色板 t 忘 clamp（负数进 cos 出现怪色，有时是 bug 有时是 feature）/ 高饱和三色都拉满（互相打架——保留一个主色，其余降饱和）/ 用 sRGB 值直接当线性（先平方）
- `## Checkpoint`：能默写余弦调色板公式；能说出四参数各自控制什么；能解释为什么收尾要 pow 0.4545
- `## 相关材料`：iq「palettes」文章链接

## 讲义 2.6 光的错觉：法线、阴影、辉光与 dithering

```markdown
# 2.6 光的错觉：伪 3D 光感的全部手法

> Day 2 · 模块 6 · 约 55 分钟
> 理论对照：《GAMES101》着色章节——真实光照模型；本篇是「用 2D SDF 伪造光感」的偏方集，两边的分界：真实渲染 vs 视觉说服
```

**章节大纲**：
- 导语：SDF 是平面的，但没人规定平面不能有光。这一讲把「体积感」四个手法一次给齐——徽章的立体、发光体的辉光、暗部的渐变、抖动的灰阶
- `## 高度场法线：SDF 的免费 3D`：把距离场当高度场 `h = 1.0 - smoothstep(0.0, w, abs(sd))`；法线 = 高度的梯度（`vec3(dhdx, dhdy, 1.0)` 归一化）；朗伯光照一行（`dot(n, lightDir)`）——「2D 形状立刻鼓起来」完整代码段
- `## 伪阴影：往光反方向再画一遍`：SDF 距离 + 光方向偏移投影（`sd(p - lightOffset)` 当阴影通道）；或最简款：形状下方 `smoothstep` 一条渐变椭圆——「设计师说的『底部压一层暗』的函数写法」
- `## glow：辉光 = 距离的幂`：`glow = pow(w / (abs(sd) + w), 2.0)` 完整代码段；参数直觉（w 带宽 = 光晕半径；指数 = 光晕锐度）；叠 additive（`col += glowColor * glow`）——「霓虹字、能量体、赛博氛围」的统一母题
- `## bloom 错觉与真 bloom 的分界`：单 pass 内「光晕叠加」够用 90% 场景；真 bloom 要 render target 双 pass（Day 3 的 3.5 接手）；一句话讲清取舍
- `## dithering：让渐变不结带`：8bit 输出下深色渐变的色带（banding）；有序抖动一行（`+ (hash - 0.5) / 255.0`）；「电影厂标的 grain 前身」
- `## How：demo 06「霓虹辉光与电影感」逐段精讲`：SDF 圆环 + 法线高光 + 双层 glow + dither 收尾的完整装配——「Day 2 全部手法的一页汇报」
- `## 常见坑`（表格）：glow 用 `step` 而不是幂衰减（硬边光圈）/ 法线忘归一化（光照忽明忽暗）/ additive 叠加不 clamp（过曝白块）/ dither 加太大（噪点脏）
- `## Checkpoint`：能写出高度场法线三行；能背 glow 公式并说出两参数的手感；能解释 dithering 解决什么问题
- `## 相关材料`

## 讲义 2.7 纹理：采样、通道与 UV 失真

```markdown
# 2.7 纹理：把图片交给 GPU 之后

> Day 2 · 模块 7 · 约 45 分钟
> 理论对照：《WebGPU 三天实战课程》2.3「纹理采样与 mipmap」——采样器状态与过滤的硬知识；本篇讲 GLSL 侧用法与失真手法
```

**章节大纲**：
- 导语：到今天为止所有画面都是「算出来的」；这一讲引入第一张外部图片——awwwards 站的 hero 图轮播、hover 失真、滚动视差全从这里起飞
- `## 采样最小闭环（JS 侧五步）`：`createTexture` → bind → `texImage2D`（图片上传）→ 参数（WRAP / FILTER）→ uniform 绑 `sampler2D`；与 webgpu 2.3 对照表（`texImage2D` vs `copyExternalImageToTexture`）
- `## texture()：一行拿颜色`：`vec4 c = texture(u_tex, uv);`；返回 RGBA 四通道；**uv 越界的行为由 WRAP 决定**（REPEAT 平铺 / CLAMP 拉伸边缘）
- `## UV 失真：先改坐标再采样`：`uv + 噪声偏移`（液态玻璃）；`uv` 极坐标扭曲（漩涡）；圆形遮罩采样（`length` 裁 UV）；**RGB shift**：三通道各自微移采样再重组（`r = tex(uv + off).r`…）——「赛博故障 / 色差」三行配方
- `## 通道复用：一张纹理四个数据源`：R 当亮度遮罩、G 当流速图、B 当 alpha——数据纹理（data texture）思维（Samsy 的 Medium 文章提过的手法）
- `## How：把图片接进 demo 05 的四格之一`（本日不设独立纹理 demo，纹理手法并入 challenge 作业——demo 阶段用程序化图案占位讲解）
- `## 常见坑`（表格）：图片跨域没 CORS（纹理黑块）/ 忘设 `UNPACK_FLIP_Y_WEBGL`（图上下颠倒）/ 非二次幂尺寸 REPEAT 失效（WebGL2 已放开，提一句历史）/ 每帧重新上传纹理（应该只传一次）
- `## Checkpoint`：能写出 UV 失真的采样行；能默写 RGB shift 三行；能说出 WRAP 两种模式的画面差异
- `## 相关材料`：webgpu 2.3、MDN texImage2D 文档

## 讲义 2.8 电影感配方：grain、vignette 与合成模式

```markdown
# 2.8 电影感配方：收尾的四个手法

> Day 2 · 模块 8 · 约 40 分钟
> 理论对照：无直接章节——本篇是「把技术拼装成作品」的收尾课，参数全部可背
```

**章节大纲**：
- 导语：同一个 shader，加不加最后这四步，观感差一个档次——它们不改变「画了什么」，只改变「像不像电影」
- `## grain：颗粒`：`+ (hash(gl_FragCoord.xy + u_time) - 0.5) * 0.04`；动态 grain（每帧换 seed）；「为什么 4% 就够」——超过是噪点，低于是脏
- `## vignette：暗角`：`1.0 - k * pow(length(uv - 0.5), 2.0)`；k 三档表（0.1 空气感 / 0.2 舞台聚光 / 0.3 老镜头）
- `## 合成模式：shader 里的 mix-blend-mode`：`screen` / `add` / `multiply` / `overlay` 的 GLSL 实现表（各一行公式）；「发光体用 screen，叠影用 multiply，胶片感用 overlay」
- `## 参数化模板：电影感配方卡`：一张总表——gamma → 对比（`col = (col - 0.5) * 1.06 + 0.5`）→ 饱和（mix 灰度）→ grain → vignette 的**固定顺序**；「顺序就是配方」
- `## How：demo 06 的收尾段回放`：把配方卡逐行套在昨天讲过的辉光场景上，前后对比（开关 uniform 切换）
- `## 常见坑`（表格）：grain 放 gamma 前（被校正吃掉）/ vignette 用 `uv` 原值不居中（偏心黑角）/ 饱和度拉过头（数码味）/ 配方顺序乱（对比在 grain 后 = 颗粒被放大）
- `## Checkpoint`：能背配方卡的五步顺序；能写 grain 与 vignette 各一行；能说出三种合成模式的适用对象
- `## 相关材料`：实例网站清单里 Orage / Noomo 的「电影感」观察点回链
```
