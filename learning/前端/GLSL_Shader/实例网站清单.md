# 实例网站清单

这份清单是课程的「靶场」：十个站，全部是 awwwards 获奖 or 年度级别的创意网站，每个都对应讲义里某一讲或某档作业的手法。怎么用——每站按下面的三步观察法看 10 分钟，比刷 30 分钟教程视频有用；本课的作业视觉目标全部对标这些站的技术层次，不要求工程规模对等。

## 三步观察法（每站通用）

1. **不动鼠标看 10 秒**：什么在动、什么是静的？——动画是 `u_time` 驱动的 shader，还是预渲染视频？
2. **慢速完整交互一遍**：鼠标横扫、滚到底再回来——响应发生在哪一层？有没有 lerp 平滑？阻尼大概什么量级？
3. **性能面板重滚一次**：帧率稳定吗？最贵的是哪一段（shader / 布局 / 视频）？

## 逐站拆解

### lusion.co

- **气质**：丝绸质感的全屏 shader 流动 + 3D 场景编排，多年 awwwards 年度最佳常客。
- **技术拆解**：官方访谈多次提及自研 shader 流场驱动丝绸质感背景（据公开访谈）；首页粒子构成的人物走 GPGPU 路线；场景切换靠 3D 编排而非页面跳转。
- **课程关联**：丝绸背景对应讲义 2.4「噪声：value noise 到 domain warping」，复刻入口是 Day 2 A 档作业「墨纹大理石」——同一套 fbm + domain warping，纹样从丝绸流场换成墨纹大理石；粒子人物对应 3.4「粒子场」。
- **观察要点**：把鼠标停在丝绸上 10 秒，流动是持续的还是在衰减——对应 shader 里 `u_time` 与噪声的哪种组合；滚动切换场景时，过渡发生在几何层还是纹理层；长时间停留后 FPS 是否稳定。

### igloo.inc

- **气质**：沉浸式 3D 叙事空间，awwwards 2024 年度网站。
- **技术拆解**：Three.js 驱动的冰雪叙事（据公开分享）；冰的通透感来自 shader 层的折射与体积感近似，雪是持续存在的粒子层；章节式滚动叙事把一镜到底切成段落。
- **课程关联**：雪粒子对应 3.4「粒子场：Points、gl_PointSize 与噪声粒子场」；章节式叙事对应 3.3「滚动驱动 shader：u_scroll、Lenis 与转场遮罩」。
- **观察要点**：滚动进度与画面章节的对应关系——如果用 `u_scroll` 分段实现，分界点会在哪里；雪是 Points 还是 sprite 贴图（放大看颗粒形状）；冰面高光是否随相机移动，判断相机矩阵是否进了 shader。

### ivress.io

- **气质**：WebGPU 优先的品牌短片式体验，2025 年度网站。
- **技术拆解**：TSL 双后端——WebGPU 渲染主路径，WebGL 自动 fallback（开发者自述）；这是 webgpu 课 3.x「WebGPURenderer 架构与迁移策略」的实战印证。
- **课程关联**：理论对照——webgpu 课第 3 天的 TSL 内容与本课 3.1「ShaderMaterial：从原生到 Three.js 的迁移」互为镜像；在本课语境下它回答的问题是「什么时候值得上新 API」。
- **观察要点**：换一个不支持 WebGPU 的浏览器打开，看 fallback 画面与主路径差多少；片头转场是实时 shader 还是视频；交互响应最明显的一层是什么。

### orage.studio

- **气质**：终端美学的暗色首页，网格里的每个格子都是「活的」。
- **技术拆解**：awwwards case study 公布过方案——Three.js + canvas texture + 时间偏移：格子里的视频被实时遮罩、错峰播放（公开 case study）。
- **课程关联**：纹理手法对应 2.7「纹理：把图片交给 GPU 之后」；「格子是被实时遮罩的视频」这一认知对应 Day 3 A 档作业「失真图卡墙」的图卡模型——每张卡是独立 mesh + 独立 uniforms。
- **观察要点**：格子失焦时的过渡是视频淡入还是 shader 遮罩（卡与卡之间对比）；性能面板里最贵的一层是视频解码还是 shader；hover 时失真的参数量级与 3.2 讲义的波纹幅度对比。

### samsy.ninja

- **气质**：可「穿行」的作品集，滚动即位移；SOTD + Developer Award（2025）。
- **技术拆解**：滚动驱动的场景穿行 + 生成式资产合成（据公开分享）；滚轮输入被平滑成持续位移，段落之间无硬切。
- **课程关联**：滚动平滑对应 3.3 的 Lenis 段与 `u_scroll` 归一化；粒子段落对应 3.4；它的「滚动即叙事」正是 Day 3 C 档作业「滚动驱动的英雄时刻」的对标原型。
- **观察要点**：滚动阻尼的手感量级——对比 Lenis 默认 `lerp: 0.1`；从粒子段到文字段的切换点在滚动进度百分之几；每段进场的动效是 shader 内还是 DOM 层。

### Noomo ValenTime

- **气质**：白金红三色的爱的叙事：雾效、镜子、粒子心（2025）。
- **技术拆解**：噪声雾与粒子心是 shader 层驱动（据公开分享）；镜子段落的高成本渲染被限制在局部画面。
- **课程关联**：雾对应 2.4 的 fbm 叠加与 2.8 的电影感配方；粒子心的聚拢对应 3.4 粒子场的目标点插值——这正是 C 档「滚动驱动的英雄时刻」粒子段的手法。
- **观察要点**：雾的层次数（fbm 倍频数的视觉判断，对照 2.4 的 4–5 倍频建议）；粒子从散到聚的时机与时长；bloom 的强度——白金高光是否溢出到暗部。

### Oryzo

- **气质**：单对象产品片：一个主体、一束光、一层滚动（2026 趋势代表作）。
- **技术拆解**：惯性渲染——所有输入都过 lerp 再驱动画面（据公开分享）；Z 深度滚动让滚动映射到相机推拉而非页面位移。
- **课程关联**：交互手感对应 1.7「交互输入」的 lerp 桥与 3.3 的滚动归一化；「单对象 + 一束光」是讲义 2.6「光的错觉」的极简应用场景。
- **观察要点**：滚动的惯性感从哪来——估算阻尼系数（对照 1.7 的 0.08 基准）；主体材质是视频帧还是实时光照；页面几乎无传统 DOM，注意导航层如何悬浮。

### Beyond Aero

- **气质**：氢能飞机官网：相机轨道 hero + 翻牌 loading（HM 2025）。
- **技术拆解**：hero 的飞机绕轨旋转由相机动画驱动（据公开分享）；loading 的翻牌动画与真实资源加载进度同步，转场用遮罩完成。
- **课程关联**：转场遮罩对应 3.3 的遮罩段——「加载完成不是淡入，是遮罩扫过」；轨道相机的缓动对应 1.6 的缓动函数库。
- **观察要点**：loading 翻牌与场景就绪的同步方式（强制等待还是真进度）；首次进场遮罩的形状与扫过方向；轨道相机的回弹曲线属于哪类缓动。

### CyD Stumpel

- **气质**：个人作品集，图卡 hover 时的液态失真是整个领域的教科书示范。
- **技术拆解**：Three.js 图卡 + hover 失真（作者公开过实现思路）；失真沿噪声流场扭曲 UV，幅度随 hover 强度变化（据公开分享）。
- **课程关联**：讲义 3.2「图片失真与鼠标视差」的直接对标——Day 3 A 档作业「失真图卡墙」的视觉目标就是它的单卡简化版。
- **观察要点**：失真的方向是径向扩散还是沿噪声流向；RGB 色散的幅度与 3.2 讲义的 0.012 基准对比；hover 离开后的回落曲线（快速弹出、缓慢归位的双段手感）。

### Bruno Simon

- **气质**：Three.js Journey 作者的开源作品集：开着卡丁车逛简历。
- **技术拆解**：Three.js 全栈 + 物理引擎（源码开源，GitHub 可查）；低多边形风格与烘焙光照把渲染成本压到极低——这是「一个作品一个主角，其余全部降透明度」的工程化版本。
- **课程关联**：对应 3.5「后期处理工作坊」的装配思想——全站效果的分工清单；shader 手法的完整体系见《Three.js 创意 3D 课程笔记》（`前端/Threejs创意3D/课程笔记/`）。
- **观察要点**：物理引擎与渲染层的分工（哪些对象有碰撞体）；哪些表面用内置材质、哪些用自定义 shader；整站几乎没有后期 pass，画面靠什么不显得平。

## 观察伦理

技术拆解只写有公开来源支撑的内容（官方技术分享、开发者访谈、公开 case study、开源仓库），不确定处一律标注「据公开访谈/分享」。读站时守住同一条线：把观察到的行为当证据，把来源不明的推断留成疑问——这是课程严谨性的一部分，也是写技术博客的基本功。
