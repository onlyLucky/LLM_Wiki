# Demo 06 · 滚轮的浪潮

对应讲义：`1.7 交互输入`（wheel 事件桥与弹簧惯性）

## 运行

```bash
npm run dev
# http://localhost:5174/demos/day1/06-滚轮的浪潮/index.html
```

## 关键点

- wheel 是未加工的原始量：像素累积、向下为正、没有平滑——JS 侧先归一化（×0.04，滚一格 ≈ 推进 4 条纹）再进惯性模型
- 回弹的本质是欠阻尼弹簧：`v += (目标-位置)×k`、`v ×= 阻尼`、`位置 += v`——lerp 是过阻尼永远不回头，弹簧多一个速度项就弹出 easeOutElastic 手感
- 步进顺序不能反：先加速度、再耗散、再位移；反了能量凭空多出来，弹簧会越弹越高
- 速度可视化用滑动平均：瞬时 |v| 毛刺太重，0.1 系数抹成「势」，快滚泛白、慢滚安静

## 视觉规格

- 色板：底色 `#0B0E14`；24 条竖条纹（fract 分格 + 中央亮带 smoothstep 0.42→0.5，边缘留过渡抗锯齿）
- 双色：波谷玫红 `#FF4D6D`、波峰天青 `#4CC9F0`，mix 沿波浪取色
- 动效：波浪沿 y 1.5 周期、相邻条纹错相 0.6；idle 慢转 0.15 rad/s（静止时画面也活着）；滚动额外推进 0.3 相位
- 速度感：弹簧速度映射条纹泛白（上限 45%）；性能：单 draw call、DPR ≤ 2，预计 60fps

## 常见报错

| 报错 | 原因 |
|------|------|
| 滚动没反应 | wheel 是累积量不是瞬时速度——直接当速度用会二次积分，画面飞走 |
| 弹簧越弹越高停不下来 | 步进顺序反了，或阻尼 ≥ 1（能量没有耗散） |
| 反向滚动不回退 | JS 侧把 wheel 取了绝对值——累积量自带符号，弹簧自动回退 |
| 条纹边缘锯齿 | 亮带用 step 硬切——smoothstep 0.42→0.5 给抗锯齿留过渡 |
