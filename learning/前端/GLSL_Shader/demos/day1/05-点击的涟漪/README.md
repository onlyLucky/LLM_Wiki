# Demo 05 · 点击的涟漪

对应讲义：`1.7 交互输入`（click 事件桥与年龄推演）

## 运行

```bash
npm run dev
# http://localhost:5174/demos/day1/05-点击的涟漪/index.html
```

## 关键点

- 事件只记账，shader 推演生命史：click 瞬间只留下三个数（时刻/位置/颜色），之后每一帧涟漪的形状都是 `u_age` 的函数——扩散、展宽、衰减全是年龄驱动
- 「从未点击」是状态不是错误：`clickTime` 初始 -1，JS 喂一个大年龄让 exp 衰减自然归零，shader 不需要 if
- 交替双色不用 shader 分支：JS 侧数奇偶传 `u_hue`，`mix(ROSE, CYAN, u_hue)` 在两端之间取色
- 距离场先做 aspect 修正再量距离，涟漪才是圆的（demo 04 同款陷阱）

## 视觉规格

- 色板：底色 `#0B0E14`；涟漪双色交替玫红 `#FF4D6D` / 天青 `#4CC9F0`（首次点击玫红）
- 波前：扩散速度 0.45/s；环宽 1.5% 起步、每秒展宽 2%；亮度 exp(-1.2·age) 约 3s 消散
- 质感：环内叠 sin 细纹（频率 80，强度 35%）模拟水面；落点余晖 exp(-3·age) 快速熄灭
- 交互：仅点击驱动，无自主动画；性能：单 draw call、DPR ≤ 2，预计 60fps

## 常见报错

| 报错 | 原因 |
|------|------|
| 页面一加载就有涟漪 | age 没处理 clickTime = -1 的初始态 |
| 涟漪是椭圆的 | aspect 修正漏了（同 demo 04） |
| 连点两次涟漪闪断 | 正常——单涟漪设计，新点击重置 u_age；多涟漪需要 uniform 数组（Day 2 展开） |
| 涟漪永不消散 | fade 的 exp 衰减没乘，或 age 传成了帧数不是秒 |
