# 03 · 时间仪器馆（TIME INSTRUMENTS）

四台仪器面板共用同一相位，把「时间的画面」变成一间可以读表的工作室。

## 运行

```bash
cd demos/day1/03-时间的画面
npx serve .   # 或任意静态服务器，浏览器打开 index.html
```

## 画面构成

- **2×2 仪器面板**：屏幕等分四格，每格是一台独立仪器，格间留暗缝
- **左下 · 呼吸灯**：灯芯随 `breathe` 曲线胀缩，外圈静态参考环 + 8 道刻度，灯晕随呼吸强度变化
- **右下 · 示波器**：三角波随相位向左滚动，网格底纹，中央读数点亮起时正好是波峰
- **左上 · 弹簧摆**：`elasticOut` 驱动滑块在轨道上过冲回摆，5 档刻度 + 右端虚线目标线
- **右上 · 进度弧**：`easeInOut` 缓动扫弧，12 刻度表盘，弧端亮点即「当前时刻」
- **公共层**：每格左上铭牌条标注仪器名、底部共用进度条、6s 慢呼吸整体明度、胶片颗粒
- **对表语义**：四台仪器由同一个 `phase` 驱动——底部进度条走完一圈，四台仪器同时归零

## 关键点

1. **相位公式**：`fract(u_time / 周期)` 把连续时间折叠成 0→1 的锯齿相位，是所有循环动画的心跳
2. **u_time 单位约定**：单位是**秒**，除以周期即可控制节奏（本页周期 6s：`fract(u_time / 6.0)`）
3. **四条缓动曲线**：`breathe`（正弦呼吸）、`triangleWave`（三角波往返）、`easeInOut`（缓入缓出）、`elasticOut`（弹性过冲）——同一相位喂进不同曲线，气质完全不同
4. **2×2 分格坐标**：`cell = floor(uv * 2.0)` 定格号，`guv = fract(uv * 2.0)` 得到格内 0-1 坐标，一套代码四格复用

## 视觉规格

| 属性 | 值 |
| --- | --- |
| 背景 | `#0E1220`（深蓝黑） |
| 表盘面 | `#141824`，比背景略亮 |
| 主强调 | 玫红 `#FF4D6D` / 青 `#4CC9F0` 按格交替 |
| 面板边距 | 格内缩 0.018，暗缝宽 0.004 |
| 缓动参数 | 四曲线统一 `p = 0.3` |

## 常见报错

- **面板边缘锯齿**：所有描边走 `stroke(d)`（`gPx` 像素级抗锯齿），不要手写 `step`
- **弹簧摆不过冲**：`elasticOut` 的 `p` 参数必须与讲义一致（0.3），改大振荡会收敛但变肉
- **示波器波形方向反了**：滚动方向由 `guv.x*2.0 - phase*2.0` 的减号决定，加号向右滚
- **格内坐标超界**：忘记 `fract`，直接用 `uv*2.0` 画图会把四格内容画成一格
- **呼吸和进度弧节奏对不上**：二者必须共用同一个 `phase` 变量，各自算相位就会漂移
