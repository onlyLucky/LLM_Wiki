# Demo 03 · 时间的画面

对应讲义：`1.6 时间与动画`（相位归一化与四条曲线）· `1.3 表达式与结构`（函数定义与分支）

## 运行

```bash
npm run dev
# http://localhost:5174/demos/day1/03-时间的画面/index.html
```

## 关键点

- 相位归一化是循环动画的心跳：`fract(u_time / 3.0)` 先把秒换成圈数再去整——不管 u_time 涨到多大，相位永远在 [0,1] 循环
- 四条曲线接口统一，全部吃 [0,1] 吐 [0,1]：呼吸 `0.5 + 0.5*sin`、三角波 `abs(fract*2-1)`、缓动 `t*t*(3-2t)`、弹性 = 指数衰减包络套正弦——接口一致，格子才能随意换装
- sin 天生值域 [-1,1]：直接当混合系数，一半时间会把颜色减成负数——先 `0.5 + 0.5*sin(...)` 映射再使用
- elasticOut 的 t=0 / t=1 边界要提前返回：衰减包络在两端的数值行为不收敛，不保护就会在起点闪一下

## 视觉规格

- 色板：四格底色 `#10151F`，2x2 分格 + 格间 0.6% 暗缝；左下呼吸（玫红）/ 右下三角波（天青）/ 左上弹性（天青）/ 右上缓动（玫红）
- 每格内容：当前值位置一条亮带（smoothstep 0.035→0.02，约 3.5% 高），扫过区域留痕迹
- 节奏表：主相位 3s（四格动画与底部进度条）；次 4.5s（痕迹亮度呼吸）；背景 6s（整体 ±2% 亮度摆动）
- 底部进度条：1.2% 高、白色 25% 透明度，与四格共用同一相位——对表用
- 细节：全屏胶片颗粒 ±1%（hash 噪声）；性能：单 draw call、DPR ≤ 2，预计 60fps

## 常见报错

| 报错 | 原因 |
|------|------|
| 动画越跑越抖 | u_time 传了毫秒：百万级浮点上 fract 精度崩坏，相位开始抖——JS 侧除以 1000 |
| 四格看不出差异 | 相位忘了 fract，或每格用了不同周期没法对表——本 demo 刻意共用一个 3s 相位 |
| 呼吸格一半时间全黑 | sin 直接当系数用，负值把颜色减穿——`0.5 + 0.5*sin(...)` 先映射 |
| 弹性格起点闪一下 | elasticOut 没保护 t<=0 / t>=1 边界 |
