# Demo 06 · 霓虹辉光与电影感

> 对应讲义 [2.6 光的错觉](../../../讲义/day2-片段着色器视觉算法/2.6-光的错觉：伪3D光感的手法.md) + [2.8 电影感配方](../../../讲义/day2-片段着色器视觉算法/2.8-电影感配方：grain、vignette与合成模式.md) · 键盘 1–5 切开关

## 运行

`npm run dev` 后访问 `http://localhost:5174/demos/day2/06-霓虹辉光与电影感/index.html`。

## 关键点

- **Day 2 的一页汇报**：SDF 圆环（2.1）→ 高度场法线 + 朗伯（2.6）→ 双层 glow（2.6）→ 配方卡五步（2.8）——装配顺序即讲义顺序，四段注释与两篇讲义逐段对应。
- **五个开关做 A/B**：键盘 1–5 独立开关 gamma / 对比 / 饱和 / grain / 暗角，hint 角标显示 ●○ 状态——「每一步值多少分」从参数表变成肉眼可测的选择题。
- **法线是编的，光感是真的**：`dFdx(h) / dFdy(h)` 与 fwidth 同源（屏幕空间导数），z=0.04 是金属浮雕档；关掉这一段（把 lit 改 0.5）环立刻瘪成纸片。
- **glow 双层的分工**：主晕窄亮（w=0.08 玫红）给强度、次晕宽柔（w=0.12 天青）给氛围——一层是发光，两层才有「光在空气里」。

## 视觉规格

- 色板：主环玫红 `#FF4D6D`（glow 90%）、内环天青 `#4CC9F0`（glow 50%）、环体金属色 `(0.94, 0.80, 0.86)`、底 `#0B0E14`；中心聚焦构图
- 动效：环自转 0.05 rad/s；grain 4%（动态 seed）；vignette 0.2（平方衰减）
- 细节：fwidth 抗锯齿填充、朗伯环境光 0.4、配方顺序 gamma → 对比 → 饱和 → grain → 暗角
- 性能：单 pass、无噪声无循环，60fps 富余（Day 2 六个 demo 里最便宜的一个）

## 常见报错

| 症状 | 原因 |
|------|------|
| 开关按了没反应 | 监听挂在 canvas 上——键盘事件要挂 `window`；或 `e.key` 比较用了 `e.code`（后者是 `Digit1`） |
| 环体一片惨白 | glow 两层系数（0.9 / 0.5）被拉满——additive 叠加没 clamp，输出前 `clamp(col, 0, 1)` 是安全带 |
| 法线段报 `dFdx` 未定义 | WebGL2 才内置导数——确认 context 是 `webgl2`（chrome.initGL 已保证）；WebGL1 要开扩展 |
| 配方顺序被重排 | 五步的前提是上一步的空间（gamma 最前、暗角最后）；顺序乱 = 颗粒被放大 / 暗角压不到对比 |
