# Demo 02 · voronoi 细胞

## 运行

`npm run dev` 后访问 `http://localhost:5174/demos/day2/02-voronoi细胞/index.html`。

## 关键点

- **3×3 遍历是安全域**：`id` 格与八个邻居全查，格线附近的「领主跳变」才不会漏；循环里不写 break——九次全跑比动态分支便宜（讲义 2.3 坑表第 3 行）。
- **一次 voronoi 三件产出**：F1 给细胞核到边缘的径向明暗（体积感）、F2-F1 给细胞壁（`smoothstep` 后是石板缝）、胜者编号二次 hash 给细胞身份色（领地感）——同一场遍历喂三种视觉。
- **身份色来自二次 hash**：`hash21(胜者编号)` 决定调色板 t，而不是直接拿 F1 染色——前者是「每细胞一种颜色」，后者是「同心波纹」，气质天差地别。
- **视差加在格子域**：`g` 进 voronoi 前加 `(u_mouse - 0.5) * 0.06`——整片细胞轻漂 3%，细节层可感知不喧宾。

## 视觉规格

- 色板：细胞低饱和蓝橙卡（`a=(0.42,0.44,0.48) b=(0.16,0.16,0.18)`）、壁 `#0D0F17`、底 `#0B0E14`
- 构图：满屏平铺、无中心——图案感来自重复与随机差
- 动效：鼠标视差 3%（lerp 0.08 由 chrome 供给）；grain ±1.5%（动态 seed）
- 细节：壁宽 `fwidth(F2-F1) × 2 + 0.01` 自适应、入场 800ms 淡入
- 性能：单 pass、每像素 9 次 hash22 + 36 次比较，60fps 富余（中端 GPU）

## 常见报错

| 症状 | 原因 |
|------|------|
| 格线附近细胞「撕开」重影 | 遍历只跑了 1 格或 3×3 少了 `+ o` 的邻居偏移——邻居的点没参与比较 |
| 细胞全黑或全灰一片 | `precision highp float;` 没写在顶部：hash 大数被 mediump 截断（讲义 2.3 坑表第 1 行） |
| 细胞壁粗成色块 | 壁宽写死（如 0.05）：近处太粗远处太细；用 `fwidth(wallT)` 自适应 |
| 鼠标一动细胞疯狂闪 | 视差直接乘了 raw 坐标——`u_mouse` 要用 chrome 的 sx/sy（已 lerp 0.08），或视差幅度超了 5% |
