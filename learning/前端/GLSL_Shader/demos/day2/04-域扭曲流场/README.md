# Demo 04 · 域扭曲流场

> 对应讲义 [2.4 噪声 · domain warping](../../../讲义/day2-片段着色器视觉算法/2.4-噪声：valuenoise到domainwarping.md) · 拖动鼠标搅动流场

## 运行

`npm run dev` 后访问 `http://localhost:5174/demos/day2/04-域扭曲流场/index.html`。

## 关键点

- **塔顶一行**：`fbm(p + u_warp * q)`——外层 fbm（`q` 两分量）决定「往哪推」，内层决定「画什么」；`5.2 / 1.3` 是 iq 的错相偏移，两个分量不同源才推得出旋涡感。
- **条纹的「流」来自相位混入**：`sin((f + p.x * 0.5 + time) * 18)` 里 `f` 是 warp 后的 fbm——条纹沿场弯曲，直条纹立刻变流线；没有 `f` 就是普通滚动条纹。
- **k 的三档表变成交互**：JS 侧帧差速度 × 8 灵敏度叠加到基线 0.3、上限 1.2，lerp 0.05 平滑——轻拖是微澜，猛拖是熔岩，松手回落丝绸档。
- **性能纪律**：warp 只 warp 一层（`q` 的两个分量共三次 fbm），倍频五层封顶——讲义 2.4 账单的工程兑现。

## 视觉规格

- 色板：条纹天青 `#4CC9F0` 25% 强度、场强微光 10%、底 `#0B0E14`
- 构图：满屏流线、无中心——背景层语义（与 demo 03 成对：一个体积感一个流线感）
- 动效：warp 基线 0.8 起步（视觉丝绸档，实际随拖速 0.3–1.2 浮动）、条纹流速 0.22、warp 漂移 0.08–0.10
- 细节：grain ±2%、vignette 0.16、入场 800ms
- 性能：单 pass、每像素 3 次 fbm（≈ 60 hash），60fps 需中端 GPU——账单见讲义 2.4

## 常见报错

| 症状 | 原因 |
|------|------|
| 拖动完全没反应 | 帧差写在更新 prev 之后（顺序反了，差值恒为零）；或 `u_warp` 忘了每帧写入 |
| 画面静止在熔岩档 | warp 只加不落：lerp 的 goal 上限写了但回退分支没有——目标是 `min(基线+速度, 1.2)`，松手速度为零自然回落 |
| 条纹是直的不弯 | 相位里没混 `f`——`sin(p.x * 18)` 只是横条纹平移；把 warp 后的 fbm 混进相位 |
| 帧率掉到 20fps | warp 里又套了 fbm（三层嵌套）；或倍频开了 7、8 层——一层封顶、五层封顶 |
