# Demo 01 · 形态标本馆

> 对应讲义 [2.1 像素级绘画：从 step 到符号距离场](../../../讲义/day2-片段着色器视觉算法/2.1-像素级绘画：从step到符号距离场.md) · 滚轮推动射灯，悬停预览

六份几何标本装进展卡陈列，射灯打到哪份，就借着暖光读哪份的公式。

## 运行

`npm run dev` 后访问 `http://localhost:5174/demos/day2/01-SDF动物园/index.html`。

## 画面构成

- **展厅夜色**：深蓝黑底上六张展卡（2×3），每张卡有卡纸底、细内框、左上铭牌条
- **编号铭牌**：铭牌条上的点数即标本编号（N°1 到 N°6）——不渲染文字，用点数读号
- **标本与底座**：标本居中陈列，下方一道软阴影带把形状「放」在展台上
- **射灯选中态**：顶部灯具亮起 → 光锥打下 → 底部光池聚拢，标本从灰蓝转为本色玫红
- **悬停预览**：鼠标所在格的标本微染本色、卡框微亮，与射灯选中态分两档

## 关键点

- **六只形状一个 fragment**：圆、方、圆角方、线段、硬并、平滑并——2.1 形状库与布尔运算的完整陈列，`cellShape` 按 `id` 分发。分格是 2.2 平铺的最小版（2×3）。
- **呼吸统一驱动**：`breath` 参数从 `cellShape` 外面传进六只形状——同频同相的 ±5% 呼吸是「陈列」而非「拼盘」的原因，也是「参数化魔法数字」习惯的第一课。
- **fwidth 抗锯齿**：`1.0 - smoothstep(0.0, fwidth(sd), sd)` 一行管六只形状的边缘——距离场相对布尔的工程红利，换形状不用换填充；而卡框、铭牌等直边 UI 走 `gPx + stroke/fillS`，两种抗锯齿同页对照。
- **底部角标当公式牌用**：`.tag--bl`（chrome 的操作提示角标）被复用为当前高亮标本的公式名，滚轮切换即换牌——「小字标注」不动用文字渲染，DOM 一行搞定。

## 视觉规格

- 色板：射灯琥珀 `#FFC145`、标本本色玫红 `#FF4D6D`、未打光 `#4A5263`、卡纸 `#131621`、展厅底 `#0B0E14`
- 动效：呼吸周期 3s、幅度 ±5%（六格同步）；光锥 `pow(ly, 1.8)` 顶亮底散、光池 `exp` 椭圆衰减
- 细节：标本 fwidth 抗锯齿、UI 元素 gPx 像素级抗锯齿、胶片颗粒 ±1%、入场 800ms 淡入
- 性能：单 pass、DPR ≤ 2，60fps（一个 6 次定长循环，六枚 SDF 共约 30 ALU）

## 常见报错

| 症状 | 原因 |
|------|------|
| 六格形状挤在左半屏 | `grid.x` 用了 `aspect / 3.0` 而非 `aspect * 2.0 / 3.0`——三列的每格宽是全屏宽的 1/3，居中域里是 `aspect * 2 / 3` |
| 高亮格数出来是 7 | `id = int(id2.x) + int(id2.y) * 3`——列数乘在 y 上；2×3 是「3 列 2 行」，写反成 2 列 3 行 |
| 滚轮滚一下跳两格 | `wheel / 120` 的分母与触控板灵敏度不匹配；按需调 240，或对 wheel 先做 lerp 平滑 |
| 平滑并的形状融成一滩 | `smin` 的 k=0.08 被改到 0.2 以上——焊枪宽过零件（讲义 2.1 坑表第 2 行） |
| 悬停格串到界外 | 鼠标分格后没做 `inBound` 边界钳制，`floor` 出负数格号让第一列跟着亮 |
| 光锥照亮了旁边的卡 | 光锥、光池都乘了 `isPick`，漏乘就会全展厅一起亮——聚光必须按格掩码 |
