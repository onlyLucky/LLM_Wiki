# Demo 01 · SDF 动物园

> 对应讲义 [2.1 像素级绘画：从 step 到符号距离场](../../../讲义/day2-片段着色器视觉算法/2.1-像素级绘画：从step到符号距离场.md) · 滚轮切换高亮

## 运行

`npm run dev` 后访问 `http://localhost:5174/demos/day2/01-SDF动物园/index.html`。

## 关键点

- **六只形状一个 fragment**：圆、方、圆角方、线段、硬并、平滑并——2.1 形状库与布尔运算的完整陈列，`cellShape` 按 `id` 分发。分格是 2.2 平铺的最小版（2×3）。
- **呼吸统一驱动**：`breath` 参数从 `cellShape` 外面传进六只形状——同频同相的 ±5% 呼吸是「陈列」而非「拼盘」的原因，也是「参数化魔法数字」习惯的第一课。
- **fwidth 抗锯齿**：`1.0 - smoothstep(0.0, fwidth(sd), sd)` 一行管六只形状的边缘——距离场相对布尔的工程红利，换形状不用换填充。
- **底部角标当公式牌用**：`.tag--bl`（chrome 的操作提示角标）被复用为当前高亮形状的公式名，滚轮切换即换牌——「小字标注」不动用文字渲染，DOM 一行搞定。

## 视觉规格

- 色板：高亮玫红 `#FF4D6D`、未选中 `#4A5263`、底 `#0B0E14`；中心聚焦构图（2×3 网格陈列）
- 动效：呼吸周期 3s、幅度 ±5%（六格同步）；选中格 glow `pow(0.10/(abs(sd)+0.10), 2.0)` × 22% 强度
- 细节：fwidth 抗锯齿边缘、入场 800ms 淡入
- 性能：单 pass、DPR ≤ 2，60fps（无噪声无循环，六个 SDF 共约 30 ALU）

## 常见报错

| 症状 | 原因 |
|------|------|
| 六格形状挤在左半屏 | `grid.x` 用了 `aspect / 3.0` 而非 `aspect * 2.0 / 3.0`——三列的每格宽是全屏宽的 1/3，居中域里是 `aspect * 2 / 3` |
| 高亮格数出来是 7 | `id = int(id2.x) + int(id2.y) * 3`——列数乘在 y 上；2×3 是「3 列 2 行」，写反成 2 列 3 行 |
| 滚轮滚一下跳两格 | `wheel / 120` 的分母与触控板灵敏度不匹配；按需调 240，或对 wheel 先做 lerp 平滑 |
| 平滑并的形状融成一滩 | `smin` 的 k=0.08 被改到 0.2 以上——焊枪宽过零件（讲义 2.1 坑表第 2 行） |
