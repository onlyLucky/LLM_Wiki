# Demo 03 · fbm 云海

> 对应讲义 [2.4 噪声](../../../讲义/day2-片段着色器视觉算法/2.4-噪声：valuenoise到domainwarping.md) · 移动鼠标看漂移

## 运行

`npm run dev` 后访问 `http://localhost:5174/demos/day2/03-fbm云海/index.html`。

## 关键点

- **三层塔的下两层**：`hash21 → noise → fbm` 逐级放大——缓动坐标（`3f²-2f³`）保证格子无缝，旋转矩阵 `m`（37° + 放大 2）保证倍频错轴不出纺织纹。
- **t 再分布是灵魂一行**：fbm 输出挤在 0.35–0.65（五层 0.5 幅的统计必然），`clamp(n * 1.6 - 0.3, 0, 1)` 铺满 0–1——「你调的从来不是颜色，是 t 的分布」的活体演示。
- **色卡改造而非新调**：熔岩卡改 `a`（压暗偏蓝）与 `d`（相位后移），保持 iq 参数骨架——起步抄卡、改 d 微调的工作流示范。
- **呼吸乘在噪声值上**：`breathe = 1 + 0.6 sin(t*0.4)` 让云量整体起伏——注意它乘的是 `n`（结果），不是 `flow`（坐标）：乘坐标会把图案缩放，乘结果是明暗呼吸。

## 视觉规格

- 色板：熔岩卡改造 `a=(0.18,0.22,0.30) d=(0.10,0.22,0.42)`——深蓝底 → 天青亮部；银边 `#4CC9F0` × 35%
- 构图：满屏横流、无焦点中心——背景层语义
- 动效：流速 0.15（斜向 (0.15, 0.05)）、呼吸 k=0.6（周期约 15.7s 的慢起伏）、鼠标漂移偏置 ±5%
- 细节：边缘 glow `pow(smoothstep(0.55,0.95,t), 2)`、vignette 0.18、grain ±1.2%、入场 800ms
- 性能：单 pass、fbm 五倍频 ≈ 20 次 hash/像素，60fps 富余

## 常见报错

| 症状 | 原因 |
|------|------|
| 云变成密密麻麻的方格 | `noise` 里缓动行 `u = f*f*(3-2f)` 被删——双线性直插，格子折面感全暴露 |
| 云有十字纺织纹 | fbm 的倍频用了 `p *= 2.0`——换旋转矩阵 `mat2(1.6,1.2,-1.2,1.6)` |
| 画面整体灰蒙无层次 | t 忘了再分布（直接 `palette(n)`）——乘 1.6 减 0.3 铺开 |
| 云越走越密像隧道冲刺 | 流动用了 `p * u_time`（缩放）而不是 `p + flow`（平移）——加法平移、乘法缩放 |
