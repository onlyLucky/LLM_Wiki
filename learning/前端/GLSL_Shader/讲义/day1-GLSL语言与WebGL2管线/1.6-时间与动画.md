# 1.6 时间与动画：让画面活过来

> Day 1 · 模块 6 · 约 50 分钟
> 理论对照：《WebGPU 三天实战课程》1.6「Uniform 与绑定组」——uniform 概念同源；本篇专注「时间」这一个 uniform 的全部工程学（[1.6-Uniform与绑定组.md](../../../webgpu/讲义/day1-原生WebGPU基础/1.6-Uniform与绑定组.md)）

到 1.5 为止，你的画面是一张精致的静图：全屏四边形、UV 坐标、软边圆——但鼠标不动它就永远不动。现在往 fragment shader 里加一个 float，一切开始流动：圆开始呼吸、条纹开始生长、方块开始弹跳。这个 float 叫 `u_time`，它是创意网站「活着的」全部秘密——awwwards 上每一个让你盯着看的页面，底层都是这一个 uniform 在推。这一讲把「时间」这一个 uniform 的全部工程学讲透：心智模型、单位与精度、三种循环波形、相位与频率的编排、四个缓动函数，收束于 demo 03「时间仪器馆」的四分屏。

## 动画三要素：清屏、状态、时间

GPU 是健忘的：每一帧它把画面完全忘掉，`gl.clear` 清空后从零重画一切。上一帧画了什么、画到一半没有，帧与帧之间不存在任何记忆——这不是缺陷，是设计。没有残留状态，就没有历史包袱，GPU 可以把全部算力花在「当前这一帧该是什么」上。

由此推出 shader 动画唯一正确的心智模型：**画面是一个纯函数，时间是唯一的自变量**——`f(time) → 画面`。给 3.7 秒，函数返回 3.7 秒那一刻的画面；给 100 次同样的 t，返回 100 次同样的画面。**shader 动画没有状态，只有时间**；这句话与 1.1 的「对一个像素做什么」并列，是本课第二句地基。

它和你写惯的 CSS 动画是两种世界观，对照表放这里：

| 维度 | CSS / JS 动画 | shader 动画 |
|------|--------------|-------------|
| 状态存放在哪 | 元素属性、JS 变量 | 不存放——uniform 里的时间就是全部输入 |
| 驱动方式 | 改属性，浏览器做补间 | 每帧从头重算 `f(time)` |
| 动画中断 | 要处理过渡打断、反向衔接 | 任意时刻传任意 t，直接精确求值 |
| 慢放 / 录屏 / 倒放 | 要回放模拟整条状态链 | 固定步长递增 t 逐帧截图，天然免费 |

可逆、可暂停、可录屏之所以免费，正因为函数是纯的：t = 3.7 的画面在过去、现在、未来都是同一张。Day 3 你会看到滚动驱动动画本质就是「把 t 换成滚动进度」——同一个模型换一个自变量。

与 rAF 的关系已被 `chrome.startLoop` 包好：它内部跑 `requestAnimationFrame`，顺带统计 FPS、刷新 pointer 平滑坐标、触发 800ms 入场淡入。你只需要提供那个纯函数：

```ts
// 你写的不是「动画系统」，是一个「给定时刻，算出画面」的回调
chrome.startLoop((nowMs) => {
  drawFrame(nowMs); // 纯函数：同样的 nowMs 永远画出同样的画面
});
```

## u_time 的单位与精度

`u_time` 的单位是秒，不是毫秒。`chrome.startLoop` 传给你的 `nowMs` 是 rAF 时间戳，单位毫秒——JS 侧必须先除以 1000 再写进 uniform。这是本课统一约定（总纲第 10 节）：`performance.now() / 1000` 的秒基准，让 shader 里的数字保持人读得懂的数量级。毫秒直接传进去，动画快 1000 倍，这是本讲头号坑。

频率直觉要从 `sin(u_time * 0.8)` 建立：0.8 是角频率（rad/s），周期 = 2π ÷ 0.8 ≈ 7.9 秒——约 8 秒一个完整呼吸周期，demo 01 的渐变呼吸就是这个参数。系数与周期的换算是你未来调动画的手感来源：

| sin 系数（rad/s） | 周期（2π ÷ 系数） | 体感 |
|------------------|------------------|------|
| 0.5 | 约 12.6s | 远景氛围，近乎静止 |
| 0.8 | 约 7.9s | 呼吸默认档（demo 01 在用） |
| 1.047 | 6s | 背景层流动 |
| 2.094 | 3s | 主元素脉动 |
| 6.0 | 约 1.0s | 心跳 / 警告频闪，慎用 |

精度有红线：u_time 一直累加，几分钟后画面开始抖。原因是 IEEE 754 单精度 float 只有 24 位有效尾数——数值越大，能表示的最小增量越大。t = 600 秒时最小步进约 0.06ms；高频动画 `sin(u_time * 40.0)` 每一步的相位跳变是 40 × 0.00006 ≈ 0.0024 rad，折回时间轴仍是 0.06ms 一档的台阶；t 到几小时步进继续变粗，高频层最先掉出肉眼可见的抖动（ES 3.00 片元侧 highp 已强制单精度，桌面与移动一处都不含糊）。工程处理一行搞定：

```glsl
u_time = time % 3600.0; // 每小时归零，精度回到原点；3600 是 3/4.5/6 的公倍数，回卷不跳变
```

选 3600 不是随意的：3s、4.5s、6s 全部整除 3600（1200 / 800 / 600 次），归零瞬间所有按节奏表走的动画恰好处于整数周期的同一相位，画面无缝复位。这行该写在 JS 侧（时间在 JS 是唯一状态源，见 How 节），写在 shader 里结果相同。

## 循环动画三件套：sin / fract / 模长

循环动画 90% 的场景只需要三个函数：`sin`、`fract`、`mod`。它们分别提供「平滑往复」「线性锯齿」「相位错峰」三种基本运动形态，组合起来能覆盖你能想到的绝大多数循环。

**sin 是呼吸**。`sin` 输出 -1..1 的平滑波，直接用它画面会「黑一半」——先做 `0.5 + 0.5 *` 映射到 0..1：

```glsl
// 三行呼吸：映射 → 半径 → 形状。-1..1 映到 0..1 后，值域才有资格当半径、当透明度
float pulse = 0.5 + 0.5 * sin(u_time * 2.094); // 周期 3s：系数 = 2π / 3
float r = 0.18 + 0.08 * pulse;                 // 半径在 0.10..0.26 之间涨缩
float circle = smoothstep(r, r - 0.02, length(p)); // 软边圆，边缘 0.02 反走样
```

**fract 是锯齿往复**。`fract` 取小数部分，输出 0..1 的锯齿；先乘 2 减 1 变成 -1..1，再 `abs` 折回来，得到 1→0→1 的三角波——匀速「去」匀速「回」，没有 sin 那种减速感：

```glsl
// 三角波：匀速往复，适合条形生长、进度扫描这类「机械感」运动
float tri = abs(fract(u_time / 3.0) * 2.0 - 1.0); // 周期 3s，1→0→1 往复
```

**mod 是相位错峰**。多个元素如果同时起步，画面像阅兵；给每个元素一个不同的延迟，层次感立刻出现：

```glsl
// 五根柱子依次起舞：第 i 根延迟 i * 0.25 秒，mod 让延迟循环不堆积
float i = floor(uv.x * 5.0);                      // 0..4 五列编号
float delay = mod(i * 0.25, 3.0);                 // 延迟封顶一个周期，错峰循环
float height = 0.5 + 0.5 * sin((u_time - delay) * 2.094); // 波浪从左往右传播
```

| 函数 | 曲线形态 | 运动质感 | 典型用途 |
|------|---------|---------|---------|
| `sin` | 平滑 S 波 | 有减速感，有机 | 呼吸、漂浮、光晕 |
| `fract`（+abs） | 三角折线 | 匀速机械 | 条形、扫描、进度 |
| `mod` | 不改波形，只错相位 | 层次与编排 | 多元素交错、波浪传播 |

三者的取舍一句话：有机的东西用 sin，机械的东西用三角波，一群东西用 mod 错峰。

## 相位与频率：让动画有编排

单个动画是节拍，多个动画按不同频率与相位组合才是编排。全课程约定一张节奏表——awwwards 动效的默认节奏，后续每个 demo 与作业的动效规格都从这里出发：

| 层级 | 周期 | sin 系数（2π ÷ 周期） | 典型角色 |
|------|------|----------------------|---------|
| 主元素 | 3s | 2.094 | hero 主体、点击反馈、光标光晕 |
| 次级 | 4.5s | 1.396 | 伴随元素、列表交错、次级图形 |
| 背景 | 6s | 1.047 | 氛围流动、大色块呼吸、噪声流速 |

这张表能成立的理由有两层。频率上，3 : 4.5 : 6 = 2 : 3 : 4 的简单比——全部同频画面像机械复制，完全乱频画面像噪声，1.5 倍与 2 倍的阶梯刚好落在「同一族但不同步」的编排区。相位上，同层元素用上一节的 `mod(i * 0.25, 周期)` 错峰，层与层之间靠周期差自然错开，不需要人为加偏移。

背下这张表的意义不在数字本身，而在「先分层再调参」的工作顺序：拿到任何动效需求，你先问主次背景分别是哪个、各自多大尺度，再把周期对号入座，参数就有了默认值——剩下才是创意微调。

## GLSL 缓动函数：easing 的 shader 写法

CSS 的 easing 搬不进 shader，因为时间在 shader 里不是 DOM 属性插值。浏览器里你写 `transition: transform 0.6s cubic-bezier(...)`，合成器替你在「属性随时间」的曲线上插值；shader 里没有属性可改，每帧都是从头求值——缓动必须自己写成 GLSL 函数：输入归一化时间 t（0..1），输出归一化进度（0..1，弹性类允许过冲）。

四个标准实现如下，函数名与签名全课程固定（`float easeXXX(float t)`，函数内 clamp），后续 demo 与作业直接引用这些名字，不再重复实现。来源是 easings.net 的标准公式：

```glsl
float easeInOutCubic(float t) {
  t = clamp(t, 0.0, 1.0);
  // 前半程立方加速、后半程立方减速，中点对接——「默认选它」的那一个
  return t < 0.5
    ? 4.0 * t * t * t
    : 1.0 - pow(-2.0 * t + 2.0, 3.0) / 2.0;
}

float easeOutQuint(float t) {
  t = clamp(t, 0.0, 1.0);
  // 五次幂减速：起步最猛、收尾最缓——「啪一下到位」的利落感
  return 1.0 - pow(1.0 - t, 5.0);
}

float easeOutElastic(float t) {
  t = clamp(t, 0.0, 1.0);
  if (t == 0.0 || t == 1.0) return t; // 端点精确归位，否则收尾有残影
  // 衰减正弦：pow 项是衰减包络（决定冲过量与收敛快慢），c4 = 2π/3 管震荡频率（1 内恰好三整周期）
  float c4 = 2.0943951;
  return pow(2.0, -10.0 * t) * sin((t * 10.0 - 0.75) * c4) + 1.0;
}

float easeOutBack(float t) {
  t = clamp(t, 0.0, 1.0);
  // c1 = 1.70158 是过冲约 10% 的经典系数——比 elastic 克制得多的一次回弹
  // 刻意用乘法展开而不是 pow(t - 1.0, 3.0)：t = 0 时底数是 -1.0，
  // GLSL 的 pow 对负底数没有定义（JS 的 Math.pow(-1, 3) 返回 -1，GLSL 却返回 NaN），
  // 一个 NaN 会顺着 scale、颜色一路传染，把整幅画面染成白色。
  // x * x 恒非负、x * x * x 乘法保号，结果与 JS 完全一致。
  float c1 = 1.70158;
  float c3 = c1 + 1.0;
  float x = t - 1.0;
  return 1.0 + c3 * x * x * x + c1 * x * x;
}
```

取舍建议直接给结论：转场与进度类 90% 的场景用 `easeInOutCubic`，别纠结；要「利落感」用 `easeOutQuint`；小元素的弹性反馈用 `easeOutElastic` 或 `easeOutBack`——且 elastic 禁止用在背景大元素上（理由见常见坑）。四条曲线的形状差异看图：

![四条缓动曲线并列对比图：标题「四条缓动曲线：时间如何变成运动」，横轴为归一化时间 t ∈ [0,1]，纵轴为输出值。左上格 linear / 线性：一条从原点到右上角的直线，标注「适用：进度底色 · 几乎不用」；右上格 easeInOutCubic / 平滑加减速：玫红色 S 形曲线，起步与收尾慢、中段快，标注「适用：主元素转场 · 默认选它」；左下格 easeOutElastic / 弹性过冲：天青色曲线，快速冲过终点后上下震荡数次收敛到 1，标注「适用：小元素回弹 · 禁用于背景（眩晕）」；右下格 easeOutBack / 回弹：琥珀色曲线，快速接近终点后轻微回拉再落定，标注「适用：按压反馈、松手弹回（demo 04）」](../../assets/diagrams/animation-easing.svg)

对着图最值得盯住的是 easeOutElastic 那条天青线：它越过纵轴 1 的位置再震荡回来——所有「越界再收敛」的弹性手感都来自这个过冲，眩晕风险也来自它：过冲意味着画面元素超出目标位置，大面积、大幅度地反复越界，眼球会跟着震荡。顺手补一个省代码的常识：`smoothstep(edge0, edge1, x)` 内置的三次 Hermite 曲线（`3t² - 2t³`）本身就是 easeInOut 家族的表亲，软边、渐显、渐隐不需要手写缓动，内置的就够。

## How：demo 03「时间仪器馆」逐段精讲

demo 03 是你的第一份「会动的 shader」，也是一间可以常开的缓动仪器馆：2×2 四分屏，四台仪器——呼吸灯、示波器、弹簧摆、进度弧——共用同一个相位运转，底部一条公共进度条统一对表。它只有两个 uniform：`u_time` 与 `u_resolution`，下面按 fragment 的实际段落过一遍，代码即蓝本。

顶点着色器与 demo 02 逐字相同——无 varying，uv 全部在 fragment 里现算。这个 demo 的全部戏剧都发生在 fragment，顶点着色器退居幕后：

```glsl
#version 300 es
layout(location = 0) in vec2 a_position;

void main() {
  gl_Position = vec4(a_position, 0.0, 1.0);
}
```

fragment 的头部先立好馆内的色板——BG 是馆内底色，FACE 是四块表盘面，ROSE / CYAN 组成双色铭牌系统：

```glsl
#version 300 es
precision highp float;

uniform vec2 u_resolution;
uniform float u_time; // 秒，JS 侧已做 % 3600 精度处理

out vec4 fragColor;

const float TAU = 6.2831853;                 // 一整圈的弧度，2π
const vec3 BG   = vec3(0.055, 0.070, 0.105); // 仪器馆底色
const vec3 ROSE = vec3(1.000, 0.302, 0.427); // #FF4D6D
const vec3 CYAN = vec3(0.298, 0.624, 0.941); // #4CC9F0
const vec3 FACE = vec3(0.078, 0.094, 0.137); // 表盘面
```

注意这里没有 u_aspect：分格发生在 fragment 内部，格内域的宽高比与整屏相同，aspect 直接从 u_resolution 算出——uniform 表越短，接线越简单。

main() 开场是标准起手式：现算 uv（1.5 两条 UV 路里的现算路）、算 aspect、给全局 `gPx` 赋值——三行之后，分格才开始。分格本身仍是「`floor` 算格编号 + `fract` 取格内坐标」两步，这是 1.5 坐标系知识第一次组合应用；最后一步把时间归一化成相位：`u_time / 3.0` 把秒换算成圈数，`fract` 去整存零，剩下的 0..1 小数就是四台仪器共读的那块「表」：

```glsl
void main() {
  vec2 uv = gl_FragCoord.xy / u_resolution;
  float aspect = u_resolution.x / u_resolution.y;
  gPx = 1.0 / u_resolution.y;

  // 2x2 分格：cell 记格编号（0 或 1），guv 是格内 0-1 坐标
  vec2 cell = floor(uv * 2.0);
  vec2 guv  = fract(uv * 2.0);
  vec2 p = (guv - 0.5) * vec2(aspect, 1.0); // 格内中心坐标，x 校正屏幕等距

  // 相位归一化：主节奏 3 秒一圈——四台仪器共用同一相位（对表）
  float phase = fract(u_time / 3.0);
```

四个面板共用一层工具，先看工具层：两条循环波形（前两节刚讲过的标准写法）+ 1.5 的 stroke / fill 描边家族（`gPx` 是全局变量，main 里赋值一次、全员共享）+ 一个环形刻度盘。缓动函数直接用本讲前文定稿的标准实现，不再重复：

```glsl
// 呼吸：sin 值域天生 [-1,1]，0.5 + 0.5x 拉回 [0,1] 才能当系数用
float breathe(float t) {
  return 0.5 + 0.5 * sin(t * TAU);
}

// 三角波：fract 给出锯齿，abs 把斜坡对折一次成对称三角
float triangleWave(float t) {
  return abs(fract(t) * 2.0 - 1.0);
}

// hash 噪声：胶片颗粒的原料
float hash(vec2 p) {
  return fract(sin(dot(p, vec2(127.1, 311.7))) * 43758.5453);
}

float gPx; // 1 物理像素（uv 域长度），供描边函数抗锯齿
float stroke(float d) { return 1.0 - smoothstep(0.0, gPx * 1.5, abs(d)); }
float fill(float d)   { return 1.0 - smoothstep(0.0, gPx * 1.5, d); }
float sdBox(vec2 p, vec2 b) {
  vec2 d = abs(p) - b;
  return length(max(d, 0.0)) + min(max(d.x, d.y), 0.0);
}

// 环形刻度盘：ang（0..TAU）角向 n 等分，刻度画在 [r0, r1] 径向带内
float dialTicks(float ang, float r, float n, float r0, float r1) {
  float aDist = abs(fract(ang / TAU * n + 0.5) - 0.5) * TAU / n;
  return stroke(aDist * r) * smoothstep(r0 - 0.006, r0, r) * (1.0 - smoothstep(r1, r1 + 0.006, r));
}
```

然后是四台仪器，一格一个面板函数，写法全部同构：`FACE` 表盘打底，若干层 `mix(col, accent, mask)` 叠图形——这份 fragment 就是你未来的缓动速查表：

```glsl
// ---- 左下 · 呼吸灯：灯芯半径随 breathe 胀缩，外圈 8 刻度参考环 ----
vec3 panelBreathe(vec2 p, float phase, vec3 accent) {
  vec3 col = FACE;
  float r = length(p);
  float lampR = 0.08 + 0.20 * breathe(phase);          // 灯芯半径 = 相位的正弦呼吸
  col = mix(col, accent, fill(r - lampR) * 0.85);      // 灯芯
  float glow = pow(clamp(1.0 - r / (lampR + 0.14), 0.0, 1.0), 2.0);
  col = mix(col, accent, glow * 0.22);                 // 灯晕：贴着灯芯二次衰减
  col = mix(col, accent, stroke(r - 0.34) * 0.30);     // 静态参考环
  float a = atan(p.x, p.y);                            // 从顶部起、顺时针为正
  col = mix(col, accent, dialTicks(a, r, 8.0, 0.36, 0.40) * 0.5);
  return col;
}

// ---- 右下 · 示波器：三角波向右滚动，中央读数点读当前值 ----
vec3 panelScope(vec2 guv, float phase, vec3 accent) {
  vec3 col = FACE;
  vec2 g = abs(fract(guv * 4.0) - 0.5) / 4.0;          // 屏面 0.25 细网格
  col = mix(col, accent, stroke(min(g.x, g.y)) * 0.08);
  float wave = triangleWave(guv.x * 2.0 - phase * 2.0); // x 上 2 个周期，随相位滚动
  float wy = mix(0.22, 0.78, wave);
  col = mix(col, accent, stroke(guv.y - wy) * 0.90);   // 波形线
  float readX = 0.5;                                    // 中央读数点：波形流过它
  float waveY = mix(0.22, 0.78, triangleWave(readX * 2.0 - phase * 2.0));
  col = mix(col, vec3(1.0), stroke(guv.x - readX) * 0.10);
  col = mix(col, vec3(1.0), fill(length(guv - vec2(readX, waveY)) - gPx * 1.5));
  return col;
}

// ---- 左上 · 弹簧摆：滑块冲过目标线、回弹归位（easeOutElastic）----
vec3 panelSpring(vec2 p, float phase, vec3 accent) {
  vec3 col = FACE;
  float bx = (easeOutElastic(phase) - 0.5) * 0.62;      // 滑块位置 -0.31..0.31
  col = mix(col, accent, stroke(p.y) * (1.0 - smoothstep(0.30, 0.32, abs(p.x))) * 0.45); // 轨道
  float tickX = abs(fract((p.x + 0.31) / 0.155) - 0.5) * 0.155; // 5 档刻度
  float tick = stroke(tickX)
             * smoothstep(0.014, 0.016, abs(p.y)) * (1.0 - smoothstep(0.032, 0.034, abs(p.y)))
             * (1.0 - smoothstep(0.32, 0.33, abs(p.x)));
  col = mix(col, accent, tick * 0.5);
  float goal = stroke(p.x - 0.31) * step(0.5, fract(p.y * 24.0)) * (1.0 - smoothstep(0.05, 0.06, abs(p.y)));
  col = mix(col, vec3(1.0), goal * 0.30);               // 右端目标线（虚线）
  col = mix(col, accent, fill(sdBox(p - vec2(bx, 0.0), vec2(0.030, 0.024)) - 0.008) * 0.95); // 圆角滑块
  return col;
}

// ---- 右上 · 进度弧：easeInOut 让指针先加速后减速扫过一整圈 ----
vec3 panelDial(vec2 p, float phase, vec3 accent) {
  vec3 col = FACE;
  float sweep = easeInOutCubic(phase) * TAU;            // 缓动角速度
  float a = atan(p.x, p.y);                             // 从顶部起、顺时针为正
  float aN = fract(a / TAU);                            // 归一 0..1（顶部 0）
  float r = length(p);
  col = mix(col, accent, stroke(r - 0.26) * 0.12);      // 暗轨道
  col = mix(col, accent, stroke(r - 0.26) * step(aN, sweep / TAU) * 0.95); // 已扫亮弧
  vec2 tipPos = vec2(sin(sweep), cos(sweep)) * 0.26;    // 端点亮点
  col = mix(col, vec3(1.0), fill(length(p - tipPos) - gPx * 2.0));
  col = mix(col, accent, dialTicks(a, r, 12.0, 0.30, 0.34) * 0.5); // 12 刻度表盘
  col = mix(col, accent, fill(r - gPx * 1.5) * 0.6);    // 轴心
  return col;
}
```

逐台点名它们在演示哪条曲线：呼吸灯的灯芯半径直接吃 `breathe(phase)`——sin 的标准三行映射；示波器的波形线是 `triangleWave` 沿横轴滚动——三角波的机械感肉眼可见；弹簧摆的滑块位置是 `easeOutElastic(phase)`——每 3 秒冲过右端白色目标线、弹回收定；进度弧的扫角是 `easeInOutCubic(phase) * TAU`——先加速后减速扫满一圈。同一个相位喂进四条曲线，一间仪器馆就成了四条曲线的并排演示。

主体合成段是「挑格子 + 上装修」：按格选面板——左下呼吸灯 / 右下示波器 / 左上弹簧摆 / 右上进度弧——双色对角交替（左下与右上玫红、右下与左上天青），然后统一加装修层：

```glsl
  // 挑格子：左下呼吸灯 / 右下示波器 / 左上弹簧摆 / 右上进度弧，双色交替
  vec3 col;
  if (cell.y < 0.5) {
    if (cell.x < 0.5) { col = panelBreathe(p, phase, ROSE); }
    else              { col = panelScope(guv, phase, CYAN); }
  } else {
    if (cell.x < 0.5) { col = panelSpring(p, phase, CYAN); }
    else              { col = panelDial(p, phase, ROSE); }
  }

  // 当前格的 accent（铭牌用）
  vec3 accent = (cell.x != cell.y) ? CYAN : ROSE;

  // 面板边框：内缩 1.8% 的矩形描边
  vec2 edge = min(guv, 1.0 - guv);
  col = mix(col, vec3(0.17, 0.21, 0.28), stroke(min(edge.x, edge.y) - 0.018) * 0.5);

  // 左上铭牌：accent 短横条（四台仪器的「编号牌」）
  col = mix(col, accent, fill(sdBox(guv - vec2(0.055, 0.935), vec2(0.045, 0.010))) * 0.9);

  // 格间暗缝：格内坐标贴边 0.4% 的位置压暗
  float seam = step(edge.x, 0.004) + step(edge.y, 0.004);
  col = mix(col, vec3(0.02), clamp(seam, 0.0, 1.0) * 0.9);

  // 底部公共进度条：与四台仪器共用相位，走到哪一目了然（对表用）
  float progress = step(uv.y, 0.012) * step(uv.x, phase);
  col = mix(col, vec3(1.0), progress * 0.25);

  // 仪器馆 6s 极慢呼吸：整体 ±2% 亮度摆动，几乎察觉不到但画面是活的
  float slow = 0.5 + 0.5 * sin(u_time * TAU / 6.0);
  col *= 1.0 + 0.02 * (slow - 0.5);

  // 胶片颗粒 ±1%：每像素每帧独立噪声，压住大面积纯色的塑料感
  col += (hash(gl_FragCoord.xy) - 0.5) * 0.02;

  fragColor = vec4(col, 1.0);
}
```

结构上一条分界线值得记住：面板函数只管「表盘内部」，装修层——边框、铭牌、暗缝、进度条、呼吸、颗粒——全部留在 main：面板可以随便换，馆的装修不动。四台仪器的颜色由 `(cell.x != cell.y)` 一行定：格编号相等的对角（左下、右上）拿 ROSE，其余两格拿 CYAN。底部公共进度条 `step(uv.x, phase)` 与仪器共用相位：进度条走满的瞬间，四台仪器恰好同时复位——这就是「对表」的可见证据。

JS 侧的帧循环——每帧只喂两个 uniform，全部动画逻辑都在 shader 里：

```ts
// ---- uniform：分辨率 / 时间（没有鼠标——这是一个纯时间驱动的 demo）
const uResolution = gl.getUniformLocation(program, 'u_resolution');
const uTime = gl.getUniformLocation(program, 'u_time');

// ---- 帧循环：每帧只喂秒数，全部动画逻辑都在 shader 里 -----------
const start = performance.now();
chrome.startLoop((now) => {
  // 毫秒转秒（契约）；% 3600 防 float 尾数耗尽，且 3600 是 3/4.5/6 的公倍数，回卷无跳变
  const t = ((now - start) / 1000) % 3600;

  gl.viewport(0, 0, chrome.width, chrome.height);

  gl.useProgram(program);
  gl.uniform2f(uResolution, chrome.width, chrome.height);
  gl.uniform1f(uTime, t);

  gl.clearColor(0.043, 0.055, 0.078, 1.0);
  gl.clear(gl.COLOR_BUFFER_BIT);

  gl.drawArrays(gl.TRIANGLE_STRIP, 0, 4);
});
```

三处契约落在这几行里。`(now - start) / 1000` 让计时从 0 起步——`% 3600` 的回卷因此恰好落在整数相位上，比拿 rAF 时间戳直接取模更干净；`u_resolution` 每帧重传，窗口缩放时 aspect 与 gPx 自动跟随，四台仪器的形状不会变形；没有 u_aspect 这个 uniform，`useProgram` 之后的 uniform 表就只剩两行，接线越短越不容易错。

节奏表 3s / 4.5s / 6s 在这间馆里的落点：主元素 3s 升格为全馆唯一主相位——四台仪器共用，一台节拍器管四台仪器；背景 6s 用在馆内呼吸上（±2% 亮度摆动，几乎察觉不到，但画面是活的）；4.5s 这一档刻意空缺——「共用相位」是这间馆的主题，节奏越少，对表越清楚，等你在 2.x 有了多图形编排的需求，再把次级节奏请回来。对着 demo 数一遍：每 3 秒四台仪器同时复位、底部公共进度条同步走满一圈——先看进度条确认对表，再逐格观察四条曲线在同一相位下的不同手感：sin 的圆融、三角波的机械、elastic 的弹跳、cubic 的从容。

## 常见坑

| 症状 | 原因 |
|------|------|
| 动画快 1000 倍，像快进 | 把 rAF 的毫秒时间戳直接写进 u_time。`nowMs / 1000` 转秒，这是全课程契约 |
| 画面有一半永远黑的 | `sin()` 直接当透明度或半径用。负值区被 clamp 成 0——先 `0.5 + 0.5 * sin(...)` 映到 0..1 |
| 换帧率动画节奏就变，且没法暂停重放 | 用 dt 累积当时间。dt 累积是 JS 侧状态，shader 无状态；坚持传绝对时间，节奏由公式决定而非帧率 |
| 看一会儿头晕想吐 | easeOutElastic 用在背景大元素上。过冲震荡留给小元素，背景一律 sin 或 smoothstep |
| 页面开几分钟后画面开始抖 | u_time 一直累加，float 尾数耗尽。JS 侧 `time % 3600`，选 3600 因为它是节奏表的公倍数 |
| 缓动动画的进度偶尔冲出画面或弹飞 | 缓动函数忘了 clamp 输入 t。t 来自 `mod`、`fract` 的除法链，浮点误差会让它略微越界 |

## Checkpoint

- 能写出呼吸动画完整三行：`0.5 + 0.5 * sin(...)` 映射、半径合成、`smoothstep` 成形——合上讲义手写出来
- 能解释纯函数动画模型与 CSS 动画的心智差异：一个「时间决定画面、无状态」，一个「改属性、有状态」；并说清由此免费获得的三样东西（可逆、可暂停、可录屏）
- 能背出节奏表「主 3s / 次 4.5s / 背景 6s」，并把周期换算成 sin 系数（2π ÷ 周期 = 2.094 / 1.396 / 1.047）
- 能默写四个缓动函数的签名与适用场景，说出 elastic 禁用于背景大元素的原因（过冲震荡引发眩晕）
- 能解释 u_time 为什么要 `% 3600`，以及为什么 3600 这个数能保证回卷时画面无跳变
