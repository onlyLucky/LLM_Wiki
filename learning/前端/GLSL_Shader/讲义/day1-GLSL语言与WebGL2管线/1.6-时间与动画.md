# 1.6 时间与动画：让画面活过来

> Day 1 · 模块 6 · 约 50 分钟
> 理论对照：《WebGPU 三天实战课程》1.6「Uniform 与绑定组」——uniform 概念同源；本篇专注「时间」这一个 uniform 的全部工程学（[1.6-Uniform与绑定组.md](../../../webgpu/讲义/day1-原生WebGPU基础/1.6-Uniform与绑定组.md)）

到 1.5 为止，你的画面是一张精致的静图：全屏四边形、UV 坐标、软边圆——但鼠标不动它就永远不动。现在往 fragment shader 里加一个 float，一切开始流动：圆开始呼吸、条纹开始生长、方块开始弹跳。这个 float 叫 `u_time`，它是创意网站「活着的」全部秘密——awwwards 上每一个让你盯着看的页面，底层都是这一个 uniform 在推。这一讲把「时间」这一个 uniform 的全部工程学讲透：心智模型、单位与精度、三种循环波形、相位与频率的编排、四个缓动函数，收束于 demo 03 的四分屏。

## 动画三要素：清屏、状态、时间

GPU 是健忘的：每一帧它把画面完全忘掉，`gl.clear` 清空后从零重画一切。上一帧画了什么、画到一半没有，帧与帧之间不存在任何记忆——这不是缺陷，是设计。没有残留状态，就没有历史包袱，GPU 可以把全部算力花在「当前这一帧该是什么」上。

由此推出 shader 动画唯一正确的心智模型：**画面是一个纯函数，时间是唯一的自变量**——`f(time) → 画面`。给 3.7 秒，函数返回 3.7 秒那一刻的画面；给 100 次同样的 t，返回 100 次同样的画面。**shader 动画没有状态，只有时间**；这句话与 1.1 的「对一个像素做什么」并列，是本课第二句地基。

它和你写惯的 CSS 动画是两种世界观，对照表放这里：

| 维度 | CSS / JS 动画 | shader 动画 |
|------|--------------|-------------|
| 状态存放在哪 | 元素属性、JS 变量 | 不存放——uniform 里的时间就是全部输入 |
| 驱动方式 | 改属性，浏览器做补间 | 每帧从头重算 `f(time)` |
| 动画中断 | 要处理过渡打断、反向衔接 | 任意时刻传任意 t，直接精确求值 |
| 慢放 / 录屏 / 倒放 | 要回放模拟整条状态链 | 固定步长递增 t 逐帧截图，天然免费 |

可逆、可暂停、可录屏之所以免费，正因为函数是纯的：t = 3.7 的画面在过去、现在、未来都是同一张。Day 3 你会看到滚动驱动动画本质就是「把 t 换成滚动进度」——同一个模型换一个自变量。

与 rAF 的关系已被 `chrome.startLoop` 包好：它内部跑 `requestAnimationFrame`，顺带统计 FPS、刷新 pointer 平滑坐标、触发 800ms 入场淡入。你只需要提供那个纯函数：

```ts
// 你写的不是「动画系统」，是一个「给定时刻，算出画面」的回调
chrome.startLoop((nowMs) => {
  drawFrame(nowMs); // 纯函数：同样的 nowMs 永远画出同样的画面
});
```

## u_time 的单位与精度

`u_time` 的单位是秒，不是毫秒。`chrome.startLoop` 传给你的 `nowMs` 是 rAF 时间戳，单位毫秒——JS 侧必须先除以 1000 再写进 uniform。这是本课统一约定（总纲第 10 节）：`performance.now() / 1000` 的秒基准，让 shader 里的数字保持人读得懂的数量级。毫秒直接传进去，动画快 1000 倍，这是本讲头号坑。

频率直觉要从 `sin(u_time * 0.8)` 建立：0.8 是角频率（rad/s），周期 = 2π ÷ 0.8 ≈ 7.9 秒——约 8 秒一个完整呼吸周期，demo 01 的渐变呼吸就是这个参数。系数与周期的换算是你未来调动画的手感来源：

| sin 系数（rad/s） | 周期（2π ÷ 系数） | 体感 |
|------------------|------------------|------|
| 0.5 | 约 12.6s | 远景氛围，近乎静止 |
| 0.8 | 约 7.9s | 呼吸默认档（demo 01 在用） |
| 1.047 | 6s | 背景层流动 |
| 2.094 | 3s | 主元素脉动 |
| 6.0 | 约 1.0s | 心跳 / 警告频闪，慎用 |

精度有红线：u_time 一直累加，几分钟后画面开始抖。原因是 IEEE 754 单精度 float 只有 24 位有效尾数——数值越大，能表示的最小增量越大。t = 600 秒时最小步进约 0.06ms，高频动画 `sin(u_time * 40.0)` 的相位抖动就是 40 × 0.06 ≈ 2.4ms；t 到几小时，抖动超过半帧，肉眼可见（部分移动 GPU 的 highp 实现还会更早暴露）。工程处理一行搞定：

```glsl
u_time = time % 3600.0; // 每小时归零，精度回到原点；3600 是 3/4.5/6 的公倍数，回卷不跳变
```

选 3600 不是随意的：3s、4.5s、6s 全部整除 3600（1200 / 800 / 600 次），归零瞬间所有按节奏表走的动画恰好处于整数周期的同一相位，画面无缝复位。这行该写在 JS 侧（时间在 JS 是唯一状态源，见 How 节），写在 shader 里结果相同。

## 循环动画三件套：sin / fract / 模长

循环动画 90% 的场景只需要三个函数：`sin`、`fract`、`mod`。它们分别提供「平滑往复」「线性锯齿」「相位错峰」三种基本运动形态，组合起来能覆盖你能想到的绝大多数循环。

**sin 是呼吸**。`sin` 输出 -1..1 的平滑波，直接用它画面会「黑一半」——先做 `0.5 + 0.5 *` 映射到 0..1：

```glsl
// 三行呼吸：映射 → 半径 → 形状。-1..1 映到 0..1 后，值域才有资格当半径、当透明度
float pulse = 0.5 + 0.5 * sin(u_time * 2.094); // 周期 3s：系数 = 2π / 3
float r = 0.18 + 0.08 * pulse;                 // 半径在 0.10..0.26 之间涨缩
float circle = smoothstep(r, r - 0.02, length(p)); // 软边圆，边缘 0.02 反走样
```

**fract 是锯齿往复**。`fract` 取小数部分，输出 0..1 的锯齿；先乘 2 减 1 变成 -1..1，再 `abs` 折回来，得到 1→0→1 的三角波——匀速「去」匀速「回」，没有 sin 那种减速感：

```glsl
// 三角波：匀速往复，适合条形生长、进度扫描这类「机械感」运动
float tri = abs(fract(u_time / 3.0) * 2.0 - 1.0); // 周期 3s，1→0→1 往复
```

**mod 是相位错峰**。多个元素如果同时起步，画面像阅兵；给每个元素一个不同的延迟，层次感立刻出现：

```glsl
// 五根柱子依次起舞：第 i 根延迟 i * 0.25 秒，mod 让延迟循环不堆积
float i = floor(uv.x * 5.0);                      // 0..4 五列编号
float delay = mod(i * 0.25, 3.0);                 // 延迟封顶一个周期，错峰循环
float height = 0.5 + 0.5 * sin((u_time - delay) * 2.094); // 波浪从左往右传播
```

| 函数 | 曲线形态 | 运动质感 | 典型用途 |
|------|---------|---------|---------|
| `sin` | 平滑 S 波 | 有减速感，有机 | 呼吸、漂浮、光晕 |
| `fract`（+abs） | 三角折线 | 匀速机械 | 条形、扫描、进度 |
| `mod` | 不改波形，只错相位 | 层次与编排 | 多元素交错、波浪传播 |

三者的取舍一句话：有机的东西用 sin，机械的东西用三角波，一群东西用 mod 错峰。

## 相位与频率：让动画有编排

单个动画是节拍，多个动画按不同频率与相位组合才是编排。全课程约定一张节奏表——awwwards 动效的默认节奏，后续每个 demo 与作业的动效规格都从这里出发：

| 层级 | 周期 | sin 系数（2π ÷ 周期） | 典型角色 |
|------|------|----------------------|---------|
| 主元素 | 3s | 2.094 | hero 主体、点击反馈、光标光晕 |
| 次级 | 4.5s | 1.396 | 伴随元素、列表交错、次级图形 |
| 背景 | 6s | 1.047 | 氛围流动、大色块呼吸、噪声流速 |

这张表能成立的理由有两层。频率上，3 : 4.5 : 6 = 2 : 3 : 4 的简单比——全部同频画面像机械复制，完全乱频画面像噪声，1.5 倍与 2 倍的阶梯刚好落在「同一族但不同步」的编排区。相位上，同层元素用上一节的 `mod(i * 0.25, 周期)` 错峰，层与层之间靠周期差自然错开，不需要人为加偏移。

背下这张表的意义不在数字本身，而在「先分层再调参」的工作顺序：拿到任何动效需求，你先问主次背景分别是哪个、各自多大尺度，再把周期对号入座，参数就有了默认值——剩下才是创意微调。

## GLSL 缓动函数：easing 的 shader 写法

CSS 的 easing 搬不进 shader，因为时间在 shader 里不是 DOM 属性插值。浏览器里你写 `transition: transform 0.6s cubic-bezier(...)`，合成器替你在「属性随时间」的曲线上插值；shader 里没有属性可改，每帧都是从头求值——缓动必须自己写成 GLSL 函数：输入归一化时间 t（0..1），输出归一化进度（0..1，弹性类允许过冲）。

四个标准实现如下，函数名与签名全课程固定（`float easeXXX(float t)`，函数内 clamp），后续 demo 与作业直接引用这些名字，不再重复实现。来源是 easings.net 的标准公式：

```glsl
float easeInOutCubic(float t) {
  t = clamp(t, 0.0, 1.0);
  // 前半程立方加速、后半程立方减速，中点对接——「默认选它」的那一个
  return t < 0.5
    ? 4.0 * t * t * t
    : 1.0 - pow(-2.0 * t + 2.0, 3.0) / 2.0;
}

float easeOutQuint(float t) {
  t = clamp(t, 0.0, 1.0);
  // 五次幂减速：起步最猛、收尾最缓——「啪一下到位」的利落感
  return 1.0 - pow(1.0 - t, 5.0);
}

float easeOutElastic(float t) {
  t = clamp(t, 0.0, 1.0);
  if (t == 0.0 || t == 1.0) return t; // 端点精确归位，否则收尾有残影
  // 衰减正弦：冲过目标后震荡收敛，6.2831853 / 3.0 控制过冲幅度
  float c4 = 2.0943951;
  return pow(2.0, -10.0 * t) * sin((t * 10.0 - 0.75) * c4) + 1.0;
}

float easeOutBack(float t) {
  t = clamp(t, 0.0, 1.0);
  // c1 = 1.70158 是过冲约 10% 的经典系数——比 elastic 克制得多的一次回弹
  float c1 = 1.70158;
  float c3 = c1 + 1.0;
  return 1.0 + c3 * pow(t - 1.0, 3.0) + c1 * pow(t - 1.0, 2.0);
}
```

取舍建议直接给结论：转场与进度类 90% 的场景用 `easeInOutCubic`，别纠结；要「利落感」用 `easeOutQuint`；小元素的弹性反馈用 `easeOutElastic` 或 `easeOutBack`——且 elastic 禁止用在背景大元素上（理由见常见坑）。四条曲线的形状差异看图：

![四条缓动曲线并列对比图：标题「四条缓动曲线：时间如何变成运动」，横轴为归一化时间 t ∈ [0,1]，纵轴为输出值。左上格 linear / 线性：一条从原点到右上角的直线，标注「适用：进度底色 · 几乎不用」；右上格 easeInOutCubic / 平滑加减速：玫红色 S 形曲线，起步与收尾慢、中段快，标注「适用：主元素转场 · 默认选它」；左下格 easeOutElastic / 弹性过冲：天青色曲线，快速冲过终点后上下震荡数次收敛到 1，标注「适用：小元素回弹 · 禁用于背景（眩晕）」；右下格 easeOutBack / 回弹：琥珀色曲线，快速接近终点后轻微回拉再落定，标注「适用：按压反馈、松手弹回（demo 04）」](../../assets/diagrams/animation-easing.svg)

对着图最值得盯住的是 easeOutElastic 那条天青线：它越过纵轴 1 的位置再震荡回来——所有「越界再收敛」的弹性手感都来自这个过冲，眩晕风险也来自它：过冲意味着画面元素超出目标位置，大面积、大幅度地反复越界，眼球会跟着震荡。顺手补一个省代码的常识：`smoothstep(edge0, edge1, x)` 内置的三次 Hermite 曲线（`3t² - 2t³`）本身就是 easeInOut 家族的表亲，软边、渐显、渐隐不需要手写缓动，内置的就够。

## How：demo 03「时间的画面」逐段精讲

demo 03 是你的第一份「会动的 shader」，也是一份可以常开的缓动速查可视化：2×2 四分屏，每格演示一种循环动画，底部一条进度条统一报时。它由两个 uniform 驱动——`u_time` 与 `u_aspect`——下面按 fragment 的实际段落过一遍，代码即蓝本。

顶点着色器沿用 1.5 的全屏四边形，四顶点 TRIANGLE_STRIP，`v_uv` 直接由 clip space 换算：

```glsl
#version 300 es
layout(location = 0) in vec2 a_position;
out vec2 v_uv;
void main() {
  v_uv = a_position * 0.5 + 0.5; // clip space (-1..1) 换算 UV (0..1)，全屏四边形不需要矩阵
  gl_Position = vec4(a_position, 0.0, 1.0);
}
```

fragment 的头部先立好节奏表的代码形态——周期不写死在调用处，集中定义成常量，调节奏只改一处：

```glsl
#version 300 es
precision highp float;

uniform float u_time;   // 秒，JS 侧已做 % 3600 精度处理
uniform float u_aspect; // 画布宽高比，横轴等比修正

out vec4 fragColor;

const float TAU = 6.2831853;
// 节奏表（全课程约定）：主 3s / 次 4.5s / 背景 6s——系数 = 2π ÷ 周期
const float F_MAIN = TAU / 3.0;
const float F_SUB  = TAU / 4.5;
const float F_BG   = TAU / 6.0;
```

四格的核心是「分格 + 局部坐标重映射」两步：`floor` 算出格编号，`fract` 取格内坐标再压回 -1..1 居中域——这是 1.5 坐标系知识第一次组合应用：

```glsl
void main() {
  // 四分屏：floor 分格编号，fract 取格内局部坐标，重映射到 -1..1 居中域
  vec2 cell = floor(v_uv * 2.0);
  vec2 p = fract(v_uv * 2.0) * 2.0 - 1.0;
  p.x *= u_aspect * 0.5; // 每格物理宽度只有半幅，等比修正后圆才是圆（1.5 的 aspect 陷阱）
```

四个动画函数一格一个，函数名即内容——这份 fragment 就是你未来的 easing 速查表：

```glsl
// 格 1 · 呼吸圆：sin 驱动半径涨缩，主元素节奏 3s
float breathingCircle(vec2 p) {
  float pulse = 0.5 + 0.5 * sin(u_time * F_MAIN); // -1..1 映到 0..1，再当半径系数
  float r = 0.18 + 0.08 * pulse;                  // 半径 0.10..0.26 呼吸
  return smoothstep(r, r - 0.02, length(p));      // 软边圆
}

// 格 2 · 三角波条：fract 往复 + mod 相位错峰，六根条依次生长，次级节奏 4.5s
float triangleBars(vec2 p) {
  float col = floor((p.x + 1.0) * 3.0);           // 0..5 六列编号
  float delay = mod(col * 0.25, 4.5);             // 每列延迟 0.25s，错峰封顶一个周期
  float tri = abs(fract((u_time - delay) / 4.5) * 2.0 - 1.0); // 1→0→1 三角往复
  float h = mix(-0.8, 0.8, tri);                  // 条顶升到顶再落回
  return smoothstep(h, h - 0.03, p.y);            // 低于条顶的区域画满
}

// 格 3 · 弹性方块：easeOutElastic 每 4.5s 从左弹到右，弹完静置
float elasticSquare(vec2 p) {
  float cycle = mod(u_time, 4.5) / 4.5;           // 周期归一化到 0..1
  float t = easeOutElastic(min(cycle * 2.0, 1.0)); // 前半程弹射，后半程停住呼吸
  float x = mix(-0.6, 0.6, t);                    // 方块中心横移
  float d = max(abs(p.x - x) - 0.15, abs(p.y) - 0.15); // 方块 SDF，讲义 2.1 正式展开
  return smoothstep(0.01, -0.01, d);
}

// 格 4 · 缓动进度条：6s（背景节奏）往复，easeInOutCubic 决定填充节奏
float easedBar(vec2 p) {
  float pingpong = abs(fract(u_time / 6.0) * 2.0 - 1.0); // 三角往复 0→1→0
  float e = easeInOutCubic(pingpong);             // 归一化时间 → 缓动后的进度
  return step(p.x, mix(-1.0, 1.0, e));            // 从左填充到 e 对应的位置
}
```

主体合成段：按格选函数、对角同色、底部进度条。色板用课程约定（玫红主、天青辅、琥珀点缀）：

```glsl
  float g = 0.0; // 每格一个动画函数，分支只在格边界发生
  if (cell.y < 0.5) {
    g = cell.x < 0.5 ? breathingCircle(p) : triangleBars(p);
  } else {
    g = cell.x < 0.5 ? elasticSquare(p) : easedBar(p);
  }

  vec3 bg = vec3(0.063, 0.082, 0.122);            // #10151F 四格统一底色
  vec3 rose = vec3(1.0, 0.302, 0.427);            // #FF4D6D 主色
  vec3 cyan = vec3(0.298, 0.788, 0.941);          // #4CC9F0 辅色
  vec3 accent = mod(cell.x + cell.y, 2.0) < 0.5 ? rose : cyan; // 对角同色，避免相邻撞色

  vec3 col = mix(bg, accent, g);

  // 底部进度条：18s 是 3/4.5/6 的最小公倍数，一圈走完所有动画恰好复位
  float progress = mod(u_time, 18.0) / 18.0;
  float bar = step(v_uv.x, progress) * (1.0 - step(0.05, v_uv.y));
  col += bar * vec3(1.0, 0.757, 0.271);           // #FFC145 琥珀点缀

  fragColor = vec4(col, 1.0);
}
```

JS 侧的时间接线只有五行，但每一行都是契约：

```ts
const uTime = gl.getUniformLocation(program, 'u_time');
const uAspect = gl.getUniformLocation(program, 'u_aspect');

chrome.startLoop((nowMs) => {
  const time = (nowMs / 1000) % 3600; // 毫秒转秒（契约）；% 3600 精度保险，回卷无跳变
  gl.uniform1f(uTime, time);
  gl.uniform1f(uAspect, chrome.width / chrome.height);
  gl.drawArrays(gl.TRIANGLE_STRIP, 0, 4); // 清屏在循环外一次性配置好 clearColor
});
```

节奏表 3s / 4.5s / 6s 在这段代码里的落点：格 1 用 `F_MAIN`（呼吸圆是画面主元素），格 2 用 4.5（三角波条是次级），格 4 用 6（进度条充当背景层节奏）——格 3 的 elastic 是一次性事件动画，不参与循环节奏，只借用 4.5s 的循环间隔。对着 demo 数一遍：呼吸圆每 3 秒完成一吸一呼，进度条每 6 秒往返一次，18 秒后底部琥珀条走满一圈、四格全部回到初始相位。

## 常见坑

| 症状 | 原因 |
|------|------|
| 动画快 1000 倍，像快进 | 把 rAF 的毫秒时间戳直接写进 u_time。`nowMs / 1000` 转秒，这是全课程契约 |
| 画面有一半永远黑的 | `sin()` 直接当透明度或半径用。负值区被 clamp 成 0——先 `0.5 + 0.5 * sin(...)` 映到 0..1 |
| 换帧率动画节奏就变，且没法暂停重放 | 用 dt 累积当时间。dt 累积是 JS 侧状态，shader 无状态；坚持传绝对时间，节奏由公式决定而非帧率 |
| 看一会儿头晕想吐 | easeOutElastic 用在背景大元素上。过冲震荡留给小元素，背景一律 sin 或 smoothstep |
| 页面开几分钟后画面开始抖 | u_time 一直累加，float 尾数耗尽。JS 侧 `time % 3600`，选 3600 因为它是节奏表的公倍数 |
| 缓动动画的进度偶尔冲出画面或弹飞 | 缓动函数忘了 clamp 输入 t。t 来自 `mod`、`fract` 的除法链，浮点误差会让它略微越界 |

## Checkpoint

- 能写出呼吸动画完整三行：`0.5 + 0.5 * sin(...)` 映射、半径合成、`smoothstep` 成形——合上讲义手写出来
- 能解释纯函数动画模型与 CSS 动画的心智差异：一个「时间决定画面、无状态」，一个「改属性、有状态」；并说清由此免费获得的三样东西（可逆、可暂停、可录屏）
- 能背出节奏表「主 3s / 次 4.5s / 背景 6s」，并把周期换算成 sin 系数（2π ÷ 周期 = 2.094 / 1.396 / 1.047）
- 能默写四个缓动函数的签名与适用场景，说出 elastic 禁用于背景大元素的原因（过冲震荡引发眩晕）
- 能解释 u_time 为什么要 `% 3600`，以及为什么 3600 这个数能保证回卷时画面无跳变
