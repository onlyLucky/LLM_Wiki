# 1.2 类型与变量：GLSL 的世界观是「向量优先」

> Day 1 · 模块 2 · 约 50 分钟
> 理论对照：《WebGPU 三天实战课程》1.4「WGSL 语言核心」——类型系统对照着看，事半功倍（[1.4-WGSL语言核心.md](../../../webgpu/讲义/day1-原生WebGPU基础/1.4-WGSL语言核心.md)）

上一模块你跑通了第一个页面，但 `fragment.glsl` 里那些 `vec3`、`precision` 还像外语。这个模块和下一模块把语言一次学扎实——两讲之后，写 shader 对你只剩创意问题，不再有语法问题。

## 标量：只有四种

GLSL 的标量只有四种：`float` / `int` / `uint` / `bool`。没有 string，没有 null，没有 undefined——GPU 每个周期都在做算术，语言里就不该有算不了的东西。

| 类型 | 字面量写法 | 本课出现频率 |
|------|-----------|------------|
| `float` | `1.0`（小数点**必须有**） | 几乎每行 |
| `int` | `1` | 循环计数器 |
| `uint` | `1u` | 少见，纹理操作偶有 |
| `bool` | `true` / `false` | 分支条件 |

最容易踩的坑现在就说破：**`1` 和 `1.0` 在 GLSL 里是两个不同类型的值，不互相隐式转换**。`float x = 1;` 直接编译报错。写 GLSL 的肌肉记忆第一条：所有小数都补上 `.0`——`0.5`、`2.0`、`-1.0`，一个都别省。

## 向量是主角：vec2 / vec3 / vec4

向量是「并排的几个数字」，GLSL 把它做成了一等公民——位置 `(x, y)`、颜色 `(r, g, b)`、坐标 `(u, v)` 全是向量。**一个类型打通图形学的全部概念**，这是 GLSL 世界观与 TS 最大的分野：TS 里你会写 `{ x: 0.5, y: 0.3 }` 的对象，GLSL 里一切皆 `vec`。

构造向量的六种姿势，全部合法且全部常用：

```glsl
vec2 a = vec2(1.0);             // 单值填充：(1.0, 1.0)
vec2 b = vec2(1.0, 0.0);        // 逐分量：x=1.0, y=0.0
vec3 c = vec3(uv, 1.0);         // 小向量拼大向量：(uv.x, uv.y, 1.0)
vec3 d = vec3(1.0, 0.0, 0.5);   // 纯数值
vec4 e = vec4(color, alpha);    // 向量 + 标量补位
vec2 f = c.xy;                  // 大向量切小向量（下一节的 swizzle）
```

记住两条规则就能推演一切：构造时**分量数必须严丝合缝**（`vec3(v2, 1.0)` 合法、`vec3(v4)` 非法），单值填充永远合法（`vec3(1.0)` = 三个 1.0）。

## swizzle：向量分量的摩斯密码

每个向量分量有三套等价的名字，按语义场景选用：

| 套系 | 分量名 | 语义场景 |
|------|--------|---------|
| `.xyzw` | x y z w | 位置 |
| `.rgba` | r g b a | 颜色 |
| `.stpq` | s t p q | 纹理坐标 |

`color.rgb`、`uv.xy`、`pos.xz` 写起来像属性访问，实际是**分量选择器**。它比 TS 的解构强大得多——可乱序、可重复：

```glsl
vec2 flipped = uv.yx;        // 交换 xy：一行完成镜像
vec3 gray = vec3(lum);       // 标量填充
vec3 onlyRed = color.rrr;    // 重复取同一个分量
vec4 pos = vec4(p.x, p.y, 0.0, 1.0); // 挑选重组
```

规则只有一条要记：**读随便读（可重复可乱序），写只能写未重复的**。`v.yx = vec2(1.0, 0.0)` 合法（交换赋值），`v.xx = vec2(1.0, 2.0)` 非法（一个分量被写两次，硬件没有意义）。编译器会拦住你，报错信息直白。

## 矩阵：mat2–mat4

矩阵本课只出现在两个场景：手写 `mat2` 做 2D 旋转，以及 Three.js 传入的 `mat4`（Day 3）。构造代码一眼记住：

```glsl
float c = cos(angle), s = sin(angle);
mat2 rot = mat2(c, -s, s, c);   // 列主序：参数按「列」排
vec2 rotated = rot * p;          // 矩阵 × 向量 = 旋转后的向量
```

列主序这个坑在 webgpu 2.1 有完整推导（[2.1-2D与3D空间变换.md](../../../webgpu/讲义/day2-渲染进阶与GPU计算/2.1-2D与3D空间变换.md)），本课你只需要记住结论：`mat2(a, b, c, d)` 的第一列是 `(a, b)`。2D 旋转矩阵背下来，Day 1 的 challenge 作业与 Day 2 的变换全靠它：

$$R(\theta) = \begin{pmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{pmatrix}$$

## 精度限定符：highp 的执念

片元着色器顶部那行 `precision highp float;` 不是仪式，是合同。GLSL ES 里 int 默认 highp，**float 必须显式声明默认精度**，不写直接编译失败。

| 精度 | 位宽 | 用途 | 本课态度 |
|------|------|------|---------|
| `highp` | float 32 位 | 坐标、时间、一切默认 | 片元顶部声明一次，全程用 |
| `mediump` | 16 位上下 | 移动端性能敏感区、后处理中间值 | Day 3 后期链可局部使用 |
| `lowp` | 8 位上下 | 颜色输出这类低精度场合 | 几乎不用 |

precision 是你跟 GPU 签的性能条款：声明得越低，GPU 越省，精度越差。课程统一 highp 起步——创意 shader 的瓶颈从来不在精度位宽，先别优化这个。

## 与 TypeScript 对照表

这一页帮你把 TS 心智映射过来，之后写 shader 时左手 TS 右手 GLSL 对照：

| TypeScript | GLSL ES 3.00 | 差异备注 |
|-----------|--------------|---------|
| `number` | `float` | 字面量必须带小数点 |
| `const n = 1 as const` | `const float N = 1.0;` | const 有类型检查 |
| `[0.5, 0.2]` | `vec2(0.5, 0.2)` | 向量可整体运算，数组不行 |
| `{ r, g, b }` | `vec3` | swizzle 取代属性访问 |
| `a + b`（数组不行） | `v1 + v2` 逐分量 | 向量运算是内建的 |
| 函数重载 | 必须显式重载声明 | 同名不同参要写多个签名 |
| `as` 断言 | 无，转换全用函数 | `float(1)`、`int(2.9)`（截断） |
| 模板字面量 | 无 string | 想都别想 |
| 可选参数 / 默认值 | 无 | 靠重载模拟 |
| 解构 `const {x, y} = p` | `p.xy` | swizzle 就是解构 |
| `Math.sin` | `sin` | 内建函数不带命名空间 |

最后两行值得停一下：GLSL 的**内建函数库非常肥**——`sin/cos/pow/exp/log/abs/min/max/clamp/mix/step/smoothstep/length/distance/dot/normalize/fract/floor/ceil/mod/sign` 全部开箱即用，且都是逐分量的。你 JS 里手写的三角函数工具函数，GLSL 里全是关键字级别的存在。

## 常量与作用域

```glsl
const float PI = 3.14159265;      // 文件级常量，大写 SNAKE_CASE
const vec3 ROSE = vec3(1.0, 0.302, 0.427); // 色板也常量化

void main() {
  float t = u_time;   // 函数内变量，块级作用域，与 JS 一致
  { float inner = 1.0; } // 块级作用域，出了花括号就没了
}
```

没有 var/let 之分，声明即定（类型固定，但值可变）。命名前缀是课程硬约定：uniform 用 `u_`、attribute 用 `a_`、varying 用 `v_`、常量大写——这套前缀让你在 200 行 shader 里一眼认出每个标识符的「来源」。

## How：在 demo 01 里找出今天学的每个语法点

demo 01 的 fragment 全文 27 行，逐行标注之后你会发现——**这 27 行里没有一行是陌生的了**：

```glsl
#version 300 es              // ← 1.3 讲预处理，先记住：必须是第一行
precision highp float;       // ← 本讲：精度条款

uniform float u_time;        // ← u_ 前缀；float 类型
uniform vec2 u_mouse;        // ← vec2 类型：两个 float 并排

in vec3 v_color;             // ← varying 输入（1.5 细讲）

out vec4 fragColor;          // ← 片元输出，vec4 = RGBA

const vec3 ROSE = vec3(1.000, 0.302, 0.427); // ← 常量 + 向量构造
const vec3 CYAN = vec3(0.298, 0.624, 0.941);

void main() {
  vec3 pull = mix(CYAN, ROSE, u_mouse.x);   // ← 内建函数 mix，逐分量线性插值
  vec3 shifted = mix(v_color, pull, 0.15);  // ← swizzle 没出现，但 v_color 整体参与运算

  float breathe = 1.0 + 0.06 * sin(u_time * 0.8); // ← 标量算术 + sin

  fragColor = vec4(shifted * breathe, 1.0); // ← vec3 × 标量 + 构造 vec4
}
```

行数对账：`mix` 和 `sin` 这两个函数明天才讲，但类型与构造已经全部过完了。你现在可以回去随便改这 27 行的类型实验——把 `0.15` 改成 `0.15f`（报错，GLSL 没有 f 后缀），把 `vec4(shifted, breathe, 1.0)` 试试（报错，分量数不匹配）——**编译器是最快的老师**，chrome 的错误面板会把它的每句话翻译给你看。

## 常见坑

| 症状 | 原因 |
|------|------|
| `float x = 1;` 编译报错 | int 到 float 无隐式转换。写 `1.0` |
| `vec3(0, 0, 0)` 编译报错 | 同上，三个 int 传给 vec3 构造器。写 `vec3(0.0)` |
| 忘写 `precision highp float;` | 片元着色器 float 无默认精度，编译失败，报错指向第一行 |
| `v.xx = ...` 报错 | swizzle 写入不能重复分量 |
| 颜色值写成 `255` 系 | GLSL 颜色是 0.0–1.0 浮点，`vec3(255, 0, 0)` 是纯白亮瞎。除以 255 |
| `0.15f` 报错 | GLSL 没有 C 风格的 f 后缀 |
