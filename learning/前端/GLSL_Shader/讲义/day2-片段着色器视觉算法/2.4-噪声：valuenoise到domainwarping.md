# 2.4 噪声：value noise、fbm 与域扭曲——流动感的来源

> Day 2 · 模块 4 · 约 60 分钟
> 理论对照：无直接章节——本篇是创意网站「背景流动感」的技术核心，参照 The Book of Shaders「Noise」与 iq 的工程化展开（[Noise](https://thebookofshaders.com/11/?lan=ch)）

hash 的格子太碎——相邻格各自为政，中间全是缝。噪声要的是反方向的东西：**相邻处相似、远处不同**——平滑随机。lusion 的丝绸、Noomo 的雾、Orage 的网格底流，几乎每个 awwwards 站的背景，全部建立在接下来三层塔上：noise → fbm → domain warping。这一讲把塔搭完，你的背景从此和「一条渐变」划清界限。

## value noise：格子间的平滑插值

hash 是格点上的值，噪声是格子间的值——中间那部分用插值补出来。算法四步：

```glsl
// value noise：格点 hash + 双线性插值 + 平滑缓动
float noise(vec2 p) {
  vec2 i = floor(p);        // 1. 格点编号（左下角那个）
  vec2 f = fract(p);        // 2. 格内位置 0..1
  vec2 u = f * f * (3.0 - 2.0 * f);  // 3. smoothstep 缓动坐标（关键一步）

  // 4. 四角 hash，按缓动后的比例双线性混合
  float a = hash21(i);                    // 左下
  float b = hash21(i + vec2(1, 0));       // 右下
  float c = hash21(i + vec2(0, 1));       // 左上
  float d = hash21(i + vec2(1, 1));       // 右上

  return mix(mix(a, b, u.x), mix(c, d, u.x), u.y); // 0..1
}
```

四步里第三步最值得盯住：`u` 不是直接拿 `f` 插值，先过一遍 `3f² - 2f³`（smoothstep 的内芯，1.6 见过的 easeInOut 表亲）。没有这一步，双线性是直线过渡，格子里会出现「折面感」——放大约两倍看得到格子轮廓；过完缓动，面与面之间曲率连续，视觉上只剩「云」。**噪声的贵，贵在这行缓动；噪声的便宜，也便宜在它只是 4 次 hash 加 3 次 mix。**

## 让噪声动起来：坐标偏移

静态噪声是纹理，动起来才是背景。一行完成：

```glsl
// 流动：采样坐标随时间平移——噪声图案整体往 -x 方向漂
float n = noise(p + vec2(u_time * 0.15, 0.0));

// 两个方向的组合流：东北向，速度 (0.12, 0.06)
float n2 = noise(p + vec2(u_time * 0.12, u_time * 0.06));
```

流动方向与速度全在偏移向量里。注意用 `+time` 而不是 `*time`：乘法会把坐标整体缩放——图案越走越密，像隧道冲刺（那是另一种效果，想要时再明着写）。**加法是平移，乘法是缩放**——GLSL 里坐标的加减乘除全是几何，写之前想清楚。

## fbm：噪声的噪音

单层 noise 的团块太单调。fractal brownian motion 的人话版：**同一噪声多个倍频相加**——每层频率翻倍、振幅减半，粗层给山势、细层给碎石：

```glsl
// fbm：五倍频（课程标准版）
float fbm(vec2 p) {
  float v = 0.0;
  float a = 0.5;             // 振幅：0.5 → 0.25 → 0.125 → ...（图注按 1.0 起步画对比；代码按 0.5 起步保总幅 ≤ 1，减半律相同）
  mat2 m = mat2(1.6, 1.2, -1.2, 1.6); // 每层旋一点，避免轴向对齐的假感
  for (int i = 0; i < 5; i++) {
    v += a * noise(p);
    p = m * p;               // 频率翻倍（用旋转+放大代替纯 *2，纹理更有机）
    a *= 0.5;
  }
  return v;                  // 输出约 0..1（总幅 0.96875）
}
```

`m` 矩阵是 iq 的私货：纯 `p *= 2.0` 的倍频会让每层格子对齐同一坐标轴，噪声出「十字纹」的假感；换成旋转 37° 附近再放大 2 倍的矩阵，层与层错开角度，云就没有纺织感了。37° 这个角度不是玄学——它让相邻倍频的主轴夹角远离 0°/90° 的对齐位。

octaves 的性能直觉：**每加一层贵一倍**（一次 noise = 4 次 hash + 3 次 mix，五层 ≈ 20 次 hash）。背景层 4–5 层封顶，纹理要更细宁可缩放格子，不要加层——8 层的视觉增益肉眼难辨，帧率直接减半（坑表第 1 行）。

五层逐层摊开，减半律一目了然——这张表就是代码注释里「总幅 0.96875」的来历：

| 层 i | 振幅 a | 累计振幅 | 频率（相对首层） | 视觉角色 |
|------|--------|---------|-----------------|---------|
| 0 | 0.5 | 0.5 | 1× | 山势：整体形体 |
| 1 | 0.25 | 0.75 | ≈2×（旋 37°） | 皱：大起伏 |
| 2 | 0.125 | 0.875 | ≈4× | 絮：云的碎边 |
| 3 | 0.0625 | 0.9375 | ≈8× | 颗粒 |
| 4 | 0.03125 | 0.96875 | ≈16× | 微尘：封顶档 |

对着表读出两条纪律的定量依据：第 4 层只贡献 0.031，砍掉它画面几乎不变——「背景 4 层即可」从这里来；反过来说想靠加层找细节，从第 5 层起每层性价比腰斩。频率带 ≈ 号是因为 `m` 矩阵是「旋转 37° + 放大 2 倍」的合成——倍频确切是 2 倍，但轴向每层错开，上文防纺织纹的设计就体现在这列里。

## domain warping：先扭曲坐标，再采样噪声

塔的顶层。前面所有采样都在问「这个点的噪声是多少」，domain warping 先问「这个点被推到哪去了」：

```glsl
// domain warping：外层 fbm 决定「往哪推」，内层 fbm 决定「画什么」
vec2 q = vec2(fbm(p), fbm(p + vec2(5.2, 1.3)));   // 第一层：扭曲场
float f = fbm(p + k * q);                          // 第二层：在扭曲后采样
// k 是 warp 强度：0.3 微澜 / 0.8 丝绸 / 1.5 熔岩
```

前后对比看双联图：

![域扭曲双联对比图：左侧面板灰描边为 warp 前的规则网格采样，网格横平竖直，玫红采样点 p 标在网格交叉处，下方注「fbm(p)：格子规规矩矩、噪声是动的采样点是死的」；右侧面板天青描边为 warp 后的网格，同一网格的线条全部变成波动的曲线（横线与竖线都被扰动弯曲），采样点从原位被推到新位置 p'，虚线箭头标出位移，下方注「fbm(p + fbm(p)·k)：每个采样点被噪声推走——丝绸的褶」；中间一枚琥珀色大箭头连接两面板，箭头下方公式框写「p' = p + fbm(p)·k」，配 k 三档强度表「0.3 · 微澜 / 0.8 · 丝绸 / 1.5 · 熔岩」，分别用天青、玫红、琥珀三色标注；底部通栏两行：「嵌套即流动感：外层 fbm 决定往哪推，内层 fbm 决定画什么——推的力量随 k 增长」「注意性能：warp 里再 warp 是指数爆炸，一层封顶」](../../assets/diagrams/domain-warping.svg)

对着图盯中间那支箭头：`p'` 是 `p` 被自己的 fbm 推走后的落点，k 是推力。右面板那些弯曲的网格线就是「丝绸的褶」的几何本质——**每个采样点被噪声推走，推的轨迹叠出流动感**。「双 fbm 的价格买一个丝绸质感」，lusion 背景的配方核心就是这一行嵌套。

warp 强度 k 的三档表写进图里也写进你的手：0.3 是微澜（水面波光），0.8 是丝绸（获奖站背景的常用档），1.5 是熔岩（图案结构被撕开重组）。从 0.8 起步调，是最不容易翻车的入口。

三层塔装进一个完整可跑的 fragment——warp 流场的最小版，demo 04 的浓缩：

```glsl
#version 300 es
precision highp float;
uniform vec2 u_resolution;
uniform float u_time;
out vec4 fragColor;

float hash21(vec2 p) { p = fract(p * vec2(234.34, 435.345)); p += dot(p, p + 34.23); return fract(p.x * p.y); }
float noise(vec2 p) {
  vec2 i = floor(p), f = fract(p); vec2 u = f * f * (3.0 - 2.0 * f); // 缓动：没有它格子折面肉眼可见
  return mix(mix(hash21(i), hash21(i + vec2(1, 0)), u.x), mix(hash21(i + vec2(0, 1)), hash21(i + vec2(1, 1)), u.x), u.y);
}
float fbm(vec2 p) {
  float v = 0.0, a = 0.5; mat2 m = mat2(1.6, 1.2, -1.2, 1.6); // 旋 37° 再放大：层间错轴
  for (int i = 0; i < 5; i++) { v += a * noise(p); p = m * p; a *= 0.5; }
  return v;
}

void main() {
  vec2 p = (gl_FragCoord.xy / u_resolution) * 2.0 - 1.0;
  vec2 q = vec2(fbm(p + vec2(0.0, u_time * 0.1)), fbm(p + vec2(5.2, 1.3))); // 两个分量必须喂不同输入
  float f = fbm(p + 0.8 * q);                 // k = 0.8：丝绸档起步
  float bands = 0.5 + 0.5 * sin((f + p.x * 0.4) * 16.0); // 条纹相位吃进 f：跟着场弯
  vec3 col = mix(vec3(0.03, 0.05, 0.09), vec3(0.3, 0.8, 0.9), bands * 0.6);
  fragColor = vec4(col, 1.0);
}
```

跑起来的画面：深蓝底上一条条天青色流动条纹，条纹走向被两层 fbm 拧出丝绸褶。想亲手验证 k 的三档表，只改 `0.8` 一个数：0.3 时条纹近乎笔直，1.5 时撕成碎流——比看图记得牢。`bands * 0.6` 把条纹亮度压到六成：高频纹理满亮度会晃眼，背景层永远给自己留三成余地，2.5 讲配色纪律时这条会再出现。

## 性能账单

一张表算清 warp 版 fbm 的成本：

| 层 | 每次 fbm 的开销 | 调用次数 | hash 总调用（每像素） |
|----|----------------|---------|---------------------|
| noise 单层 | 4 hash + 3 mix | 5（octaves） | 20 |
| fbm 一次 | 20 hash + 15 mix | 3（q 两个分量 + 采样一次） | 60 |
| 1080p 全屏 | — | ≈ 207 万像素 | ≈ 1.24 亿 |

这张表解释了两条工程纪律：**warp 常只 warp 一层**（`q.y` 可复用或第二层改便宜的单 fbm）；**背景层降 octaves**（远处看不见第 5 层的细节，4 层即可）。60fps 的预算约 16.6ms，中端 GPU 每帧能烧的 hash 数量级就在 1–2 亿——账算在前面，调参时心里有秤。

## How：demo 03「fbm 云海」+ demo 04「域扭曲流场」双联精讲

两份 demo 是塔的上下两层，并排食用。

demo 03 是塔的第一二层（noise → fbm → 调色板映射），fragment 核心段：

```glsl
// demo 03 核心段：fbm 云海
vec2 flow = vec2(u_time * 0.15, u_time * 0.05);       // 流速向量（视觉规格：0.15）
float n = fbm(p * 1.2 + flow);                        // 五倍频 + 流动

// 调色板映射：熔岩卡改造（深蓝底 → 天青亮部）——2.5 的钩子
vec3 col = palette(clamp(n * 1.6 - 0.3, 0.0, 1.0));

// 边缘 glow：噪声值高处提亮——「云的银边」
col += vec3(0.298, 0.624, 0.941) * pow(smoothstep(0.55, 0.95, n), 2.0) * 0.35;
```

值得盯住的是 `n * 1.6 - 0.3` 这步「再分布」：fbm 输出挤在 0.35–0.65 的高斯峰里（五层 0.5 幅相加的统计必然），直接当 t 画面发灰；乘 1.6 拉开、减 0.3 对中，t 才铺满 0–1。**你调的从来不是颜色，是 t 的分布**——2.5 的主旋律在这里提前彩排。

demo 04 是塔顶（warp 后的 fbm 当速度场，条纹沿场流动）：

```glsl
// demo 04 核心段：域扭曲流场
vec2 q = vec2(fbm(p + vec2(0.0, u_time * 0.1)),
              fbm(p + vec2(5.2, 1.3) + vec2(u_time * 0.08, 0.0)));
float f = fbm(p + 0.8 * q);          // k = 0.8：丝绸档（视觉规格）

// 条纹沿场流动：warp 域的 fbm 再当条纹的相位
float bands = 0.5 + 0.5 * sin((f + p.x * 0.5) * 18.0);
vec3 col = BG + CYAN * bands * 0.25; // 天青 25% 透明度（视觉规格）
```

条纹的相位里混进了 `f`（warp 后的 fbm）——条纹不再直挺，跟着场的弯曲走，「流」出来了。鼠标拖动搅场：JS 侧把拖动速度向量加进 `q` 的偏移（`u_vel` 思路与 Day 1 A 档同源），warp 强度随拖速 0.3 → 1.2——**轻拖是丝绸，猛拖是熔岩**，k 的三档表变成了一个可玩的交互。

## 常见坑

| 症状 | 原因 |
|------|------|
| octaves 叠到 7、8 层 | 视觉无增益（第 5 层以下人眼分不出）、帧率减半；背景 4–5 层封顶是性能纪律 |
| warp 里又 warp（`fbm(p + fbm(p + fbm(p)))`） | 指数爆炸：每层嵌套都是 3 倍 fbm 开销；一层封顶，想要更乱调 k，不要叠结构 |
| 噪声输入忘 `fract` 或无界增长 | `u_time` 无限增大，hash 的大数精度崩坏，画面抖动闪烁；给坐标周期化或 clamp 输入域 |
| `abs(p)` 之后 noise 出现折痕 | 折叠后的坐标在镜像线上一阶不连续——顺带一招：故意用 `abs` 造「纸折痕」效果，是 bug 也是 feature |
| 云看起来有方向性的「纺织纹」 | 倍频用纯 `p *= 2.0`，各层格子轴向对齐；换成旋转矩阵 `m = mat2(1.6, 1.2, -1.2, 1.6)` |
| 画面一大片均匀的灰，分不出云形 | fbm 输出挤在 0.35–0.65；t 要再分布（乘 1.6 减 0.3 之类），或把 palette 的对比拉高 |
| 想让云流动，结果图案加速变密像隧道冲刺 | 写成了 `noise(p * u_time)`——乘法是缩放不是平移；流动用加法 `p + u_time * velocity` |
| warp 的丝绸变成单向斜拉的「拉面」 | `q` 的两个分量喂了同一输入（`vec2(fbm(p), fbm(p))`）：q.x 恒等于 q.y，扭曲场退化成对角线平移——第二分量要加偏移 `fbm(p + vec2(5.2, 1.3))` |
| fbm 高频层全是碎渣、形体消失 | 振幅写成了 `a = 0.5`（每层重置等幅）而不是 `a *= 0.5`（逐层减半）——高频与低频一样响，山被碎石淹没 |

## Checkpoint

- 能默写 value noise 四步（格点 hash → 四角值 → smoothstep 缓动 → 双线性 mix），并说出缓动那步去掉会发生什么
- 能解释 fbm 每层「频率加倍、振幅减半」分别对应视觉上的什么（细节密度 / 细节强度）
- 能写出 domain warping 一行，并背出 k 的三档表（0.3 微澜 / 0.8 丝绸 / 1.5 熔岩）
- 能背出性能账单：一次五倍频 fbm ≈ 20 次 hash，warp 版 ≈ 60 次；背景层的两条纪律（只 warp 一层、远处降 octaves）
- 能解释「加法是平移、乘法是缩放」在让噪声流动时的选择
