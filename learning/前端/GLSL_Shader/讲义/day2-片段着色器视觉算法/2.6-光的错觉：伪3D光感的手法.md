> Day 2 · 模块 6 · 约 55 分钟
> 理论对照：《GAMES101》着色章节——真实光照模型的完整推导（[05-着色.md](../../../../计算机图形学/GAMES101/05-着色.md)）；本篇是「用 2D SDF 伪造光感」的偏方集，两边的分界：真实渲染 vs 视觉说服；《WebGPU 三天实战课程》2.4 着色与光照模型是 DX/WebGPU 侧的对照（[2.4-着色与光照模型.md](../../../webgpu/讲义/day2-渲染进阶与GPU计算/2.4-着色与光照模型.md)）

SDF 是平面的，但没人规定平面不能有光。徽章的立体感、发光体的辉光、暗部的沉稳、渐变的细腻——它们都不需要真的去算三维光照，只需要**说服你的视网膜**。GAMES101 的着色模型解的是物理方程（辐照度、BRDF、能量守恒）；本篇的手法解的是感知方程（哪一行代码让画面「看起来被光照过」）。两条路线的分界先划清，你才知道什么时候该用哪边：**作品要真实感时用前者，作品要氛围时用后者**——创意网站九成场景要的是氛围。

## 高度场法线：SDF 的免费 3D

2.1 说过距离场可插值、可缩放、可 smooth、可发光——支票在这里兑第一张。把 `abs(sd)` 的边界带当「高度」看：形状中央是高原、边界是悬崖，这个虚构的地形自带法线（坡度的反方向），有法线就能上朗伯光照：

```glsl
// 高度场：边界带当高度——中央 1、悬崖外 0，w 是崖宽
float h = 1.0 - smoothstep(0.0, 0.06, abs(sd));

// 法线：高度在 x/y 方向的梯度，z 抬起来
vec3 n = normalize(vec3(
  h - hNeighborX,   // 「自己减右邻」= -dFdx(h)：光从哪侧来，法线就朝哪侧翻
  h - hNeighborY,
  0.05              // z 是「陡峭度」旋钮：越小越像金属浮雕
));

// 更实操的写法：直接用屏幕空间导数——与上一版只差一个符号（光照方向镜像），二选一
vec3 n = normalize(vec3(dFdx(h), dFdy(h), 0.05));

// 朗伯一行：法线与光方向的点积——2D 形状立刻鼓起来
float lambert = clamp(dot(n, normalize(vec3(-0.5, 0.8, 0.6))), 0.0, 1.0);
vec3 lit = baseColor * (0.35 + 0.65 * lambert); // 0.35 环境光，别让暗部死黑
```

「2D 形状立刻鼓起来」的机关：`dFdx(h) / dFdy(h)` 就是 2.1 的 fwidth 背后的同一对导数——它们量的是「这个量在屏幕上怎么变化」，光照要的「坡度」正是它。z 分量 0.05 是手感旋钮：调小，浮雕感锐利（金属徽章）；调大，起伏平缓（陶土哑光）。**法线是编出来的，光感是真的**——视网膜不查推导过程。

## 伪阴影：朝光源方向再算一遍

立体感的另一半来自投影。两个档位，按预算选：

```glsl
// 便宜款：形状下方一条渐变椭圆——「设计师说的『底部压一层暗』」的函数写法
float shadow = smoothstep(0.0, 0.35,
  length((p - shapeCenter) * vec2(1.0, 2.2)) // y 压扁成椭圆
  - shapeRadius);
shadow *= smoothstep(0.0, 0.4, shapeCenter.y - p.y); // 只在形状下方
col *= 0.55 + 0.45 * shadow;

// 标准款：SDF 距离 + 光方向偏移——「朝光源方向再算一遍 SDF」
float sh = sdShape(p + lightOffset);      // lightOffset 指向光源（影子甩向光的反方向）
float shade = smoothstep(0.0, 0.15, sh);  // 形状自己挡住的地方，sh < 0
col *= mix(0.6, 1.0, shade);              // 阴影区压到 60% 亮度
```

标准款的一个细节：`sdShape(p + lightOffset)` 是**平移坐标后再问 SDF**——2.2 黄金法则的又一客户。被自身挡住的像素，在「往光源方向挪一点」的坐标系里落在形状内（SDF 为负），阴影即成。光偏移量越大影子越长，方向就是光来的反方向。

三段手法的旋钮各有定数，摆进同一张表，你调参时就不必来回翻小节：

| 手法 | 旋钮 | 典型值 | 打开后的观感 | 失手后的症状 |
|------|------|--------|--------------|--------------|
| 朗伯 | 光方向 `vec3(-0.5, 0.8, 0.6)` | 左上来光 | 高光在左上、右下走暗 | z 拉到 0.9 → 正面平光，浮雕消失 |
| 朗伯 | 环境光系数 `0.35` | 暗部保底 35% | 背光面保留色相与细节 | 0 → 暗部死黑；0.5 → 立体感被洗平 |
| 法线 | z 分量 `0.04` | 陡峭度 | 金属徽章的锐利浮雕 | 0.10 起 → 陶土/塑料感（坑表第 5 行） |
| 法线 | 崖宽 `0.05` | 边界带宽度 | 光感聚在边缘一圈 | 0.15 → 糊成一团；0.01 → 高频锯齿 |
| glow | 带宽 `0.08 / 0.12` | 主窄次宽 | 主晕给强度、次晕给氛围 | 两层同宽 → 只剩一层的效果 |
| glow | 指数 `2.0` | 标准锐度 | 光渐近零、永不封顶 | 4.0 → 电弧感；1.0 → 大雾 |
| 伪阴影 | 偏移幅度 `0.05` | 影长 | 影子贴着形状落地 | 0.2 → 影子与形状脱节 |
| 伪阴影 | 压暗系数 `0.6` | 影深 | 影区 60% 亮度、柔和落影 | 0.3 → 一块黑补丁 |
| dither | 幅度 `±0.5/255` | 修复带 | 色带消失、看不见的噪 | 超过 1/255 → 看得见的颗粒（坑表第 4 行） |

光方向的三个分量单独拆开记：**xy 是光的屏幕方位，z 是光打得多「正」**。`vec3(-0.5, 0.8, 0.6)` 读作「左上 45 度斜打、略偏正面」；你把它镜像成 `vec3(0.5, -0.8, 0.6)`，光立刻翻到右下——同一行代码、观感整个翻转，这是验证光向最快的一改。z 与法线的 z 分量是一对反着用的搭档：光向的 z 越大光越「正」（平光、立体感弱），法线的 z 越小浮雕越锐（金属感）。

`0.35 + 0.65 * lambert` 的两个系数是**底光比**：0.35 给背光面保底（色相不死、暗部有细节），0.65 给受光面封顶——两者相加恰好 1，正对光处正好满亮。你想让暗部更「重」，把 0.35 压到 0.15、同时抬 0.65 到 0.85：**对比度变了，满亮点没动**；只改一个数，满亮点跟着漂，过曝或发灰就来敲门。

伪阴影的两个系数要成对调：**偏移定影长、压暗定影深**——长影配浅压（偏移 0.10、系数 0.75）是日光下的长柔影，短影配深压（偏移 0.03、系数 0.55）是灯下紧贴的深影。只调一个的翻车你自己就能复现：影子拉长了却压得一样深，看起来像「抠图没抠干净」。

三段的装配次序也是一条隐性纪律：glow 先加进暗场（additive），朗伯底色再用 `mix` 盖回形状内——次序反过来（先盖底色再加 glow），圆内的光晕被底色吃掉一半，边缘光圈出现缺口。你回看 demo 06 段 2、段 3 的先后，就是这么排的。

## glow：辉光 = 距离的幂

发光体是 SDF 的招牌菜。距离的幂衰减一行公式：

```glsl
// glow：w 是光晕带宽（半径），指数是锐度
float glow(float sd, float w) {
  return pow(w / (abs(sd) + w), 2.0);
}

// additive 叠加：color += glowColor * glow——「加」是光的语义
col += rose * glow(sd, 0.08) * 0.9;   // 主光晕：玫红，窄而亮
col += cyan * glow(sd, 0.12) * 0.5;   // 次光晕：天青，宽而柔
```

两参数的手感：**w 是光晕半径**（0.08 约 4% 屏宽），**指数是锐度**（2.0 标准，1.0 弥散，3.0 锐利）。双层 glow 的叠加顺序（窄亮的先、宽柔的后）是霓虹字、能量体、赛博氛围的统一母题——**主晕给强度，次晕给氛围**，一层 glow 是发光，两层才有「光在空气里」。

为什么用幂而不是 step（`step(abs(sd), w)` 画一个硬光圈）？step 的光晕有边——像贴纸；幂衰减在远处渐近零，光「散进空气里」。见坑表第 1 行，这是辉光手法的头号高频错。

`pow(w / (abs(sd) + w), 2.0)` 的数值走查（w = 0.08）你可以直接背：sd = 0 处 glow = 1.0（贴边最亮），离开一个带宽（sd = 0.08）剩 0.25，两个带宽剩 0.11，四个带宽剩 0.04——**距离每翻一倍、亮度掉到四分之一**（平方律），渐近零但永不触底，这就是「散进空气」的曲线形状；step 版在 w 处一刀切到 0，边界硬得像贴纸。

指数是这条曲线的弯度旋钮：1.0 时两倍距离剩一半（线性弥散、像雾），2.0 剩四分之一（标准），3.0 剩八分之一（锐收、像电弧）——你在参数表里改的这一个数，决定光「化开」还是「收住」。

## bloom 错觉与真 bloom 的分界

上面这种「单 pass 内的光晕叠加」够用 90% 的场景，但它是「贴着形状发光」，不是「亮的东西把整个画面照亮」——后者是真 bloom：亮部渲染进 render target，模糊后叠回全屏，光源会「洇」到旁边的物体上。真 bloom 要双 pass 与后处理链，是 Day 3 的 3.5 后期工作坊的主菜。**分界一句话：要「形状发光」用本节的 glow，要「画面有大气」等 3.5 的 bloom。** 现在用 glow 把霓虹 hero 做完，第 3 天你会回来给整个场景加大气。

## dithering：让渐变不结带

8bit 输出（每通道 256 级）在深色渐变上会露馅：相邻灰度差 1/255，人眼在暗部能分辨——渐变变成一条条色带（banding）。解法是抖动：在输出前加一个小随机，把色带打散成「看不见的噪」：

```glsl
// 有序抖动一行：±0.5/255 的 hash 扰动
col += (hash21(gl_FragCoord.xy) - 0.5) / 255.0;
```

加了这一行，色带消失，代价是极轻的颗粒——**这颗颗粒就是电影厂标的 grain 前身**（2.8 会把它放大成风格）。数学上它做的事叫「以时间/空间平均换取量化精度」：单个像素偏差半级，人眼平均后看到的是中间色。

±0.5/255 的两端各验一次你就懂了它的分寸：+0.5/255 把 0.300 变 0.30196（向上进一档），−0.5/255 把它变 0.29804（向下退一档）——**半个量化级的扰动，逼着色带里的相邻档随机上下跳**，人眼把空间里的跳变平均掉，看到的就是平滑渐变。这也解释了幅度为什么卡在 0.5/255：小于它，扰动够不着下一档、色带纹丝不动；大于 1/255，跳变本身可见、成了颗粒。

banding 专挑暗部与低饱和区下手：8bit 里相邻码级差恒为 1/255，亮区（0.9 附近）人眼分辨不出，暗区（0.05 附近）却隔着一整档感知差——所以 hero 的深色底、暗场 glow 的过渡带是重灾区，亮色页面反而从来不出事。你怀疑「是不是我写错了」之前，先看看渐变是不是深色。

顺带一提静态版与动态版：本节的 dither 不带 u_time（静态抖动——噪点钉在像素位上，人眼更难察觉），2.8 的 grain 带 u_time（动态颗粒——胶片的呼吸感）。**修复带要安静，风格带要呼吸**，同一个 hash，语境定生死。

## How：demo 06「霓虹辉光与电影感」逐段精讲

demo 06 是 Day 2 全部手法的一页汇报：SDF 圆环 + 高度场法线 + 双层 glow + dither 收尾，装配顺序即各讲顺序。fragment 主体四段：

```glsl
// —— 段 1：SDF 圆环（2.1）——
float sd = abs(length(p) - 0.42) - 0.045;   // 圆环：到圆心的距离减环心半径再减半环宽

// —— 段 2：高度场法线 + 朗伯（本讲）——
float h = 1.0 - smoothstep(0.0, 0.05, abs(sd));
vec3 n = normalize(vec3(dFdx(h), dFdy(h), 0.04));
float lit = clamp(dot(n, normalize(vec3(-0.4, 0.7, 0.5))), 0.0, 1.0);

// —— 段 3：双层 glow（本讲）——
float g1 = pow(0.08 / (abs(sd) + 0.08), 2.0);  // 主晕：玫红，窄亮
float g2 = pow(0.12 / (abs(sd) + 0.12), 2.0);  // 次晕：天青，宽柔

vec3 col = BG;
col += rose * g1 * 0.9;
col += cyan * g2 * 0.5;
col = mix(col, ringColor * (0.4 + 0.6 * lit), 1.0 - smoothstep(0.0, fwidth(sd), abs(sd)));

// —— 段 4：dither + 电影感配方（2.8 的前奏）——
col += (hash21(gl_FragCoord.xy) - 0.5) / 255.0;
col *= 1.0 - 0.2 * pow(length(uv - 0.5), 2.0); // vignette 顺手带上（平方版与 2.8 同款：远角压得狠、中心保持平）
```

值得盯住的是开关 uniform：demo 06 把「法线 / glow / dither / vignette」各挂一个 0/1 uniform，键盘切换做 A/B 对比——**关掉法线，环立刻瘪成纸片；关掉 glow，霓虹变成贴纸；关掉 dither，暗部色带立现**。四个开关把「每一步值多少分」变成可测量的选择题，这个 demo 结构本身就是教学法的示范。

离开 demo 自己敲一遍才算过手——三段手法拼成一个能直接跑的完整 fragment，配 1.7 的装配管线与全屏 quad 即可渲染：

```glsl
#version 300 es
precision highp float;
uniform vec2 u_resolution;
out vec4 fragColor;

void main() {
    vec2 uv = (gl_FragCoord.xy * 2.0 - u_resolution) / u_resolution.y;
    float sd = length(uv) - 0.35;                  // 2.1 的圆 SDF：一切光感的载体
    // 段 1：高度场法线 + 朗伯——中央高原、边界悬崖，dFdx 就是坡度
    float h   = 1.0 - smoothstep(0.0, 0.05, abs(sd));
    vec3  n   = normalize(vec3(dFdx(h), dFdy(h), 0.04));
    float lit = clamp(dot(n, normalize(vec3(-0.5, 0.8, 0.6))), 0.0, 1.0);
    // 段 2：双层 glow——「加」是光的语义，主晕窄亮、次晕宽柔
    float g1 = pow(0.08 / (abs(sd) + 0.08), 2.0);
    float g2 = pow(0.12 / (abs(sd) + 0.12), 2.0);
    vec3  col = vec3(0.02, 0.03, 0.06);            // 深色底：光感要暗场衬托
    col += vec3(0.95, 0.30, 0.45) * g1 * 0.9;      // 主晕：玫红
    col += vec3(0.30, 0.75, 0.90) * g2 * 0.5;      // 次晕：天青
    // 段 3：朗伯只画在圆内，fwidth 抗锯齿——底色不吞光晕
    vec3 base = vec3(0.90, 0.85, 0.80) * (0.35 + 0.65 * lit);
    col = mix(col, base, 1.0 - smoothstep(0.0, fwidth(sd), abs(sd)));
    // 段 4：dither 收尾——±0.5/255，把色带打散成看不见的噪
    col += (fract(sin(dot(gl_FragCoord.xy, vec2(12.9898, 78.233))) * 43758.5453) - 0.5) / 255.0;
    fragColor = vec4(clamp(col, 0.0, 1.0), 1.0);
}
```

自检顺序照参数表从上往下：先只留段 2 看光晕的形状与宽度，再开段 1 看浮雕随光向翻面，段 4 收尾再开、对比暗场色带——三段各自独立成立，合在一起才是「光的错觉」。

## 常见坑

| 症状 | 原因 |
|------|------|
| 光晕有一个生硬的圆边 | glow 用了 step（`step(abs(sd), w)`）——硬光圈像贴纸；换成幂衰减 `pow(w / (abs(sd) + w), 2.0)`，光才散进空气 |
| 光照忽明忽暗、闪烁 | 法线没 normalize——点积的量纲随法线长度漂移；朗伯前必须归一化 |
| additive 叠加后亮部一片死白 | 叠加没 clamp：`col += glow` 可以无限超 1；输出前 `clamp(col, 0.0, 1.0)` 或压低各层系数 |
| dither 加完画面变脏 | 抖动幅度太大：±0.5/255 是「看不见的噪」，超过 1/255 就成了看得见的颗粒——那是 2.8 的风格 grain，不是本节的修复带 |
| 浮雕感太假、像塑料 | 法线 z 分量太大（起伏太缓）或崖宽 w 太窄（边缘太利）；金属感 0.03–0.05，陶土感 0.08–0.12，w 与 z 成对调 |
| 阴影方向与光照方向打架 | 标准款的 lightOffset 推导搞反：偏移是「朝光源方向挪」再算 SDF——方向反了阴影跑到亮面去 |
| 形状内部成片黑点或条纹 | 法线 z 取了 0：平坦区 dFdx(h) = dFdy(h) = 0，normalize(vec3(0, 0, 0)) 未定义，NaN 落屏成黑斑；z 至少 0.02 |
| 暗部出现反色污渍 | lambert 没 clamp：dot 为负时底色乘上负数，通道翻转成怪色；点积后立即 clamp(…, 0.0, 1.0) |
| dither 加完变成大块污斑 | hash 输入用了 uv 而非 gl_FragCoord.xy：uv 只有 0–1 的量程，fract 精度撑不起像素级扰动，噪点糊成色块 |

## Checkpoint

- 能写出高度场法线三行（h → dFdx/dFdy 法线 → 朗伯点积），并说出 z 分量的手感
- 能背 glow 公式 `pow(w / (abs(sd) + w), 2.0)`，并说出 w 与指数各自的手感
- 能区分「形状发光」（本节 glow）与「画面有大气」（3.5 真 bloom）的分界与取舍
- 能解释 dithering 解决什么问题、幅度为什么是 ±0.5/255
- 能说出伪阴影标准款「平移坐标后再问 SDF」用到了 2.2 的哪条黄金法则
- 能说出光方向 `vec3(-0.5, 0.8, 0.6)` 三个分量各自的手感，并演示镜像成 `(0.5, -0.8, 0.6)` 后观感怎么翻
- 能解释 `0.35 + 0.65 * lambert` 两个系数为什么相加为 1、只改一个会发生什么
