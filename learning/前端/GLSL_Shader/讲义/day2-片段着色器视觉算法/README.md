# Day 2 · 片段着色器视觉算法

第二天只回答一个问题：**每个像素的颜色怎么算。**

昨天搭好的「全屏四边形 + 时间 + 交互」全部成为地基，今天专心做视觉算法——SDF、随机、噪声、色彩、光感、纹理、电影感，8 篇讲义是创意网站背景与主视觉的完整武器库：

| # | 讲义 | 主题 | 一句话 |
|---|------|------|--------|
| 2.1 | [像素级绘画：从 step 到符号距离场](2.1-像素级绘画：从step到符号距离场.md) | SDF | 距离场相对布尔的降维打击：可插值、可缩放、可发光 |
| 2.2 | [坐标变换：旋转平铺与极坐标图案](2.2-坐标变换：旋转平铺与极坐标图案.md) | 变换 | 变换坐标而不是形状——mat2、fract 平铺、曼陀罗公式 |
| 2.3 | [伪随机与图案：hash 格子与 voronoi](2.3-伪随机与图案：hash格子与voronoi.md) | 随机 | 确定性随机是数字世界生命感的第一来源 |
| 2.4 | [噪声：value noise 到 domain warping](2.4-噪声：valuenoise到domainwarping.md) | 噪声 | 三层塔：noise → fbm → warp，流动感的全部来源 |
| 2.5 | [色彩工程：余弦调色板与配色直觉](2.5-色彩工程：余弦调色板与配色直觉.md) | 色彩 | 一个公式四参数装下一整套配色——你调的是 t 的分布 |

一天的主线是一条塔：**形状（2.1–2.2）→ 随机（2.3）→ 连续（2.4）→ 上色（2.5–2.6）→ 素材与收尾（2.7–2.8）**。上半场产出「图案的骨架」，下半场产出「图案的气质」，晚上 C 档作业把两层合成一件作品。

图表资产位于 [assets/diagrams](../../assets/diagrams/)，本日引用 4 张：SDF 等值线（sdf-distance-field）、噪声三联（noise-fbm-composition）、域扭曲双联（domain-warping）、余弦调色板（palette-cosine）。
