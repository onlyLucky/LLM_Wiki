# 2.1 像素级绘画：从 step 到符号距离场

> Day 2 · 模块 1 · 约 55 分钟
> 理论对照：《GAMES101》光栅化章节——「屏幕上没有形状，只有像素」的硬件视角（[04-光栅化.md](../../../../计算机图形学/GAMES101/04-光栅化.md)）；本篇讲软件视角：每个像素自己判断「我在不在形状里」

昨天的画面全是渐变——连续的、没有边界的东西。真实的创意网站里你逃不开「有边界的形状」：按钮的圆角、徽章的描边、卡片的光晕、加载环的缺口。CSS 画这些靠 border-radius 和 box-shadow，shader 里靠什么？靠每个像素独立回答同一个问题：「我离形状多远」。这一讲从最粗暴的 step 开始，一路走到符号距离场（SDF）——它是后面voronoi、辉光、伪 3D 的共同地基，是 Day 2 的第一块承重墙。

## step：一刀切出的边界

`step(edge, x)` 是 GLSL 里的布尔转连续量的第一站：`x >= edge` 返回 1，否则返回 0。语义是「过线没有」，一刀切，没有过渡：

```glsl
#version 300 es
precision highp float;

uniform vec2 u_resolution;

out vec4 fragColor;

void main() {
  vec2 uv = gl_FragCoord.xy / u_resolution;

  // 半屏切割：x 过了中线就是 1——左暗右亮，一刀切出两个世界
  float half_ = step(0.5, uv.x);

  vec3 col = mix(vec3(0.043, 0.055, 0.078), vec3(0.298, 0.624, 0.941), half_);
  fragColor = vec4(col, 1.0);
}
```

单刀没意思，四次 step 相乘画一个矩形边框才有手感：

```glsl
// 矩形边框 = 四次「过线判断」相乘——乘法就是 AND，加法就是 OR
float border(float v, float lo, float hi) {
  return step(lo, v) * step(v, hi); // 两条都过线（v 在 [lo, hi] 内）才得 1
}
float box = border(uv.x, 0.35, 0.65) * border(uv.y, 0.35, 0.65);
```

**为什么不写 if**——1.1 讲分支发散时的老朋友回来了：if 让一个 warp 里的像素走两条路，GPU 得两条都执行再丢弃一条；更要命的是 if 的结果只有 0/1，你拿它做不了任何后续加工——不能平滑、不能发光、不能呼吸。step 返回的是数值不是状态，数值可以继续参与运算，这是「shader 思维」和「DOM 思维」的分水岭：**条件是数据，不是控制流。**

## smoothstep：给边界一条 1px 的过渡带

step 的边在放大镜下是锯齿：边界像素要么全亮要么全暗，落在亮侧还是暗侧全看采样点位运气。`smoothstep(edge0, edge1, x)` 给边界铺一条过渡带：x 在 edge0 与 edge1 之间按三次 Hermite 曲线从 0 走到 1（1.6 讲过它就是内置的 easeInOut 表亲）：

```glsl
// 抗锯齿版的 border：0.002 的过渡带让边界像素拿到「半亮」
float borderSoft(float v, float lo, float hi, float w) {
  // 上边界「越大越暗」：用 1 减正序 smoothstep——edge0>edge1 的逆序写法规范里是未定义行为，别依赖
  return smoothstep(lo - w, lo + w, v) * (1.0 - smoothstep(hi - w, hi + w, v));
}
```

过渡带宽写多少像素？写死了（比如 0.002）在不同分辨率上粗细不一致；更聪明的做法是问 GPU「这个像素旁边，值变化有多快」——`fwidth(d)` 返回变量 d 在屏幕空间上的每像素变化率。边界斜着穿过像素时，fwidth 自动变宽；正交穿过时变窄。**过渡带宽度 = fwidth(d)，就是「天生抗锯齿」的全部机关**：

```glsl
float d = abs(sd);                       // 到边界的距离（下一节的主角）
float aa = fwidth(d);                    // 该像素处 d 的变化率
float fill = 1.0 - smoothstep(0.0, aa, d); // 距离场版的完美边缘
```

fwidth 在 WebGL2 里开箱即用；WebGL1 时代要开 `OES_standard_derivatives` 扩展——你不会遇到，但老代码里看到那行 getExtension 会明白它在干什么。

## SDF：一个返回「距离」的函数

border 的两次 step 相乘，把「在不在矩形里」压成了一个 0/1。但矩形内外的像素其实还有一条没被利用的信息：离边界多远。把它留下，就是符号距离场（Signed Distance Field）：

```glsl
// 圆的 SDF：负值在圆内、零在圆上、正值在圆外
float sdCircle(vec2 p, float r) {
  return length(p) - r;
}
```

一个 SDF 就是一个 TypeScript 函数：输入坐标，返回离形状多远——只不过每个像素并发调用它。你在前端写过 `getBoundingClientRect` 判断点击落点，SDF 是它的连续版：不判断「在不在」，直接给出「离多近」。

等值线长什么样，看这张图：

![符号距离场图：左侧面板为圆 SDF 的同心等值线地图，玫红实线圆为 d=0 的边界，圆内淡填充区域标注 d=-1.0 与 d=-0.5 的内部等值线（玫红弱虚线），圆外标注 d=+0.5 与 d=+1.0 的外部等值线（天青虚线，越远越稀）；右侧上图为边界放大图，形状内外之间存在一条琥珀色标注的 fwidth(d) 过渡带，下图为公式卡片「fill = 1.0 - smoothstep(0.0, fwidth(d), d)」并注「过渡带宽度 = 该像素处距离的变化率」；底部通栏文字「布尔只能回答是与否，距离回答了有多近——可插值 · 可缩放 · 可 smooth · 可发光」](../../assets/diagrams/sdf-distance-field.svg)

对着图从内向外过一遍等值线：中心的 d=-1.0，走到玫红实线归零，出了实线变正、天青虚线越画越稀——距离场是整张画布的等高线地图，形状只是其中海拔为零的一条线。最值得盯住的是右上的放大镜：边界两侧那条琥珀色过渡带，宽度不是你定的，是 `fwidth` 依像素实时算的——SDF 填充天生抗锯齿的原因。

**为什么用距离而不是布尔**，图底那行字就是答案：距离可插值（两个形状的距离场能 mix 出渐变形变）、可缩放（距离除以 s 等于半径乘 s）、可 smooth（smoothstep 出任意宽度的软边）、可发光（距离的幂就是辉光，2.6 的主菜）。布尔只能回答是与否，距离回答了有多近——这多出来的一个维度，是后面七讲反复兑现的支票。

## 形状库：圆 / 方 / 圆角方 / 线段

四个标准 2D SDF，全部来自 iq 的文章（课程精简版，够用到毕业）：

```glsl
// 圆：到圆心的距离减半径。最便宜的 SDF，5 个 ALU 之内
float sdCircle(vec2 p, float r) {
  return length(p) - r;
}

// 方：到中心的距离减半边长，逐轴取「超出量」
float sdBox(vec2 p, vec2 b) {
  vec2 d = abs(p) - b;              // 对称折叠：四象限共用同一套计算
  return length(max(d, 0.0)) + min(max(d.x, d.y), 0.0);
  // 调参直觉：b 是半宽半高；内角行为来自第二项，别删
}

// 圆角方：距离往回收一个圆角半径——一行参数化「方↔圆」的连续变形
float sdRoundBox(vec2 p, vec2 b, float r) {
  return sdBox(p, b - r) - r;
  // 调参直觉：r=0 是方，r=min(b.x,b.y) 是胶囊；徽章常用 0.1–0.2
}

// 线段：到两端点所在线段的最近距离
float sdSegment(vec2 p, vec2 a, vec2 b) {
  vec2 pa = p - a, ba = b - a;
  float h = clamp(dot(pa, ba) / dot(ba, ba), 0.0, 1.0);
  return length(pa - ba * h);
  // 调参直觉：dot 求的是「垂足在线段上的投影比例」，
  // clamp 到 [0,1] 让两端封口——忘了 clamp，两端会拖出无限长
}
```

sdBox 那两行是 2D SDF 的最高密度代表：`abs(p)` 把四象限折叠到第一象限（2.2 会正式讲对称折叠），`max(d, 0.0)` 丢弃内部的负值保证外面距离正确，第二项处理「拐角内」的欧氏距离。看不懂推导没关系，**这四个函数当标准库背下来，参数会调就行**——iq 的原文链接在文末，想啃推导的时候再去。

## 布尔运算：并交差与平滑混合

形状库的原子只有四个，组合起来才是场景。距离场的布尔运算是三行算术，比 CSS 的 clip-path 直观得多：

```glsl
float d1 = sdCircle(p, 0.3);
float d2 = sdBox(p, vec2(0.25));

float uni = min(d1, d2);      // 并：离谁都算近——两形状融合
float inter = max(d1, d2);   // 交：必须同时近——重叠区
float diff = max(d1, -d2);   // 差：d1 减去 d2——布尔取反对「挖洞」

// 平滑并：两个距离场用软最小值焊接——lusion 液态形体的全部秘密
float smin(float a, float b, float k) {
  float h = clamp(0.5 + 0.5 * (b - a) / k, 0.0, 1.0);
  return mix(b, a, h) - k * h * (1.0 - h);
}
float blob = smin(d1, d2, 0.08); // k 是「焊枪宽度」
```

min/max 为什么能当布尔用？回到定义：距离场是「离形状多近」，`min(d1, d2)` 取更近的那个——像素离并集的距离正是两者较小值，数学上严丝合缝。`smin` 把硬 min 换成一条 k 宽的软过渡带，两形状在接触处像水滴一样融合——**k 太小看不出焊接，k 大于形状半径的量级就会整体「融化」**（常见坑表第 3 行）。awwwards 上那些液态 logo 变形、水银质感按钮，底层全是这一行。

## How：demo 01「形态标本馆」逐段精讲

demo 01 把本讲的六个考点装裱成 2×3 展墙上的六份标本：圆、方、圆角方、线段、硬并、平滑并，各住一张展卡，呼吸统一、滚轮换灯、悬停预告。fragment 的上半场是「展品」——本讲的四个标准 SDF 就是标本库本体；下半场是「布展」——分格、选格、展卡、射灯依次就位。先看上半场：

```glsl
#version 300 es
precision highp float;

uniform vec2 u_resolution;
uniform float u_time;
uniform float u_pick;  // 射灯对准的格 0–5（JS 滚轮写入）
uniform vec2  u_mouse; // 鼠标 UV（0-1，左下原点），悬停预览用

out vec4 fragColor;

const vec3 BG    = vec3(0.043, 0.055, 0.078); // #0B0E14 展厅夜色
const vec3 CARD  = vec3(0.075, 0.088, 0.128); // #131621 卡纸
const vec3 DIM   = vec3(0.290, 0.322, 0.388); // #4A5263 未打光标本
const vec3 ROSE  = vec3(1.000, 0.302, 0.427); // #FF4D6D 标本本色
const vec3 AMBER = vec3(1.000, 0.757, 0.271); // #FFC145 射灯暖光
const float TAU  = 6.2831853;

float gPx;
float stroke(float d) { return 1.0 - smoothstep(0.0, gPx * 1.5, abs(d)); }
float fillS(float d)  { return 1.0 - smoothstep(0.0, gPx * 1.5, d); }

// ---- 标本库：讲义 2.1 的四个标准实现 ------------------------------
float sdCircle(vec2 p, float r) {
  return length(p) - r;
}

float sdBox(vec2 p, vec2 b) {
  vec2 d = abs(p) - b;
  return length(max(d, 0.0)) + min(max(d.x, d.y), 0.0);
}

float sdSegment(vec2 p, vec2 a, vec2 b) {
  vec2 pa = p - a, ba = b - a;
  float h = clamp(dot(pa, ba) / dot(ba, ba), 0.0, 1.0);
  return length(pa - ba * h);
}

float smin(float a, float b, float k) {
  float h = clamp(0.5 + 0.5 * (b - a) / k, 0.0, 1.0);
  return mix(b, a, h) - k * h * (1.0 - h);
}

// ---- 每格一份标本：id 决定画什么，breath 统一呼吸 ----------------
float cellShape(vec2 cell, int id, float breath) {
  float b = breath; // 0.95–1.05，周期 3s（视觉规格）
  if (id == 0) return sdCircle(cell, 0.16 * b);
  if (id == 1) return sdBox(cell, vec2(0.15 * b));
  if (id == 2) return sdBox(cell, vec2(0.14 * b)) - 0.06; // 圆角：距离往回收
  if (id == 3) return sdSegment(cell, vec2(-0.16 * b, -0.10), vec2(0.16 * b, 0.10)) - 0.018;
  if (id == 4) return min( // 硬并：min 就是 OR
    sdCircle(cell - vec2(-0.09, 0.0), 0.12 * b),
    sdBox(cell - vec2(0.10, 0.0), vec2(0.11 * b)));
  return smin( // 平滑并：k = 0.08 的焊枪（视觉规格）
    sdCircle(cell - vec2(-0.09, 0.0), 0.12 * b),
    sdBox(cell - vec2(0.10, 0.0), vec2(0.11 * b)), 0.08);
}
```

调色板从三色扩到五色：展厅夜色 `BG` 打底，展卡是 `CARD`，没打光的标本灰蓝 `DIM`，射灯落下的标本亮出本色 `ROSE`，灯光本身是暖橙 `AMBER`。`gPx` 是 1.5 的像素尺，`stroke`/`fillS` 是沿用它的描边/填充家族——填充函数叫 `fillS` 而非 demo 03 的 `fill`，因为 main 里 fwidth 主旋律那行还要声明一个局部变量 `fill`，重名会撞车。`cellShape` 是标本柜：六个 `if` 把六份标本装进六个格，`breath`（0.95–1.05）由 main 统一算好再传入。

下半场进 main()。开场是熟悉的现算 UV 三行（1.5），顺手给 `gPx` 上弦；然后是 2×3 分格——正式讲法在 2.2，这里先用起来：每格的 id 由 floor 结果拼出，与 `u_pick` 对出 `isPick`。悬停检测是这间馆的小机关：把完全相同的一套分格变换喂给鼠标 UV，算出鼠标落在哪一格再与当前格比对——几何变换复用一次，鼠标就有了「格感」：

```glsl
void main() {
  vec2 uv = gl_FragCoord.xy / u_resolution;
  float aspect = u_resolution.x / u_resolution.y;
  vec2 p = uv * 2.0 - 1.0;
  p.x *= aspect;
  gPx = 1.0 / u_resolution.y;

  // ---- 2×3 分格（讲义 2.2 平铺的最小版）--------------------------
  // 每格高 1.0、宽 aspect * 2.0 / 3.0：三列两行铺满屏
  vec2 grid = vec2(aspect * 2.0 / 3.0, 1.0);
  vec2 g = p / grid + vec2(1.5, 1.0); // y 偏移 = 行数一半（2 行 → 1.0），两行才都完整
  vec2 id2 = floor(g);
  vec2 cell = (fract(g) - 0.5) * grid; // 格内坐标还原居中域量纲

  int id = int(id2.x) + int(id2.y) * 3;
  int pick = int(u_pick + 0.5);
  float isPick = id == pick ? 1.0 : 0.0;

  // ---- 悬停格：同一套分格变换喂给鼠标 UV -------------------------
  vec2 mp = u_mouse * 2.0 - 1.0;
  mp.x *= aspect;
  vec2 mg = floor(mp / grid + vec2(1.5, 1.0));
  float inBound = step(0.0, mg.x) * step(mg.x, 2.0) * step(0.0, mg.y) * step(mg.y, 1.0);
  float mId = mg.x + mg.y * 3.0;
  float isHover = (abs(mId - float(id)) < 0.5 ? 1.0 : 0.0) * inBound * (1.0 - isPick);
```

射灯点亮之前先布展。每格内缩 0.020 收出一张卡纸，卡上左上角贴一块铭牌条，铭牌上的编号点用 for 循环点出「这是几号标本」——点数不够的格子不亮；形心下方再垫一条 exp 双向衰减的软阴影，标本就像摆在底座上。三样装修全是对距离场的 `fillS` 填充，没有一行 if：

```glsl
  // ---- 展卡：格内内缩的卡纸 + 细内框 ------------------------------
  vec2 cardHalf = grid * 0.5 - vec2(0.020);
  float dCard = sdBox(cell, cardHalf);
  vec3 col = mix(BG, CARD, fillS(dCard));

  // ---- 铭牌条：左上小牌，牌上 id+1 颗编号点 ----------------------
  vec2 plateC = vec2(-cardHalf.x + 0.075, cardHalf.y - 0.022);
  float dPlate = sdBox(cell - plateC, vec2(0.045, 0.009));
  col = mix(col, vec3(0.185, 0.212, 0.278), fillS(dPlate) * 0.85 * fillS(dCard));
  float dots = 0.0;
  for (int i = 0; i <= 5; i++) {
    float dx = -0.030 + 0.012 * float(i);
    dots = max(dots, fillS(length(cell - (plateC + vec2(dx, 0.0))) - 0.0035) * step(float(i), float(id)));
  }
  col = mix(col, mix(vec3(0.42, 0.46, 0.54), AMBER, isPick), dots);

  // ---- 标本底座阴影：形心下方的软带 -------------------------------
  float shadow = exp(-abs(cell.y + 0.22) * 26.0) * exp(-abs(cell.x) * 5.0);
  col = mix(col, vec3(0.020, 0.026, 0.042), clamp(shadow, 0.0, 1.0) * 0.55 * fillS(dCard));
```

然后是本讲的主旋律登场：`breath` 驱动 `cellShape` 取出距离场，fwidth 抗锯齿填成标本——打光格填本色 ROSE，其余灰蓝 DIM，悬停格先微染 35% 本色做预告。最后射灯三件套只加在选中格：`pow` 提亮的光锥从顶窄到底宽铺下来，exp 光池在展卡上部洇开一圈暖光，卡顶再装一颗灯具；卡框常态深灰、选中转琥珀，胶片颗粒收尾：

```glsl
  // ---- 标本体：fwidth 抗锯齿填充（讲义 2.1 的主旋律）-------------
  float breath = 1.0 + 0.05 * sin(u_time * TAU / 3.0);
  float sd = cellShape(cell, id, breath);
  float aa = fwidth(sd);
  float fill = 1.0 - smoothstep(0.0, aa, sd);

  vec3 ink = mix(DIM, ROSE, isPick);           // 打光=本色，否则灰蓝
  ink = mix(ink, mix(DIM, ROSE, 0.35), isHover); // 悬停：微染本色
  col = mix(col, ink, fill);

  // ---- 射灯（仅选中格）：灯具 + 光锥 + 地面光池 ------------------
  float ly = clamp((cell.y + cardHalf.y) / (cardHalf.y * 2.0), 0.0, 1.0); // 0 底 1 顶
  float lampW = mix(cardHalf.x * 0.95, 0.10, ly); // 顶部窄、底部宽的光锥
  float beam = pow(ly, 1.8) * smoothstep(lampW, lampW - 0.05, abs(cell.x)) * isPick;
  col += AMBER * beam * 0.28;

  float pool = exp(-length((cell - vec2(0.0, 0.30)) * vec2(1.0, 2.1)) * 9.0);
  col += AMBER * pool * isPick * 0.16;

  float dLamp = length(cell - vec2(0.0, cardHalf.y - 0.010)) - 0.016;
  col = mix(col, mix(vec3(0.16, 0.18, 0.24), AMBER, isPick), fillS(dLamp) * fillS(dCard));

  // ---- 卡框线：常态深灰，选中琥珀 ---------------------------------
  vec3 frame = mix(vec3(0.155, 0.180, 0.240), AMBER * 0.85, isPick);
  col = mix(col, frame, stroke(dCard) * (0.55 + 0.45 * max(isPick, isHover)));

  // ---- 胶片颗粒 ----------------------------------------------------
  float n = fract(sin(dot(gl_FragCoord.xy, vec2(127.1, 311.7))) * 43758.5453);
  col += (n - 0.5) * 0.02;

  fragColor = vec4(col, 1.0);
}
```

值得盯住的一处：六份标本共用一个 `breath` 参数——main 里算一次，`cellShape` 里全部照收，呼吸节奏全馆统一，是「陈列」而不是「拼盘」的原因。参数化你的魔法数字，让一个变量驱动全局节奏，这个习惯从 demo 01 保持到课程结束。

射灯与悬停的接线在 main.ts：滚轮切换走 chrome 的 `pointer.wheel` 累积量，`((Math.floor(chrome.pointer.wheel / 120) % 6) + 6) % 6` 让负向滚动也循环（1.7 的事件桥）；底部角标被复用成公式牌，射灯每换一格就写下当前标本的 SDF 公式；鼠标位置经 `u_mouse` 进 shader，悬停预览完全在 fragment 里算，JS 侧只喂一次坐标。打开 demo 对照本节代码逐格数过去，六个考点就都过了手。

## 常见坑

| 症状 | 原因 |
|------|------|
| 距离直接当颜色输出（`col = sd`） | SDF 输出的是带符号距离，量级任意——直接显示要么过曝要么全黑；先 `smoothstep` 再进颜色，2.6 会讲距离的合法消费方式 |
| smin 之后形状「融成一滩」 | k 大于形状特征尺寸：焊枪宽过零件本身；k 取形状半径的 1/4 到 1/2 量级 |
| 线段两端拖出长长的尾巴 | `clamp(dot(pa, ba) / dot(ba, ba), 0.0, 1.0)` 忘写或忘了 clamp——投影比例没封口，线段被当成无限直线 |
| 方形的角是尖的、想要圆角改不动 | 用的是 sdBox 而非 `sdBox(p, b - r) - r` 的圆角版——圆角是距离场参数化红利，CSS 里 border-radius 的对应物 |
| 边缘在低分屏锯齿、高分屏发糊 | 过渡带写死了像素宽度；换成 `fwidth(sd)` 依像素自适应——「天生抗锯齿」的机关在导数 |

## Checkpoint

- 能默写 `sdCircle` 与 `sdBox`（含圆角版的关系），并说出 sdBox 里 `abs(p)` 那一步在干什么
- 能解释距离场相对布尔运算的三个优势（可插值 / 可缩放 / 可发光），各举一个后续讲义会兑现的场景
- 能写出任意 SDF 的抗锯齿填充行：`1.0 - smoothstep(0.0, fwidth(sd), sd)`，并解释 fwidth 量的是什么
- 能写出并 / 交 / 差三行距离运算，并说明 smin 的 k 在视觉上对应什么
- 能说出「条件是数据，不是控制流」在 step 与 if 的对比中体现在哪
