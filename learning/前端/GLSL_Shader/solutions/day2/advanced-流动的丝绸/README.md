# 作业 A 答案 · 流动的丝绸

## 运行

`npm run dev` 后访问 `http://localhost:5174/solutions/day2/advanced-流动的丝绸/index.html`。

## 实现要点

- **占位透传是骨架的设计核心**：`fbm` 的占位是 `return noise(p)`、warp 的占位是「无 warp 直接采」、palette 的占位是 `vec3(t)` 灰度——每补一层画面可见地升一级，学生永远知道自己在哪一层。
- **拖动偏置只进展示层**：`drag` 加在 `flow`（采样偏移），不进 hash 的种子层——种子层一动（把 u_vel 混进 hash 输入）整片噪声每帧重掷，画面闪成雪花。2.3 的「种子层与展示层分离」在交互语境下的再现。
- **u_vel 要换量纲再定标**：0–1 域的帧差直接乘 0.2 会让宽屏上的拖动偏置偏角——`u_vel * vec2(2.0 * aspect, 2.0) * 0.2` 先换居中域，方向才是拖动的方向。
- **gamma 放 palette 之后**：iq 卡的参数是感知空间调的，但 shader 运算在线性空间——`pow(col, vec3(0.4545))` 在最后把成果翻译回人眼空间，暗部的暗红才浮出来。
- **t 再分布不能省**：fbm 五层 0.5 幅相加挤在 0.35–0.65，直接上色中段占八成画面；`f * 1.6 - 0.3` 一行是「灰蒙」到「有层次」的距离。

## 视觉规格

- 色板：iq 熔岩卡 `a=b=(0.5,0.5,0.5) c=(1,1,1) d=(0.0,0.10,0.20)`——暗红 → 金的丝绸；底 `#0B0E14`
- 构图：满屏流动、无中心——背景层语义
- 动效：基础流向 (0.12, 0.06)/s、warp 流速 0.06、k=0.8（丝绸档）、拖动偏置 ×0.2
- 细节：t 再分布 ×1.6 −0.3、gamma 0.4545、vignette 0.15
- 性能：单 pass、每像素 3 次 fbm（约 60 hash）——中端 GPU 60fps，账单见讲义 2.4
