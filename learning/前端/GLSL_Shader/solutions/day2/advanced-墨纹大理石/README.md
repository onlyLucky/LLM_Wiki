# 作业 A 答案 · 墨纹大理石

## 运行

`npm run dev` 后访问 `http://localhost:5174/solutions/day2/advanced-墨纹大理石/index.html`。

## 实现要点

- **fbm 不上色、只扭相位**：云海的 fbm 直接进 palette 当「天气」，本题的 f 进 sin 的相位当「纹样」——平行细纹被揉皱成 suminagashi 脉线，纸面天然留白。这是与课程 demo 03-fbm 云海避同构的本质差异。
- **占位透传是骨架的设计核心**：noise 占位 `return 0.5`（灰直纹）、fbm 透传（脉上褶皱）、palette 灰度透传（宣纸上墨）——每补一层墨纹长出一层，学生永远知道自己在哪一层。
- **c = 0.5 让 t 只走半圈**：t ∈ [0, 1]（纸→墨单向过渡），palette(1) 是纸、palette(0) 是墨；若 c = 1 会转整圈，纸墨之间混进一圈无关色相。d 三通道错峰 (0.50, 0.52, 0.56)：纸偏暖、墨偏青。
- **拖动偏置只进展示层**：`drag` 加在 `flow`（采样偏移），不进 hash 的种子层——种子层一动整片墨纹每帧重掷，画面闪成雪花。2.3「种子层与展示层分离」在交互语境下的再现。
- **u_vel 要换量纲再定标**：`u_vel * vec2(2.0 * aspect, 2.0) * 0.2` 先换居中域，偏置方向才是拖动方向。
- **gamma 放 palette 之后**：pow 0.4545 把暗部抬亮——浓墨保持黑、脉缘浮出灰阶（墨分五色），纸是暖白不刺眼。

## 视觉规格

- 色板：iq 余弦 `a=b=(0.5,0.5,0.5) c=(0.5,0.5,0.5) d=(0.50,0.52,0.56)`——palette(1) 暖白宣纸、palette(0) 青黑浓墨、中间淡青灰（墨分五色）
- 构图：大部分画面是纸、脉是线不是云——「纹样」语义
- 动效：基础漂移 (0.03, 0.02)/s（墨在水里是慢的）、warp 错相 0.02、k=0.8（墨流档）、拖动偏置 ×0.2
- 细节：主脉 pow 7、支脉飞白 pow 14、gamma 0.4545、vignette 0.15
- 性能：单 pass、每像素 3 次 fbm（约 60 hash）——中端 GPU 60fps，账单见讲义 2.4
