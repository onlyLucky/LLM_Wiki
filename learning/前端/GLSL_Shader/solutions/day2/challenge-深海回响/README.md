## 实现要点

- **背景对比度让给前景**：海雪层的 25% 透明度不是美学偏好，是视觉层级的工程参数——背景对比度一高，前景的双层 glow 就被吃掉。低对比的蓝灰系色卡（与前景主色同族）是「氛围」而非「抢戏」的定量翻译。
- **回响脉动只呼吸主 glow**：`pulse = 0.85 + 0.15 * sin(u_time * 1.8)` 只乘 PING——声呐 ping 是构造物主动发出的（呼吸），生物光绿是被动的环境（恒定）；两层一起呼吸，「回响」就退化成「整幅画在抖」。
- **流速向下是海雪的语义**：背景层 y 分量取负（-0.08）——深海雪是下沉的；流向一反，丝绸的「流」就变成深海的「沉」，一行参数换一个世界观。
- **视差两倍差是分层下限**：前景 5% / 背景 2%——1:2 的幅度比是「分层可感」的经验下限；再小是同一张纸，再大背景先糊。
- **构图的最小完整件**：声呐环（`abs(length - R) - w`）+ 锚链线段 `smin` 焊深潜灯珠——三个 SDF、两次布尔（一次 min 一次 smin），就把「主体 + 支线」的视觉关系搭出来了；曼陀罗式复杂图案反而不如一件构造物耐看。
- **法线的 z=0.04 与崖宽 0.05 成对**：金属浮雕档的手感组合，单独调一个会失衡（讲义 2.6 坑表第 5 行）。
- **收尾 clamp 是安全带**：三层 additive（两层 glow + 填充）叠加后过曝风险真实存在，`clamp(col, 0.0, 1.0)` 在输出前兜底。

## 视觉规格

- 色板：主 glow 声呐青 `#4CC9F0` × 0.9 × pulse、次 glow 生物光绿 `#3EF0C7` × 0.5、环体深海金属 `(0.78, 0.94, 0.92)`、背景蓝灰系 `snowPalette` × 0.25、底 `#0B0E14`
- 构图：中心聚焦（声呐环 40% 半径），锚链引向右上黄金分割点附近的灯珠
- 动效：背景流速 (0.04, -0.08)（海雪下沉）、warp k=0.6（背景收敛——让给前景）；回响脉动 ±15% @ 1.8 rad/s（只呼吸主 glow）；前景静止（视差即它的动）；grain 4%（动态 seed）
- 视差：前景 5% / 背景 2%（lerp 0.08 chrome 供给）
- 配方卡：gamma 0.4545 → 对比 ×1.06 → 饱和 ×0.9 → grain ±0.04 → vignette 0.2（平方衰减）
- 性能：单 pass、前景 3 SDF + 背景 3 次 fbm 四倍频（≈48 hash/像素），60fps（中端 GPU）
