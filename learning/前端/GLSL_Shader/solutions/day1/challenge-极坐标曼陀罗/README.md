# 作业 C 答案 · 极坐标曼陀罗

## 运行

`npm run dev` 后访问 `http://localhost:5174/solutions/day1/challenge-极坐标曼陀罗/index.html`。

## 实现要点

- **旋转与扰动都加在折叠前**：折叠前加是转轴，12 重对称保持；折叠后加等于给每个扇区不同的偏移，对称当场撕碎。本题最重要的一处取舍，写反了画面立刻告诉你——变成一团碎玻璃。
- 涟漪推的是花瓣半径不是亮度：`rOuter += wave * 0.08` 让波前经过处花瓣鼓起——「推开花瓣」比「亮一下」更接近水的记忆，也更贴合本题「图案推演」的气质。u_age 喂大数时 `exp` 衰减自动归零，无需 if。
- 双层花瓣不同频率（内 9 外 5）、不同半径（0.30 / 0.62）：单层曼陀罗是图章，双层才是图案——层次感是「作品集级」与「练习题」的分界。
- 0.1 rad/s 一圈约 62.8 秒，不是恰好 60 秒——要严格的 60s 整圈用 `TAU / 60.0`（约 0.1047）；本答案取规格的 0.1，肉眼与掐表都无差。
- 颜色沿层分工：内环琥珀（challenge 签名色）、外环天青（课程辅色）——撞色但不抢，暗角把视线收回中心。
- 12 重对称的折叠公式 `abs(mod(angle, sector) - sector * 0.5)`：mod 折进扇区、abs 对中线镜像。先画纯色细环 + sin 条纹自检重复次数，再往上堆效果——骨架注释里那条自检技巧值得保留成习惯。

## 视觉规格

- 色板：内环琥珀 `#FFC145`（80% 强度）、外环天青 `#4CC9F0`（55%）、底 `#0B0E14`
- 构图：中心聚焦，12 重对称辐射
- 动效：旋转 0.1 rad/s（约 62.8s 一圈）；呼吸周期 4s、半径 ±6%；涟漪波速 0.45/秒、衰减 `exp(-age × 1.2)`、推瓣 5–8%；鼠标扰动 ±0.3 rad（约 ±17°）
- 细节：双层花瓣（内 k=9 半径 0.30 / 外 k=5 半径 0.62）、波前水痕微光、暗角 15%、页头 1.2s 延迟淡入、入场 800ms
- 性能：单 pass、DPR ≤ 2，60fps（无循环无纹理，纯解析式）
