圆形用距离来判断边界，矩形用 x 和 y 范围来判断。两个方向的范围同时满足，就在矩形内。

用 step 判断范围

判断 vUv.x 是否在 0.2 到 0.8 之间：

float x = step(0.2, vUv.x) * step(vUv.x, 0.8);
  • step(0.2, vUv.x) = 1 当 vUv.x >= 0.2
  • step(vUv.x, 0.8) = 1 当 vUv.x <= 0.8
  • 两者相乘：只有 0.2 <= vUv.x <= 0.8 时才为 1

同样处理 y 方向，两者相乘得到矩形遮罩：

float y = step(0.3, vUv.y) * step(vUv.y, 0.7);
float rect = x * y;  // 矩形内为 1，外为 0

练习

练习代码里 x = 0.0，y = 0.0（全黑）。用 step 构造两个方向的范围遮罩，让矩形区域（x: 0.2~0.8, y: 0.3~0.7）显示为白色。

答案解析

float x = step(0.2, vUv.x) * step(vUv.x, 0.8);
float y = step(0.3, vUv.y) * step(vUv.y, 0.7);
float rect = x * y;

每个 step 是一个 0/1 的边界判断，两个方向各两个 step 相乘，形成四条边。四边都满足时 rect = 1（白色），否则 rect = 0（黑色）。

改变边界值可以移动矩形的位置和大小。试试 step(0.4, vUv.x) * step(vUv.x, 0.6) 让矩形变窄。

完整参考代码glsl/basic/simple-rectangle.answer.frag
#ifdef GL_ES
precision mediump float;
#endif

varying vec2 vUv;

void main() {
    // 用 step 组合四条边：每条边 step 结果为 1 表示"在边界内侧"
    // 四个结果相乘：只有四条边都满足时才为 1（矩形内）
    float x = step(0.2, vUv.x) * step(vUv.x, 0.8);
    float y = step(0.3, vUv.y) * step(vUv.y, 0.7);
    float rect = x * y;
    gl_FragColor = vec4(vec3(rect), 1.0);
}
