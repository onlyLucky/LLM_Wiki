垂直渐变

上一节用 vUv.x 做水平渐变，这一节换成 vUv.y，方向变成从下到上。

vUv.y 控制垂直方向

vUv.y 在画面底部是 0.0，顶部是 1.0：

float t = vUv.y;
vec3 color = mix(colorA, colorB, t);
  • 底部：t = 0.0 → 完全是 colorA
  • 顶部：t = 1.0 → 完全是 colorB

示例颜色

  • a = vec3(0.1, 0.15, 0.25) — 深夜蓝
  • b = vec3(0.2, 0.85, 1.0) — 天蓝色

底部深色，顶部亮蓝，像是天空渐变。

练习

练习代码里因子 t 是 0.0（画面全是颜色 a）。把 t 改成 vUv.y，让颜色从下到上渐变。

答案解析

float t = vUv.y;

vUv.y 底部为 0，顶部为 1，mix 在两色间插值得到垂直渐变。

vUv.x → 水平，vUv.y → 垂直，就这一个字母的区别。

完整参考代码glsl/basic/vertical-gradient.answer.frag
#ifdef GL_ES
precision mediump float;
#endif

varying vec2 vUv;

void main() {
    vec3 a = vec3(0.1, 0.15, 0.25);
    vec3 b = vec3(0.2, 0.85, 1.0);
    gl_FragColor = vec4(mix(a, b, vUv.y), 1.0);
}
