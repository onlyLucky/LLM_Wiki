上一节学了用 step 计算圆形遮罩。这一节用同样的遮罩，但不输出灰度——而是用它在两种颜色之间切换。

遮罩控制颜色

圆形遮罩的值是 0 或 1。把它传给 mix，就能选择背景色或前景色：

float circle = 1.0 - step(0.3, d);
vec3 bg = vec3(0.06, 0.07, 0.1);   // 深色背景
vec3 fg = vec3(0.2, 0.85, 1.0);    // 亮蓝色
gl_FragColor = vec4(mix(bg, fg, circle), 1.0);
  • 圆内（circle = 1）→ mix 取 fg（亮蓝）
  • 圆外（circle = 0）→ mix 取 bg（深色）

练习

练习代码里 circle = 0.0（全显示背景色）。用 1.0 - step(0.3, d) 计算遮罩，让画面中央出现一个蓝色圆。

答案解析

float circle = 1.0 - step(0.3, d);

和 simple-circle 里的遮罩完全一样——圆内为 1，圆外为 0。不同的是这里把它用于 mix，而不是直接作为灰度输出。遮罩的本质是一个 0/1 的开关，mix(a, b, 0) 取 a，mix(a, b, 1) 取 b。

改变 fg 的颜色值，比如 vec3(1.0, 0.4, 0.1) 变成橙色圆。

完整参考代码glsl/basic/circle-drawing.answer.frag
#ifdef GL_ES
precision mediump float;
#endif

varying vec2 vUv;

void main() {
    vec2 p = vUv - 0.5;
    float d = length(p);
    // 用颜色感受距离场：圆内为蓝色，圆外为深色背景
    float circle = 1.0 - step(0.3, d);
    vec3 bg = vec3(0.06, 0.07, 0.1);
    vec3 fg = vec3(0.2, 0.85, 1.0);
    gl_FragColor = vec4(mix(bg, fg, circle), 1.0);
}
