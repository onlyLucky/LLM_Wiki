整理自 shader-learn.com 的六个部分、共 104 个 fragment shader 小案例，每个案例一页：

  • 左侧是 教程介绍 与 参考答案 两个 Tab；右侧是一块可切换的舞台画布——正确预览（参考代码的渲染结果）与 当前预览（你的练习代码）
  • 案例代码已抽离为独立的 glsl/<部分>/<序号>_<案例>.frag（练习）与 _<序号>_<案例>.answer.frag（参考）文件：在编辑器里改 .frag 文件保存，页面画布会自动更新，无需刷新
  • 案例代码为 WebGL 通用的 GLSL ES 1.00 写法（gl_FragColor），由本页运行时以全屏四边形 + varying vec2 vUv 驱动，并按需注入 u_time / u_resolution / u_mouse
