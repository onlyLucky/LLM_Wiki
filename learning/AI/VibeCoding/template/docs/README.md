# 非规格文档（docs/）

> **给 AI**：本目录存放**不属于规格契约**的辅助资料。规格相关的一切以 `specs/` 为准；本目录仅作参考，**不作为实现依据**。

| 阶段 | 优先级 | 状态 | 负责人 | 最后更新 |
|------|--------|------|--------|----------|
| 全程 | 中 | 进行中 | [@维护者] | YYYY-MM-DD |

## 目录说明

| 子目录 | 用途 | 示例 |
|--------|------|------|
| `meeting-notes/` | 会议纪要、讨论记录 | `2026-01-01-kickoff.md` |
| `external/` | 外部资料、参考资料、调研 | `competitor-analysis.md` |
| `human-guides/` | 面向人的使用手册、操作指南 | `user-guide.md` |

## 与 specs/ 的区别

| 维度 | `specs/` | `docs/` |
|------|----------|---------|
| 性质 | 契约，单一事实来源 | 参考资料 |
| 变更 | 需评审、需同步索引 | 可自由增删 |
| AI 使用 | 必读、作为实现依据 | 按需查阅、不作依据 |

## 命名约定

- 会议纪要：`YYYY-MM-DD-<主题>.md`
- 其他：小写英文 + 连字符，如 `deployment-notes.md`

## 维护约定

- 重要结论若影响实现，应**提炼后移入 `specs/`**，本目录只保留过程记录
- 过期资料及时归档或删除，避免误导
