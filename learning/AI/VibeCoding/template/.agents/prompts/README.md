# 提示词目录 — 可复用提示词

> **给 AI**：本目录存放可复用的任务指派提示词。指派新功能、缺陷修复或评审任务时，**先查这里**，复制对应模板并填写 `[占位符]`，避免每次重新描述需求。

| 阶段 | 优先级 | 状态 | 负责人 | 最后更新 |
|------|--------|------|--------|----------|
| 04 开发与执行 | 高 | 进行中 | [@维护者] | YYYY-MM-DD |

## 提示词索引

| 提示词 | 文件 | 用途 | 使用时机 |
|--------|------|------|----------|
| 新功能开发 | [feature.md](feature.md) | 指派单个小功能，写清范围白/黑名单 | 领取功能类任务时 |
| 缺陷修复 | [bugfix.md](bugfix.md) | 先复现、再定位、后修复 | 处理缺陷时 |
| 代码评审 | [review.md](review.md) | 独立评审 Agent 只审不改 | 关键模块完成后 |

## 使用约定

- 一次只指派一个任务；提示词中必须写清改动范围的白名单与黑名单
- 上下文按需引用（给文件路径与条目 ID，如 `prd.md` 的 F-001），不全文粘贴
- 完成后逐项核对提示词模板末尾的「完成后检查」
- 新增提示词时基于现有文件的结构创建，并登记到上方清单
- 可执行的重复流程沉淀到 [skills/](../skills/README.md)，决策与教训沉淀到 [memory/](../memory/decisions.md)
