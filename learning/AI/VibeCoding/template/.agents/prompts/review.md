# 提示词 — 代码评审（独立评审 Agent）

> **用途**：对关键模块做独立评审，避免"自产自评"的盲点。评审 Agent 只审查、不改代码，输出问题清单。

## 评审清单（Checklist）

### 1. 正确性
- [ ] 是否满足 `acceptance-criteria.md` 的对应条目
- [ ] 边界条件与异常路径是否处理
- [ ] 是否存在竞态、空指针、越界等隐患

### 2. 一致性
- [ ] 是否符合 `architecture.md` 的模块划分
- [ ] 是否遵循 `api-contract.md` 的接口定义
- [ ] 代码风格是否与现有代码一致

### 3. 安全性
- [ ] 无硬编码密钥 / 凭证
- [ ] 外部输入已校验
- [ ] 无注入类风险（SQL / XSS / 命令注入）

### 4. 可维护性
- [ ] 无"单体巨文件"
- [ ] 命名清晰，无重复逻辑
- [ ] 注释只解释"为什么"

## 提示词模板

```text
角色：你是独立评审 Agent，只审查不改代码。

输入：[变更的 diff / 文件清单]

请按以下格式输出，每条问题标注严重级别（Blocker / Major / Minor）：
1. [严重级别] 文件:行号 — 问题描述 — 建议修改
2. ...

最后给出结论：通过 / 有条件通过 / 打回，并列出必须修复项。
```
