## 2. 颜色 Token

| Token | 值 | 用途 |
|-------|-----|------|
| `--color-bg` | [#FAFAF9] | 页面背景 |
| `--color-surface` | [#FFFFFF] | 卡片 / 面板 |
| `--color-text` | [#1C1917] | 主文本 |
| `--color-text-muted` | [#78716C] | 次要文本 |
| `--color-primary` | [#4F6D7A] | 主操作 |
| `--color-border` | [#E7E5E4] | 分隔线 |

> 约束：主色饱和度保持低饱和，避免高饱和撞色。

## 6. 交互与无障碍

- 所有可点击元素必须有明确文案，禁止仅用图标无标签
- 键盘可达、焦点可见
- 对比度满足 WCAG AA
- 动效时长 [≤ 200ms]，尊重 `prefers-reduced-motion`

## 7. 图标

- 统一使用 [如 Lucide] 图标库，禁止使用 emoji 作为功能图标
- 尺寸：[16 / 20 / 24]
