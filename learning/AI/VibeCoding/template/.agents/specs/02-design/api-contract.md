| 错误码 | HTTP | 含义 | 处理建议 |
|--------|------|------|----------|
| `INVALID_INPUT` | 400 | 参数校验失败 | 提示用户修正 |

| `FORBIDDEN` | 403 | 无权限 | 提示无权限 |
| `NOT_FOUND` | 404 | 资源不存在 | 提示不存在 |
| `INTERNAL` | 500 | 服务异常 | 重试 / 上报 |
