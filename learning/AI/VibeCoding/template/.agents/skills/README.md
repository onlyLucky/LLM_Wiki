## 新增技能模板

在本目录新建 `<技能名>.md`，按以下结构编写：

```markdown
# 技能：[名称]

## 用途
[这个技能解决什么问题]

## 前置条件
- [依赖、权限、环境]

## 步骤
1. [步骤 1]
2. [步骤 2]

## 验证
- [如何确认执行成功]

## 回滚 / 失败处理
- [失败时怎么办]

## 示例
```bash
[可直接运行的命令]
```
```

## 命名约定

- 文件名使用小写英文，如 `deploy.md`、`db-migrate.md`
- 一个技能只做一件事；复杂流程拆成多个技能并在步骤中互相引用
