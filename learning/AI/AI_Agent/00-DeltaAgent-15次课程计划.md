# 00 · DeltaAgent 15 次课程计划与学习地图

十五次课、每次课约六小时净学习（讲义 2.5h + demo 2h + 作业 1.5h），一条主线：让 LLM 听懂你的话（第 1–5 课）→ 让 Agent 记得住、串得起（第 6–9 课）→ 搭起自己的节点引擎（第 10–12 课）→ 让短剧画面动起来（第 13–15 课）。建议隔日一课：学习日上课、次日消化（作业 + 复盘 + 返工），三十天完成十五次课；赶进度也可十五天连上，作业当晚收口。《AI-Agent-动画短剧工具-学习路线.md》是地图，本计划是行军表，《_制作计划/01-第1课-规格.md》起的规格文件是施工图——三层各管一层，谁也不替谁干别人的活。

## 课程定位

**学员画像**：TypeScript / Vite / React 熟练（知识库里 GLSL、WebGPU 两门课已结营），Python 从工程角度快速补齐（第 1 课用 uv 对着 npm 世界一次迁移完）；AI Agent 从零开始，目标明确——十五次课后亲手组装自己的动画短剧 Agent 工具，不是泛泛了解概念。

**课程终点**：第 15 课结营时交付一套能跑的 DeltaAgent MVP——一句话创意进，多镜头、2D 骨骼（3D 渲染）的动画短片段出（含配音与口型），管线节点可插拔、多 Agent 分工、向量记忆、System One 决策门控、数据回流接口全部就位。对标《学习路线》终极项目 M0–M3 的压缩实现；动画深度按「够用就走」取核心链路，结营后按模块七继续加深。

**双模型一句话**：GLM-5.3 当教研组长（写规格、写讲义、审查验收），GLM-5.3-flash 当执行工程师（照规格写代码、跑测试、记进度）。你运营的这条「大脑 + 手脚」流水线，正是第 14 课要学的系统一 / 系统二分工的活教材——而且它和小模型执行的工程难题同名：**质量不靠模型自觉，靠规格颗粒度 + 测试验收 + 审计闭环**。

### 质量保障链（回答「小模型执行怎么保证质量」）

1. **规格先行，永远比执行批次早一步**：没有课规格不开批，全 15 份已建齐（黄金样例 = 第 1 课规格）；规格必须写到「函数签名、TODO 编号、测试断言」级——小模型没有创意决策权，只有翻译权
2. **黄金样例制度**：demo 结构范本、作业骨架范本、讲义范本各取第 1 课产物，后续批次「先读样例再动笔」，不另发明结构
3. **测试即验收**：规格里的 pytest 用例原样落地，全绿才算完工；断言只许加不许删改
4. **冒烟即证据**：每个 demo 实跑一次，输出片段贴进 PROGRESS 备注——只写「完成」按未完成论（GLSL 课审计报告抓过这种批次）
5. **审计-返工-复验闭环**：每课代码批完成后，制定侧出五维审计单（结构 / 链接路径 / 风格禁用词 / 可运行 / 技术正确性行号级校对），不达标项出返工单，修复后复验记录进 PROGRESS

### 升级与降级

- 执行侧同一处连续两次修复失败 → 升级制定侧接手，根因写进该 demo 常见报错表
- 跨课重构、架构选型、LoRA 超参 → 直接制定侧
- C 档作业做不出来不要恋战，标 TODO 隔课回来——它考察组合能力，不是意志力

### 模型切换

TraeCode / TraeWork 模型列表里，制定会话选 GLM-5.3、执行会话选 GLM-5.3-flash；列表缺 flash 档时就近选同系轻量款，分工不变。模型可用性以客户端当前内置列表为准（docs.trae.cn）。两个会话唯一交接面是规格文档——制定侧不直接改代码，执行侧不擅自改规格。

## 作业与验收

每晚三档，取舍逻辑与 GLSL 课一致：B 档验收「概念通」，A 档验收「能组合」，C 档验收「作品级」。时间不够只做 B 档，下一课照样跟得上；C 档做不出来标 TODO 隔课回来。各课三档的考点、TODO 编号与提示三档，全部写进课规格（黄金样例见第 1 课规格），由执行侧照规格产出骨架与答案——学员只面对挖空后的骨架和错误指引，不面对答案。

## 结营标准

1. 一句话创意进，≥3 镜头、≥30 秒、含配音与口型的 2D 风格成片出
2. 管线至少 6 个 Schema 化节点，替换 TTS 后端不需要改管线全局代码
3. 剧本与分镜经 Score 门控自动返工至少 1 轮，通过才放行
4. 同一角色跨镜头复用同一份骨骼资产
5. 埋点日志落盘，能从日志生成一份 SFT 数据集样本
6. 讲义 47 篇齐全、PROGRESS 30 批全部登记（每批带冒烟证据）、C 档作业至少完成 5 个

## 结营之后

1. 动画深度按《学习路线》模块七继续：骨骼绑定精细化、NPR 自定义 shader、动作库扩充
2. 从《学习路线》技术栈表逐项替换升级：Chroma → Qdrant、托管 API → 自建 AIGC 管线
3. 把 C 档作业整合成作品集仓库，DeltaAgent 从 MVP 走向终极项目 M3（数据回流微调常态运转）
4. 自训练闭环常态化：每次出片都沉淀样本，按月跑一轮 LoRA + 评估回归
