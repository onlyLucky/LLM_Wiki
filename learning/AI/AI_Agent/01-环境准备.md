# 01 环境准备

十分钟过一遍清单，第 1 课就能开工；分批解锁的部分装到对应课的前一晚即可。

## 今天就装（第 1 课前）

| 工具 | 检查命令 | 说明 |
|---|---|---|
| uv | `uv --version` | Python 版本、依赖、脚本运行全交给它，不手动管 venv |
| 模型接入（三选一） | — | 云端 API Key / Ollama 本地 / 兼容 OpenAI 协议的自有端点 |
| Ollama（可选） | `ollama list` | 本地路线才需要，先拉一个轻量对话模型即可 |
| DeltaAgent 仓库 | `ls ~/Documents/code/2026/@learn/DeltaAgent` | 骨架 README 已就位，批2 执行 `uv init` 补脚手架 |

`.env` 约定：`OPENAI_API_KEY` / `OPENAI_BASE_URL` / `MODEL_NAME` 三个变量名全课程统一；`.gitignore` 必须包含 `.env` 后再做任何提交。

## 按课解锁

| 课次 | 追加安装 | 用途 |
|---|---|---|
| 第 6–7 课 | `uv add chromadb` | 向量库与 RAG |
| 第 10–12 课 | `uv add fastapi uvicorn`；Redis（brew）；第 12 课当天用 pnpm 起 Vite | 服务化、队列、前端编辑器 |

Blender 全课走命令行渲染：`blender --background --python 脚本.py`，不依赖 GUI 操作。

```bash
ollama list          # 走本地路线时
ffmpeg -version
blender --version
```

五条全通（本地路线四条），环境就算就绪。

## 常见环境问题

| 症状 | 处理 |
|---|---|
| API 调用超时 | 检查代理与 `OPENAI_BASE_URL`；公司网络下优先本地 Ollama 路线 |
| Key 有泄露风险 | `.env` 进 `.gitignore`；代码只读环境变量；日志与 print 一律不出现 Key |
| Ollama 拉模型慢 | 先拉最小参数量的对话模型，第 1 课只验证链路，不追求质量 |
| `uv run` 找不到包 | 在仓库根执行 `uv sync`；demo 统一从仓库根运行，不在子目录里建环境 |
