## 讲义 13.1 规格 · 2D 骨骼：切块、层级、蒙皮

```markdown
# 13.1 2D 骨骼：一次绑定，终身复用——你的工具为什么用 3D 骨骼渲 2D

> 第 13 课 · 模块 1 · 约 55 分钟
> 理论对照：《学习路线》模块七「2D 骨骼动画原理」——工具的核心动机课
```

**章节大纲**：

- 导语：Spine 式 2D 骨骼把立绘切块绑骨——换动作不重画；代价是每个角度要重画切件。你的工具反着来：3D 一次绑定，渲成 2D 画面，任何角度都白拿
- `## 四件套机制`：切块（分层 PNG）/ 骨骼层级（root→spine→head→arm 父子树）/ 蒙皮权重（网格顶点跟骨走）/ IK-FK（手抓把手 vs 程序摆位）——四行表 + mermaid 骨架树
- `## Spine 思路的最小复刻`：PNG 切块贴片 + 平面骨绑定（作业 C 档做）；「2D 骨骼解决『动』，3渲2 解决『转』——你的短剧要转面、换镜头，所以选后者」
- `## 资产红利表`：一次绑定 × 多镜头 / 多角色 / 重渲改风格——「第 14 课 AIGC 角色一致性靠锚点图，本课的骨骼资产是另一半：动作与镜头一致性」
- `## How：demo 13 的 armature 结构对应表`
- `## 常见坑`（5 行）：切块边界无重叠（动作时露缝）/ 权重全默认 1:1（动作像硬纸板）/ IK 末端骨忘设目标 / 层级挂错父（手臂跟着头转）/ 把绑定当一次性（资产版本管理从今天开始）
- `## Checkpoint`：能画出四骨层级树；能说清 2D 骨骼与 3渲2 各解决什么；能列出资产红利的三个白拿项

## 讲义 13.2 规格 · bpy 程序化：建模、骨骼与动画曲线

```markdown
# 13.2 bpy 程序化：把 Blender 变成你的渲染节点

> 第 13 课 · 模块 2 · 约 65 分钟
> 理论对照：《学习路线》模块七「程序化 3D」——第 10 课 Node 思想的动画版
```

**章节大纲**：

- 导语：GUI 操作无法进管线；bpy 让 Blender 变成一个函数——输入参数，输出帧序列，正好做成第 14 课的渲染节点
- `## 场景装配`：bpy.ops 三板斧（object.armature_add / mesh.primitive / camera）；清场纪律（每次脚本先清默认 Cube）
- `## 绑定与关键帧`：modifier（armature）接线；`keyframe_insert(data_path, frame)`；骨旋转驱动示例（挥手：arm.rotation 从 -30° 到 30°，三关键帧缓动）
- `## 动画十二法则取三条`：缓入缓出（第 1 课 GLSL 课的 easing 知识跨域复用！）、预备动作、挤压拉伸——每条给 bpy 关键帧摆法；「你前端课攒的缓动手感在这里直接变现」
- `## 摄像机运动`：推近（z 位移关键帧）与轻微摇移；帧率与 duration 换算（第 9 课 Shot.duration 的单位回收：duration×FPS=帧数）
- `## How：demo 13 的 stage.py 分段对照`
- `## 常见坑`（6 行）：忘清默认场景（Cube 入镜）/ `--background` 下没有窗口系统（禁用任何 view3d 操作）/ 骨尺度单位误用（米 vs Blender 单位）/ 关键帧帧号错位（FPS 常量统一）/ 修改器顺序（armature 要在生成器之后）/ 脚本里硬编码绝对路径
- `## Checkpoint`：能写出清场 + 建骨 + 关键帧最小脚本；能做 duration→帧数换算；能说出三条法则各自的关键帧摆法

## 讲义 13.3 规格 · NPR：Toon Shading、描边与色阶

```markdown
# 13.3 3渲2：秘密全在着色 ramp 与描边

> 第 13 课 · 模块 3 · 约 60 分钟
> 理论对照：《学习路线》模块七「3渲2（NPR）」——风格化渲染的参数手册
```

**章节大纲**：

- 导语：写实渲染回答「光怎么照」；NPR 回答「观众看什么」——把连续光照压成两三档色阶，3D 模型立刻变 2D 漫画脸
- `## Toon ramp`：Ramp shader 两档（亮部 / 暗部 + 硬边过渡）；shader 节点接线图（mermaid）；三档 vs 两档的观感对照（作业 B 档）
- `## 描边两条路`：Freestyle 线稿（视空间轮廓，线条风格参数）与反转法线实体描边（厚度可控、性能好）——对照表三行（实现 / 风格 / 开销）；本工具默认 Freestyle，常量可切
- `## 色阶与风格参数区`：OUTLINE_WIDTH / RAMP_STEPS / PALETTE 三常量的效果对照；「风格是参数，不是玄学——改参数出风格对照图」
- `## 渲染输出`：`--background --python` 命令行；输出到 assets/13/frames/（PNG 序列）；文件命名 `frame_0042.png`；序列验证清单（帧数、首尾帧存在）
- `## How：demo 13 的渲染配置段`
- `## 常见坑`（5 行）：Freestyle 在 Eevee/Workbench 引擎差异（锁定一个写进常量）/ 描边参数全局一个值导致远近一样粗 / ramp 过渡太软（又变写实了）/ 透明背景忘开（合成要抠底）/ 输出路径不存在（脚本先 mkdir）
- `## Checkpoint`：能说出两条描边路的取舍；能给参数区加一个新风格参数；能写出输出验证清单

## demo 规格 · 13-程序化舞台

| 项 | 规格 |
|---|---|
| 路径 | `demos/13-程序化舞台/`（README.md / render.py / stage_builder.py / tests/test_run.py）；产出 `assets/13/frames/frame_0001.png …` |
| 行为目标 | `uv run blender --background --python demos/13-程序化舞台/render.py`（若环境无 blender 命令包装，README 给两种启动方式）→ 清场 → 搭舞台（地板 + 背景墙 + 两根角色占位胶囊）→ 建 4 骨 Armature（root/spine/head/arm）绑胶囊 → 60 帧动画（挥手 + 摄像机缓推，缓动用三关键帧）→ Toon ramp + Freestyle 描边 → 输出 60 帧 PNG 序列；`--quick` 参数（10 帧）供快速冒烟 |
| 接口约束 | 顶部常量区（全参数集中）：`FPS = 24`、`FRAME_COUNT = 60`、`OUTLINE_WIDTH = 2.0`、`RAMP_STEPS = 2`、`PALETTE = {"亮部": "#F5E9DA", "暗部": "#8A6F5C"}`、`BG_COLOR = "#141A24"`、`OUTPUT_DIR = "assets/13/frames"`；`stage_builder.py`：`build_stage(context) -> None`、`build_armature(context) -> Object`、`animate(armature, frame_count) -> None`（挥手三关键帧：-30° / +30° / 0°，缓入缓出）、`setup_npr(context) -> None`（ramp + Freestyle）；render.py：读常量、按序调用、`--quick` 减帧渲染、输出后打印验证清单 |
| 分段结构 | S1 清场与常量装载 → S2 舞台与占位角色装配 → S3 骨骼与绑定 → S4 关键帧动画（三法则取三条的摆法）→ S5 NPR 配置与渲染输出 + 验证清单 |
| 验收测试 | `test_frame_math`（duration 2.5s × FPS 24 == 60 帧换算函数）/ `test_constants_frozen`（常量区六项存在且类型正确——参数契约测试）/ `test_stage_builder_pure_calls`（builder 各函数签名与调用序对 mock context 可跑通、无窗口操作）/ 渲染冒烟：有 Blender 环境时跑 `--quick` 并断言输出目录 10 帧 PNG 存在；无环境则 pytest -m "not render" 跳过并在 PROGRESS 如实登记「渲染冒烟待学员本地」 |
| 渲染冒烟口径 | 执行侧环境有 Blender：跑 --quick、帧清单数 == 10、首尾帧存在，输出行贴 PROGRESS；无 Blender：全部纯逻辑测试照跑，渲染项标注「待学员执行」，不许标完成 |

**README 关键点 4 条**：① 两种启动方式（blender 命令行 vs `blender --background --python` 的路径差异）② duration→帧数换算与第 9 课合同的接口 ③ 参数区即「风格配置文件」——第 14 课渲染节点的入参雏形 ④ 缓动三关键帧与 GLSL 课 easing 的跨域对照。

**常见报错预填**：默认 Cube 没清入镜 / `--background` 下调 view3d API 报错 / Freestyle 与引擎不匹配（线条不出）/ 输出目录未建 / 骨旋转单位用错（弧度 vs 度）/ 透明通道没开。
