## 讲义 14.1 规格 · 角色一致性：ControlNet 与 IP-Adapter

```markdown
# 14.1 角色一致性：同一张脸，不许换人

> 第 14 课 · 模块 1 · 约 55 分钟
> 理论对照：《学习路线》模块七「AIGC 内容管线」——一致性是短剧的地基
```

**章节大纲**：

- 导语：观众对「换脸」零容忍——多镜头短剧的第一技术红线；市面 ComfyUI 管线怎么解，你的工具怎么取
- `## 三件套`：锚点图（角色定妆照，一次生成反复用）/ IP-Adapter 嵌入（把锚点图的特征向量注入生成）/ ControlNet（姿态与构图约束）——三行表（管什么 / 输入 / 缺了会怎样）；「锚点图管脸，骨骼管动作——两条一致性链在 demo 会师」
- `## ComfyUI 管线拆解`：北电《极境》式的角色一致性工作流骨架（锚点图 → 特征提取 → IP-Adapter → ControlNet 姿态 → 视频生成后端）；节点图 mermaid；「拆解它不是为了照搬，是为了知道哪些节点将来进你的管线」
- `## 两条出片通道`：AIGC 图生视频（进阶，托管 API 或开源模型，需 GPU/Key）与 bpy 帧序列（保底，第 13 课已具备）——本课 demo 主走保底通道、AIGC 留接口；「通道本身是一个 Choice 决策点——路由交给决策层，这正是三原语的第一个用户」
- `## 常见坑`（5 行）：锚点图风格漂移（多锚点不统一）/ ControlNet 权重过高把画面锁死 / 一致性与动作幅度的天然冲突 / AIGC 通道没兜底（Key 失效全线瘫痪——保底通道是工程要求不是备胎）/ 换后端没留通道接口（第 10 课合同的动画域版）
- `## Checkpoint`：能说出三件套各自管什么；能画出 ComfyUI 一致性管线骨架；能解释为什么保底通道是工程要求

## 讲义 14.2 规格 · TTS、口型与 FFmpeg 合成

```markdown
# 14.2 出片流水线：从帧序列到能看的片子

> 第 14 课 · 模块 2 · 约 60 分钟
> 理论对照：《学习路线》模块七「TTS 口型、FFmpeg 合成」
```

**章节大纲**：

- 导语：画面、声音、字——三条素材流在 FFmpeg 里合流；本课把 30 秒短片完整跑通
- `## TTS`：edge-tts 生成配音（voice / rate 参数）；文本即第 9 课分镜的台词字段——「合同字段在此兑现」；音频时长回填验证（`ffprobe`）
- `## 简化口型`：音节驱动方案——把台词按音节切片、映射到嘴部骨骼的开合关键帧（张开/闭合两态 + 每音节 2–3 帧），第 13 课骨骼的复用；与 Wav2Lip 视频后处理路线一行对照（进阶通道）
- `## FFmpeg 合成`：帧序列 → 视频（`-framerate`）、配音 mux、字幕烧录（drawtext 或 .ass）三条命令；30 秒成片的参数表（分辨率 / 帧率 / 码率）
- `## 合成验证`：`ffprobe` 检查（时长 / 流 / 帧率）——「产物验证用工具说话，肉眼不算证据」
- `## How：demo 14 的 compose 段`
- `## 常见坑`（5 行）：帧率与 TTS 时长对不上（嘴空转或抢拍）/ 字幕中文乱码（字体路径）/ mux 命令流顺序（`-map` 想清楚）/ 帧序列断号 / 分辨率与第 13 课渲染输出不一致（全链参数表统一）
- `## Checkpoint`：能写出合成三命令；能做时长对齐校验；能说出音节口型方案的简化代价

## 讲义 14.3 规格 · System One 三原语与类型化问题设计

```markdown
# 14.3 三原语：把管线里的每个 if 换成一个决策

> 第 14 课 · 模块 3 · 约 55 分钟
> 理论对照：《学习路线》模块五「决策引擎」——System One 判断模型的工程接入
```

**章节大纲**：

- 导语：第 12 课的阈值 if 写死一个数；生产管线的问题是「阈值本身该不该过审」——把判断交给专门的决策模型，LLM 退回规划位
- `## 三原语接口`：`choice(state, options) -> ChoiceResult(selection, probabilities, confidence)`；`score(state, rubric) -> ScoreResult(value, band_probs, confidence)`；`noul(state, statement) -> float`（0–1；0.5 是弃权，按第三分支处理）；接口与 OpenRouter 文档对齐，真实后端可替换、mock 后端脚本化
- `## 类型化问题设计`：把业务判断翻译成类型化问题的四步模板（给状态 → 列选项 / 定标尺 / 写命题 → 定阈值与降级路径）；「问题设计得好，小判断不用大模型」
- `## 接线改造`：第 12 课门控的 Critic if → Score 原语；镜头走哪条渲染通道 → Choice 原语；「要不要重渲染」→ Noul 原语——改造前后对照表；留痕：每个决策记录「问题 / 结果 / 置信度 / 耗时」
- `## 与 LLM 的分工`：系统一（判断：高频、结构化、毫秒级）与系统二（规划与生成：第 15 课的埋点样本有一部分就来自这些决策）；「你的双模型制作流水线——GLM-5.3 制定、flash 执行——就是同一个原理的真人版」
- `## How：demo 14 的 decision 接线段`
- `## 常见坑`（5 行）：把开放问题硬塞给 Noul（命题要可判真伪）/ 0.5 弃权当「是」处理（要写第三分支）/ 置信度不看就行动（低于阈值走降级）/ 决策不留痕（第 15 课埋点断粮）/ 原语调用当免费（低置信度高频调用也要预算）
- `## Checkpoint`：能写出三原语签名；能把一个业务 if 翻译成类型化问题；能说出弃权分支的处理

| 项 | 规格 |

| 路径 | `demos/14-30秒单镜头短片/`（README.md / run.py / compose.py / tests/test_run.py）；决策沉淀 `src/deltaagent/decision.py`；素材依赖第 9 课 storyboard.json（mock 固定样例内置）与第 13 课渲染通道 |

| 接口约束 | `decision.py`：`ChoiceResult(selection: str, probabilities: dict[str, float], confidence: float)`、`ScoreResult(value: float, band_probs: dict[str, float], confidence: float)`；`DecisionClient.ask_choice(state: str, options: list[str]) -> ChoiceResult`、`ask_score(state: str, rubric: list[str]) -> ScoreResult`、`ask_noul(state: str, statement: str) -> float`；`MockDecisionClient` 同签名、脚本化序列；`log_decision(question, result, elapsed_ms) -> None` 追加 `assets/14/decisions.jsonl`（第 15 课埋点的前身）；compose.py：`tts(text, out_path) -> Path`、`align_mouth(syllables, fps) -> list[int]`（开合帧表）、`compose(frames_dir, audio_path, subtitle, out_path) -> Path`（FFmpeg 三步：序列转视频 / mux / 烧字幕） |
| 分段结构 | S1 决策封装与 mock 序列 → S2 通道路由（Choice → bpy 或 aigc 接口占位）→ S3 分镜取数与渲染（复用第 13 课，禁改）→ S4 TTS + 口型 + 合成 → S5 质检门控（Score → Noul → 重渲一轮）与留痕落盘 |
| 验收测试 | `test_choice_routes_backend`（mock choice 返回 bpy 且路由分支正确）/ `test_score_gate_triggers_rework`（首轮 6.0 → Noul 0.85 → 重渲后二轮 8.2，轮次计数 == 2）/ `test_noul_abstain_branch`（0.5 时走第三分支：记录弃权并按默认放行）/ `test_mouth_align_framecount`（音节数 × 每音节帧数与台词时长换算一致）/ `test_compose_outputs_file`（FFmpeg 可用时产物存在且 ffprobe 时长 > 0；无 FFmpeg 环境标注 skip 并登记） |

**README 关键点 4 条**：① 三原语接管的三处 if 对照表 ② decisions.jsonl 字段与第 15 课埋点的血缘 ③ 两条通道的保底逻辑（AIGC 失败自动落 bpy）④ 全链参数表（分辨率 / 帧率全链一致）。

**常见报错预填**：edge-tts 网络（降级静音占位并提示）/ FFmpeg 字幕字体路径 / ffprobe 未装 / 帧序列断号（合成报错）/ mock 决策序列错位。
