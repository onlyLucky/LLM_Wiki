## 目录

| 章节 | 内容 | 对应课程 |
|------|------|----------|
| [01 - 概览与光栅化](01-概览与光栅化.md) | 图形学定义、应用领域、渲染管线 | Lecture 01 |
| [02 - 向量与线性代数](02-向量与线性代数.md) | 向量运算、点积叉积、矩阵 | Lecture 02 |

| [07 - 光线追踪](07-光线追踪.md) | Whitted-Style、BVH、辐射度量学、路径追踪、材质与外观 | Lecture 13-18 |
| [08 - 动画与模拟](08-动画与模拟.md) | 关键帧、质点弹簧系统、运动学、ODE 求解、流体模拟 | Lecture 21-22 |
