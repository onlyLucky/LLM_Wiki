## 三轮修复：光照渲染「椭圆」问题（方形画布）

- 用户反馈：光照渲染案例显示的都是椭圆形，与教程「球体光照」描述不符。
- 根源：全部光照案例（及基础部分圆形案例）按**正方形 UV 空间**书写（`p = vUv - 0.5; sphereSDF(p, 0.32)`，无宽高比校正），而预览画布是宽矩形（约 920×380），x 方向拉宽 2.4 倍 → 圆变扁椭圆。
- 修复（只改共享资产，无需重新生成页面）：
  - `runtime.js` applySize：绘制缓冲统一取 `min(w, h)` 方形；`pointer()` 把指针坐标经 object-fit contain 的内容区换算（黑边钳制到边缘）。
  - `course.css`：`.preview canvas` 加 `object-fit: contain`，方形内容居中，黑边为有意的装裱效果。
- 验证：截图像素分析 ambient-diffuse / lambert-sphere / rim-light 球体包围盒均 264×264（ratio=1 正圆）；solid-color 红色方块 414×414 正方形；实时编辑（LIVE）与动画（ripple hash）无回归。
- 教训：截图像素检测的谓词会被四角 tag 文字污染，需向内收缩裁剪区再测。

## 四轮改造：GLSL 代码抽离为独立 .frag 文件（改文件即改预览）

- 用户需求：页面内嵌代码有格式问题；把需要修改的 GLSL 单独抽离成文件，只改 glsl 文件就能改当前预览。
- 实现：生成器新增 write_glsl_files()——每案例产出 `shader-learn/glsl/<part>/<slug>.frag`（练习）与 `<slug>.answer.frag`（参考），共 208 个文件；写入前 normalize_code() 统一格式（去行尾空白 21 处、补结尾换行 24 处、收拢空行）。页面保留内嵌代码作 file:// 兜底，文件内容优先。
- runtime.js：新增 watchFile(url, onChange)——fetch(cache:'no-store') 轮询 1.5s；首次加载必定应用（文件 > 内嵌），变更时练习侧仅在页面空闲（textarea 未聚焦且 3s 内无本地编辑）才覆盖，参考侧直接应用（同步正确预览 + 答案 Tab 代码）。RESET 按钮恢复到文件最新内容。
- **关键 bug**：初版把 boot 闭包里的 fileWatchIdle() 写进了模块级 watchFile 的 gate——作用域外引用抛 ReferenceError，被 .catch 静默吞掉，变更检测正常但 apply 永不执行（首次加载因 `prev===null` 短路掩盖了问题）。修复：watchFile 只负责检测并回调，空闲判定移回 boot 侧回调。教训：Promise 链里的 catch 不打日志会吞掉作用域类错误。
- 页面新增：编辑器下方 file-hint 提示条（显示 .frag 路径）、答案 Tab 代码标签旁显示源文件路径。
- 验证（playwright + 像素采样）：改 solid-color.frag 黑→绿 → 当前预览 3s 内变绿 + 编辑器同步；内联编辑绿→蓝仍生效；改 .answer.frag 红→紫 → 正确预览变紫 + 答案 Tab 更新；RESET 回到文件内容；ripple 全图校验和随时间变化；无 JS 报错。截图采样要在 .canvas-wrap 上做并避开四角标注。
