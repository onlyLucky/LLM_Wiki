## 修复 basic/17_grid-lines（网格线）缺失左、下边框
- 问题：`float line = step(1.0 - lw, g.x) + step(1.0 - lw, g.y)` 只在每个格子的末端（`g→1`）画线，`g = 0` 一侧永远不画。最右/最上因为 `fract(整数) = 0` 恰好落在线宽内而成线，最左/最下则完全没有 → 网格不闭合。
- 新写法（到最近格线的距离，对称）：
  ```glsl
  vec2 e = min(g, 1.0 - g);                       // 格子两端都算格线，格线处为 0
  float line = 1.0 - step(lw * 0.5, min(e.x, e.y));
  ```
  线条以格线为中心向两侧各占 `lw * 0.5`，总宽仍是 `lw`，与旧版粗细一致；四条外边框都存在（因线心落在画布边界上，边框为半个线宽，视觉上自然收边）。
