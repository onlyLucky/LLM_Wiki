## 🔑 关键发现

- **坑1：Docker bind mount inode 替换** — 用 `sudo rm -rf dist && sudo mv /tmp/xxx dist` 替换部署目录会换 inode，容器挂载仍指向旧 inode → 容器内 `/usr/share/nginx/html/` 空目录 → 首页 403/demo 500。修复：`docker restart award-websites` 让容器重新绑定挂载
- **坑2：Next.js 16 动态路由导出为单文件** — demo 页面导出为 `demo/xxx.html` 单文件，`demo/xxx/` 目录只有 `.txt` 中间产物无 `index.html`，nginx `try_files $uri $uri/ /index.html` 对带斜杠 URL 触发 `directory index is forbidden` → 403。修复：为每个 demo 目录复制生成 `index.html`，且**必须同步修复本地 `out/`**，否则下次 build 复现
- **部署知识已存在并完成整合** — 排查中发现 `china-static-site-deployment` skill 的 reference 已自动记录此次部署笔记（10:55 生成），因此采用「优化既有 skill」而非新建重复 skill，避免内容分裂
